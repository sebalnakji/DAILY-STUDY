# 지도 학습(Supervised Machine Learning)이란 무엇인가?

## 질문

> **지도 학습(supervised machine learning)이란 무엇인가?** 👶
>
> 원문: *What is supervised machine learning?*

## 핵심 개념

질문에 답하기 위해 필요한 핵심 개념을 정리한다.

- **레이블(label)이 붙은 데이터**: 입력 `X`에 대해 정답 출력 `y`가 이미 태깅되어 있는 데이터.
- **함수 학습**: 지도 학습의 목표는 입력을 출력으로 매핑하는 함수 `f: X → y`를 데이터로부터 추정하는 것.
- **학습 vs 예측**: 학습 단계에서는 정답을 보고 오차를 줄이고, 예측 단계에서는 처음 보는 입력에 대해 출력을 추론한다.
- **문제 유형 구분**
  - 회귀(regression): 출력이 연속값 (예: 집값 예측)
  - 분류(classification): 출력이 이산 범주 (예: 스팸 / 정상)
- **비지도 학습과의 대비**: 비지도 학습은 정답 레이블 없이 데이터 구조(군집, 저차원 표현)를 찾는다.
- **대표 알고리즘**: Linear Regression, Logistic Regression, KNN, Decision Tree 등.
- **KNN 직관**: 새 데이터에 가장 가까운 `k`개의 레이블된 이웃을 보고 다수결/평균으로 결정한다.

## 기준 답변

기준 레포의 답변을 바탕으로 핵심만 재구성한다.

지도 학습은 **잘 레이블링된 학습 데이터로 알고리즘을 훈련시키고, 그 데이터를 바탕으로 출력을 예측하는 머신러닝 유형**이다. 여기서 "레이블링됐다"는 것은 입력 데이터에 이미 적절한 출력이 태깅되어 있다는 뜻이다.

즉 본질적으로 지도 학습은 **입력 집합을 받아 출력을 반환하는 함수를 학습하는 작업**이다. 대표적인 예로 Linear Regression, Logistic Regression, KNN 등이 있으며, KNN은 가장 가까운 `k`개의 레이블된 데이터 포인트를 참고해 결과를 정하는 방식이다.

## 내가 정리한 내용

- 정답(Label)이 포함된 과거 데이터를 이용해 입력값과 출력값의 관계를 학습하는 방법
- **핵심 목적**: 학습 데이터를 단순히 잘 맞추는 것이 아니라, 처음 보는 데이터도 정확하게 예측하는 것. 즉 **일반화 성능**을 높이는 것
- **문제 유형**: 예측 대상인 `y`의 형태에 따라 나뉨

  | 유형 | 예측 대상 | 예시 |
  |---|---|---|
  | 회귀 | 연속적인 숫자값 | 집값, 매출, 수요 예측 |
  | 분류 | 정해진 범주 | 스팸/정상, 이탈/유지 |

- **대표 알고리즘**
  - Linear Regression
  - Logistic Regression
  - K-Nearest Neighbors
  - Decision Tree
- **요약**: 정답이 있는 데이터를 바탕으로 입력과 출력의 관계를 학습하고, 새로운 데이터의 값을 예측하는 방법

## 검토 결과

### 확인된 부분

- 정의 / 목적 / 분류 기준 / 대표 알고리즘 네 요소를 모두 갖춘 완결된 답변.
- 문제 유형의 기준을 "출력 형태"가 아니라 **"예측 대상 `y`의 형태"** 로 정확히 서술함.
- 실습 문제(이탈 예측 → 지도·이진 분류 / 고객 유형 파악 → 비지도·군집) 모두 정답.

### 보강 포인트

- **확률을 출력해도 분류다.** 모델이 `0.87`을 뱉어도 학습한 `y`가 0/1이면 분류 문제다. 확률은 중간 산출물이고, **임계값(threshold)** 을 씌워야 최종 답이 된다.
- **임계값 선택 = 정밀도(precision) ↔ 재현율(recall) 트레이드오프.** 이탈 예측처럼 놓치는 비용이 큰 문제는 임계값을 낮춰 과잉 탐지를 감수한다. → Classification / Validation 주제로 이어짐.
- **Logistic Regression은 이름과 달리 분류 알고리즘이다.** 면접 단골 함정.
- **레이블은 공짜가 아니다.** "이탈"의 정의(구독 취소 / 90일 미접속 등)를 사람이 정해야 레이블이 생기고, 정의가 바뀌면 문제 자체가 바뀐다. 면접에서 이탈 예측 문제를 받으면 모델보다 **"이탈을 어떻게 정의하나요?"** 를 먼저 되묻는 편이 좋다.
- **같은 데이터라도 질문이 바뀌면 유형이 바뀐다.** "이탈할까?"는 분류지만 "언제 이탈할까?"는 연속값이므로 회귀/생존분석이 된다.
- **지도 vs 비지도의 결정적 차이는 평가 가능 여부.** 지도는 정답이 있어 Accuracy·F1·RMSE로 객관적 채점이 되지만, 비지도는 정답이 없어 실루엣 계수 같은 내부 지표와 사람의 해석에 의존한다.
- **자기지도학습(self-supervised)** 은 사람이 붙인 레이블 없이 데이터 자체에서 정답을 만들어낸다(다음 단어 맞히기 등). 학습 메커니즘은 지도 학습이며 LLM 사전학습이 대표 사례다.

- 말로 답할 때는 맨 아래 `요약` 문장을 **가장 먼저** 꺼낸다. 두괄식이 훨씬 잘 들린다.
