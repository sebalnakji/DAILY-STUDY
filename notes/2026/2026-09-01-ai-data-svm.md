## 핵심 개념

질문에 답하기 위해 필요한 핵심 개념을 정리한다.

### 정의

**두 클래스를 가르는 초평면(hyperplane) 중에서 마진(margin)이 가장 큰 것을 찾는 분류 알고리즘.**

```text
결정 함수:  f(x) = wᵀx + b
분류:       ŷ = sign( wᵀx + b )

w : 초평면의 법선 벡터(방향)
b : 절편(위치)
```

- **초평면(hyperplane)**: 특징 공간을 두 영역으로 나누는 경계. 2차원이면 직선, 3차원이면 평면, d차원이면 (d−1)차원 초평면.
- **마진(margin)**: 초평면과 **가장 가까운 데이터 점** 사이의 거리.
- **서포트 벡터(support vector)**: 마진 경계 위에 놓인, **초평면에 가장 가까운 점들**.

### 왜 하필 "마진이 최대"인가

선형 분리가 가능한 데이터에는 두 클래스를 가르는 직선이 **무한히 많다.** 그중 무엇을 고를 것인가가 SVM의 출발점이다.

```text
     ○ ○ ○                    ○ ○ ○
    ○ ○ ○                    ○ ○ ○
  ─────────  ← 경계 A       ╌╌╌╌╌╌╌╌╌  마진 위
  ● ● ●                     ─────────  ← 경계 B
 ● ● ●                      ╌╌╌╌╌╌╌╌╌  마진 아래
                            ● ● ●
                           ● ● ●
경계 A: 아슬아슬하게 붙음    경계 B: 양쪽에서 최대한 멀리
새 점이 조금만 흔들려도       → 새 점이 흔들려도 여유가 있다
반대편으로 넘어간다
```

**마진이 클수록 일반화 성능이 좋다**는 것이 SVM의 핵심 가설이다. 훈련 데이터에 딱 붙은 경계는 노이즈에 취약하고, 여유를 둔 경계는 새 데이터에 강하다.

수학적으로는 **마진 = `2 / ||w||`** 이므로, 마진 최대화는 **`||w||` 최소화**와 같다.

```text
minimize   ½‖w‖²
subject to yᵢ(wᵀxᵢ + b) ≥ 1   (모든 i에 대해)
```

이 형태를 **이차 계획법(Quadratic Programming, QP)** 문제라고 하며, **전역 최적해가 유일하게 존재**한다.

> 💡 **경사하강법과의 차이** — [[2026-08-27-ai-data-gradient-descent]]에서 다룬 신경망의 손실 지형은 지역 최솟값이 많아 초기값에 따라 결과가 달라진다. SVM의 목적 함수는 **볼록(convex)** 이라 **어디서 출발해도 같은 답**에 도달한다.

### 서포트 벡터만이 모델을 결정한다

SVM의 가장 특이한 성질이다.

| 데이터 점 | 모델에 미치는 영향 |
|---|---|
| 마진 경계 위·안쪽의 점 (**서포트 벡터**) | **결정적** — 이 점들만으로 초평면이 정해진다 |
| 마진 밖 멀리 있는 점 | **전혀 없음** — 지워도 결과가 똑같다 |

훈련 데이터가 100만 개여도 서포트 벡터가 200개면, **모델은 그 200개만 기억하면 된다.** 그래서 SVM은 **희소한(sparse) 모델**이다.

> 로지스틱 회귀와 비교하면 대조가 뚜렷하다. 로지스틱 회귀는 **모든 점**이 손실에 기여해 경계를 조금씩 밀어낸다. SVM은 **경계 근처 점만** 본다.

### 소프트 마진 — 현실 데이터는 깨끗하지 않다

지금까지는 **선형 분리가 완벽히 가능하다**고 가정했다(하드 마진, hard margin). 현실에서는 클래스가 섞여 있어 그런 직선이 아예 없다.

**슬랙 변수(slack variable) `ξᵢ`** 를 도입해 위반을 허용한다.

```text
minimize   ½‖w‖²  +  C · Σξᵢ
subject to yᵢ(wᵀxᵢ + b) ≥ 1 − ξᵢ,   ξᵢ ≥ 0
             ↑                        ↑
        마진을 넓혀라            위반을 줄여라
```

**`C`는 이 두 요구의 균형을 잡는 하이퍼파라미터**다.

| `C` | 의미 | 결과 |
|---|---|---|
| **크다** | 위반에 큰 벌점 | 마진이 좁아짐. 훈련 데이터에 밀착 → **과적합 위험** |
| **작다** | 위반에 관대 | 마진이 넓어짐. 오분류를 감수 → **과소적합 위험** |

> 💡 **`C`는 정규화 강도의 역수**다. [[2026-08-09-ai-data-regularization]]의 `λ`와 방향이 반대라고 기억하면 된다 — `C = 1/λ`. `C`가 작을수록 정규화가 세다.

### 힌지 손실(Hinge Loss)

슬랙 변수를 정리하면 SVM은 다음 손실을 최소화하는 것과 같다.

```text
L(y, f(x)) = max(0, 1 − y·f(x))
```

| `y·f(x)` | 상황 | 손실 |
|---|---|---|
| ≥ 1 | 마진 밖에서 **올바르게** 분류 | **0** — 손실 없음 |
| 0 ~ 1 | 맞았지만 **마진 안쪽** | 0 ~ 1 |
| < 0 | **틀림** | 1 이상, 선형 증가 |

```text
손실
 3 │╲
 2 │ ╲
 1 │  ╲
 0 │   ╲________  ← 여기가 서포트 벡터가 아닌 점들
   └───┴────────  y·f(x)
  -1   0   1   2
```

**`y·f(x) ≥ 1`인 점은 손실이 정확히 0**이다. 이것이 "서포트 벡터만 모델을 결정한다"의 수학적 근거다 — 손실이 0인 점은 기울기도 0이라 학습에 아무 영향을 주지 않는다.

기준 레포 `ml-fundamental.md`의 손실 함수 목록에도 **Hinge loss (SVM)** 이 올라 있다.

## 기준 답변

### 커널 SVM — 선형으로 안 갈리면?

```text
1차원 데이터:   ● ● ○ ○ ○ ● ●
                직선(점) 하나로 못 가른다
```

이런 데이터는 **어떤 직선으로도** 분리할 수 없다. 그런데 차원을 하나 올려 `z = x²`를 추가하면:

```text
2차원(x, x²)으로 올리면:

 x² │  ●             ●
    │    ●         ●
    │ ╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌  ← 이제 직선으로 갈린다!
    │      ○  ○  ○
    └──────────────── x
```

**저차원에서 안 갈리는 데이터도 고차원으로 올리면 갈리는 경우가 많다.** 이것이 커널 SVM의 착상이다.

#### 문제 — 고차원 매핑은 비싸다

특징이 100개인 데이터를 3차 다항식 공간으로 올리면 차원이 **수십만 개**로 폭발한다. `φ(x)`를 실제로 계산해서 저장하는 건 불가능하다.

#### 커널 트릭(Kernel Trick)

여기서 결정적인 관찰이 나온다. **SVM의 쌍대(dual) 형태를 보면 데이터가 오직 "내적(inner product)" 형태로만 등장한다.**

```text
쌍대 목적 함수:  Σαᵢ − ½ ΣΣ αᵢαⱼ yᵢyⱼ ⟨xᵢ, xⱼ⟩
                                        ↑
                              데이터는 내적으로만 쓰인다
```

고차원으로 올린 뒤에도 필요한 건 `⟨φ(xᵢ), φ(xⱼ)⟩` 뿐이다. 그렇다면 —

> **`φ(x)`를 실제로 계산하지 않고, 내적 결과만 바로 구할 수 있다면?**

그 역할을 하는 함수가 **커널 함수(kernel function)** 다.

```text
K(xᵢ, xⱼ) = ⟨φ(xᵢ), φ(xⱼ)⟩

좌변: 원래 저차원 공간에서의 값싼 계산
우변: 고차원 공간에서의 비싼 내적
→ 계산은 좌변으로, 효과는 우변으로
```

**고차원 공간에 실제로 가지 않고 그 공간에 간 것과 같은 결과를 얻는다.** 이것이 커널 트릭이다.

#### 대표적인 커널

| 커널 | 수식 | 성격 |
|---|---|---|
| **선형(Linear)** | `K = xᵢᵀxⱼ` | 매핑 없음. 특징 수가 많고 선형 분리가 되는 경우(텍스트 등) |
| **다항(Polynomial)** | `K = (γ·xᵢᵀxⱼ + r)ᵈ` | `d`차 다항 상호작용을 표현 |
| **RBF / 가우시안** | `K = exp(−γ‖xᵢ−xⱼ‖²)` | **무한 차원** 공간에 대응. 가장 널리 쓰이는 기본값 |
| **시그모이드** | `K = tanh(γ·xᵢᵀxⱼ + r)` | 신경망 유사. 실무에서는 드물게 사용 |

**RBF(Radial Basis Function) 커널의 `γ`**:

| `γ` | 영향 반경 | 결과 |
|---|---|---|
| **크다** | 각 점의 영향이 **좁다** | 경계가 구불구불 → **과적합** |
| **작다** | 각 점의 영향이 **넓다** | 경계가 밋밋 → **과소적합** |

> 🔧 커널 SVM에서 튜닝할 하이퍼파라미터는 보통 **`C`와 `γ` 두 개**다. 어제 배운 [[2026-08-31-ai-data-hyperparameter-tuning]] 기준으로는 **2차원 저차원 문제**라 **Grid Search**가 적합하고, 둘 다 **로그 스케일**로 훑어야 한다(`C ∈ {0.01, 0.1, 1, 10, 100}`).

### 장점과 단점

| 장점 | 단점 |
|---|---|
| **고차원에서 강하다** — 특징 수 > 샘플 수여도 동작 | **대용량 데이터에 느리다** — 학습이 대략 `O(n²)~O(n³)` |
| **볼록 최적화** — 전역 최적해가 유일 | **커널·하이퍼파라미터 선택**에 성능이 크게 좌우 |
| **희소 모델** — 서포트 벡터만 저장 | **확률 출력이 없다** — 별도 보정(Platt scaling) 필요 |
| **마진 최대화**로 일반화가 좋다 | **해석이 어렵다** — 커널 쓰면 특징 중요도를 못 본다 |
| 커널로 **비선형 경계** 표현 | 특징 **스케일링이 필수** (거리 기반이므로) |

### 언제 쓰는가

| 상황 | SVM 적합? |
|---|---|
| 샘플 수천~수만, 특징 많음 (텍스트 분류, 바이오인포매틱스) | ✅ 매우 적합 |
| 샘플 수십만~수백만 | ❌ 학습이 너무 느림 → 로지스틱 회귀·트리 계열 |
| 표 형태 데이터, 특징 혼합형 | △ → **그래디언트 부스팅**이 보통 낫다 |
| 이미지·음성 등 원시 신호 | ❌ → 딥러닝 |

## 내가 정리한 내용

### 1. SVM이 경계를 고르는 기준

마진이 크면 새 데이터가 조금 흔들려도 유지됨. 즉 **일반화가 잘 되므로 SVM은 마진이 큰 경계를 선택**함.

### 2. 왜 대부분의 데이터를 무시할 수 있는가

마진은 경계와 **가장 가까운 데이터 점까지의 거리(= 최솟값)** 이고, 그 최솟값을 만드는 점들을 **서포트 벡터**라고 부른다. 따라서 **최솟값을 만드는 점들만** 필요하고 나머지는 무시할 수 있음. 서포트 벡터는 보통 여러 개이며, 최소한 양쪽 클래스에서 각각 하나 이상은 있어야 한다.

### 3. `C`의 역할

- `C`는 **마진과 위반의 균형**.
- `C`를 크게 하면 위반에 대해서 엄격해지며 **마진이 좁아짐**.
- `C`를 작게 하면 위반에 대해서 유해지며 **마진이 넓어짐**.
- 마진이 좁다는 건 **경계가 데이터 점에 바짝 붙어 있다**는 뜻이다. 훈련 데이터에는 노이즈·이상치가 섞여 있어서, **이상치 하나를 맞히려다 경계 전체가 뒤틀린다.** `C`를 낮추면 모델이 "저 점 하나는 틀리고 넘어가겠다"고 말할 수 있게 된다.
- 결국 `C`는 **훈련 데이터를 얼마나 믿을 것인가**를 정하는 손잡이다.

### 4. 커널 트릭

- 저차원에서 안 갈리는 문제가 **고차원에서는 갈리는 경우가 많음**. 하지만 다항 공간으로 올리면 **차원이 급격하게 증가**함.
- 이 문제를 해결하기 위해 **고차원 공간에 실제로 가지 않고 간 것과 같은 결과를 얻는 커널 트릭**을 사용.
- 비용 문제는 **내적 결과만 구하여** 해결. 이게 가능한 이유는 **SVM의 목적 함수에 데이터가 오직 "점끼리의 내적" 형태로만 등장하기 때문**이다. 데이터가 날것으로 등장했다면 `φ(x)`를 실제로 계산해야 했을 것이고 커널 트릭은 불가능했다.

### 5. 커널 SVM의 한계

- **표현력이 큰 것은 훈련 데이터를 잘 맞추는 것이고, 이는 과적합 여력도 커지는 것.** 즉 표현력과 일반화는 맞바꾸는 관계.
- `γ`가 크면 각 훈련점이 좁은 영역만 관할해 **사실상 데이터를 외운다.**
- 과적합 말고도 한계가 있다 — **학습이 느리고**(`O(n²)~O(n³)`, 샘플 수십만이면 현실적으로 못 씀), **하이퍼파라미터에 민감하고**, **해석이 안 되고**(특징 중요도를 못 봄), **특징 스케일링이 필수**이며, **확률 출력이 없다**.

## 검토 결과

### 확인된 부분

- **SVM의 선택 기준**을 "마진이 크면 흔들려도 유지된다 → 일반화"로 정확히 설명했다. 마진 최대화가 목적이 아니라 **일반화를 위한 수단**이라는 인과를 바로 세웠다.
- **`C`가 마진과 위반의 균형**이라는 것과 양방향 결과를 정확히 정리했다.
- **커널 트릭의 동기 → 문제 → 해법** 순서를 스스로 재구성했다(저차원 안 갈림 → 차원 폭발 → 가지 않고 간 효과).
- **"표현력과 일반화는 맞바꾸는 관계"** 를 스스로 도출했다. 편향-분산 트레이드오프를 커널 SVM 맥락에서 이해했다는 신호다.

### 보강 포인트

#### ① 마진과 서포트 벡터 — 정의의 순서가 뒤집혀 있었다

| | 내용 |
|---|---|
| **전** | 마진은 **서포트 벡터와 경계의 거리**의 최솟값 |
| **후** | 마진은 경계와 **가장 가까운 데이터 점**까지의 거리(= 최솟값)이고, **그 최솟값을 만드는 점들을 서포트 벡터라고 부른다** |

**서포트 벡터가 먼저 있고 마진이 정의되는 게 아니다.** 거리의 최솟값을 재고 나서, 그 최솟값을 만든 점에 **이름을 붙인 것**이 서포트 벡터다.

이 순서가 중요한 이유: 뒤집어 놓으면 **"왜 나머지를 무시하나"에 답이 안 된다.** "서포트 벡터와의 거리니까 나머지는 무시"는 순환 논리다. 반면 **"최솟값을 최적화하니까, 최솟값을 만들지 않는 점은 값을 못 바꾼다"** 는 순환이 없다.

#### ② 서포트 벡터는 하나가 아니다

| | 내용 |
|---|---|
| **전** | 따라서 **한 데이터만** 필요하고 나머지는 무시할 수 있음 |
| **후** | **최솟값을 만드는 점들(서포트 벡터)만** 필요하다. 보통 **여러 개**이며, 최소한 **양쪽 클래스에서 각각 하나 이상** 있어야 한다 |

경계는 양쪽 클래스 **사이**에 있어야 하므로 한쪽 점만으로는 위치가 정해지지 않는다. 최소 2개, 실제로는 보통 수십~수백 개다.

#### ③ "마진이 좁으면 왜 과적합인가"가 빠졌다

교정 후 내용은 위 `내가 정리한 내용` 3번에 반영. 핵심은 **이상치 하나가 경계 전체를 뒤튼다**는 그림이다.

#### ④ 커널 트릭이 "가능한 이유"가 빠졌다

| | 내용 |
|---|---|
| **전** | 비용 문제는 **내적 결과만 구하여** 해결 |
| **후** | (동일) + **가능한 이유는 목적 함수에 데이터가 오직 내적 형태로만 등장하기 때문** |

"내적만 구하면 된다"는 **결과**고, "내적으로만 등장한다"는 **조건**이다. 조건이 있어야 트릭이 성립한다.

#### ⑤ 한계가 과적합 하나뿐이었다

교정 후 내용은 위 `내가 정리한 내용` 5번에 반영. 특히 **"느리다"** 가 실무 선택에서 결정적이다.

### 심화: 최솟값을 최적화하느냐, 합을 최적화하느냐

SVM이 대부분의 데이터를 무시할 수 있는 진짜 이유는 **목적 함수가 "최솟값"을 다루기 때문**이다.

> 🏫 **비유**: 반에서 **가장 키 작은 학생의 키**를 재고 있다. 뒤쪽에 서 있는 키 큰 학생 열 명이 조퇴해도 **측정값은 그대로**다. 최솟값을 만드는 사람이 아니니까. 그런데 맨 앞 학생이 조퇴하면 **숫자가 바뀐다.**

멀리 있는 점이 **얼마나** 멀든 상관없다. 마진 1.5 거리에 있든 150 거리에 있든, 최솟값이 아닌 건 매한가지다.

| | SVM | 로지스틱 회귀 |
|---|---|---|
| 목적 | **최솟값**(가장 가까운 거리)을 키운다 | **전체 합**(모든 점의 손실)을 줄인다 |
| 멀리 있는 점 | 최솟값이 아니므로 **무시** | 합에 조금이라도 기여하므로 **반영** |
| 점 하나 삭제 | 서포트 벡터가 아니면 **변화 없음** | **항상 조금 움직임** |

**"최솟값을 최적화하느냐, 합을 최적화하느냐"** — 이 차이 하나가 두 모델의 성격을 전부 갈라놓는다. 힌지 손실이 `y·f(x) ≥ 1`인 점에서 정확히 0이 되는 것이 이 성질의 수학적 표현이다.

### 심화: `C = ∞`이면 이상치 하나가 경계를 뒤튼다

`C`를 무한대로 보내면 소프트 마진이 **하드 마진**이 된다 — 위반을 하나도 허용하지 않는다.

```text
정상 데이터 (C 적당)              이상치 하나 (C = ∞)
  ○ ○ ○ ○                          ○ ○ ○ ●  ← 라벨이 잘못 붙은 점 하나
 ○ ○ ○ ○                          ○ ○ ○ ╱
╌╌╌╌╌╌╌╌╌  넓은 마진             ╌╌╌╌╌╌╱  마진이 억지로 뒤틀림
─────────                        ────╱
╌╌╌╌╌╌╌╌╌                       ╌╌╌╱
 ● ● ● ●                         ● ● ● ●
● ● ● ●                         ● ● ● ●
```

**이상치 하나 때문에 경계 전체가 뒤틀린다.** 그 점 하나를 맞히려다 나머지 전부의 일반화를 희생하는 것이다. 데이터가 깨끗하면 `C`를 크게, 노이즈가 많으면 작게.

### 심화: 무한 차원의 함정 — `γ`와 암기

"차원을 무한히 올리면 뭐든 갈라지지 않나?" — **정말로 갈라진다. 그게 문제다.**

> **동전을 던져 아무렇게나 붙인 라벨도 갈라낼 수 있다.**

무작위 라벨조차 훈련 정확도 100%로 맞힌다면 그 모델은 **배운 게 아니라 외운 것**이다.

| `γ` | 각 점의 영향 반경 | 경계 모양 | 결과 |
|---|---|---|---|
| **크다** | 아주 좁다 | 훈련점 하나하나를 감싸는 섬 모양 | **암기 = 과적합** |
| 적당 | 적당 | 부드러운 곡선 | 일반화 |
| **작다** | 아주 넓다 | 거의 직선 | **과소적합** |

```text
γ 큼 (과적합)              γ 적당              γ 작음 (과소적합)
  ⊂●⊃  ⊂●⊃                  ╭────╮
 ⊂○⊃  ⊂●⊃                  ╱  ●  ╲              ─────────
  ⊂●⊃ ⊂○⊃                 │ ● ● ● │
훈련점마다 섬을 만듦        ╲  ○  ╱             직선 하나로 대충
새 점은 전부 틀림           ╰────╯
```

`γ`가 크면 각 훈련점이 **자기 주변 아주 좁은 영역만** 관할한다. 사실상 훈련 데이터를 좌표째 외우는 것이고, 그 사이 빈 공간에 떨어진 새 데이터는 전부 틀린다.

**이건 편향-분산 트레이드오프가 커널 SVM에서 나타난 형태다.** 무한한 표현력은 곧 **분산이 무한히 커질 수 있다**는 뜻이고, 그래서 `C`와 `γ`로 **일부러 제약을 걸어야** 한다.

### 심화: `C`와 `γ` 튜닝 — Grid가 표준인 이유

어제 배운 판단 기준을 적용하면:

| 판단 축 | 이 상황 | 가리키는 전략 |
|---|---|---|
| 하이퍼파라미터 개수 | **2개**(`C`, `γ`) — 저차원 | **Grid** |
| 좋은 범위를 아는가 | **안다** — 둘 다 관례적 범위가 잘 알려져 있다 | **Grid** |
| 1회 학습 비용 | 보통 | Bayesian 불필요 |
| 병렬 자원 | 있으면 활용 | Grid / Random 둘 다 OK |

2차원이면 Grid의 투영 손실이 거의 없다. 게다가 `C`·`γ`는 표준 범위가 있어 "값 목록을 못 짜겠다"는 Random의 명분이 약하다. scikit-learn 문서의 SVM 튜닝 예제도 **`C` × `γ` 격자 탐색**이 표준이다.

> **Random이 틀린 건 아니다.** 예산이 고정돼 있고(예: "40번만") 촘촘한 격자가 예산을 초과한다면 Random이 합리적이다. 다만 이 문제에서 더 강하게 가리키는 신호는 **"저차원 + 알려진 범위"** 라 Grid다.

**로그 스케일 함정은 그대로 적용된다** — [[2026-08-31-ai-data-hyperparameter-tuning]]

```text
❌ C ∈ {2, 4, 6, 8, 10}          → 0.001~1 구간을 통째로 못 본다
✅ C ∈ {0.01, 0.1, 1, 10, 100}
   γ ∈ {0.0001, 0.001, 0.01, 0.1, 1}
```

`C`가 1→2로 가는 변화는 정규화 강도가 절반으로 줄지만, 100→101은 1% 변할 뿐이다. **곱셈적으로 움직여야** 의미 있는 탐색이 된다.

### 이전 학습과의 연결

- [[2026-08-27-ai-data-gradient-descent]] — 신경망의 손실 지형은 지역 최솟값이 많아 초기값에 따라 결과가 달라진다. SVM의 목적 함수는 **볼록(convex)** 이라 **어디서 출발해도 같은 답**에 도달한다. 이것이 SVM의 큰 장점이다.
- [[2026-08-09-ai-data-regularization]] — `C`는 정규화 강도의 **역수** 역할을 한다. L2의 `λ`와 방향이 반대라고 기억하면 된다.
- [[2026-08-31-ai-data-hyperparameter-tuning]] — `C`·`γ` 튜닝에 어제 배운 전략 선택 기준과 로그 스케일 함정이 그대로 적용된다.
- [[2026-08-21-ai-data-gradient-boosting]] — 표 형태 데이터에서 SVM보다 부스팅을 먼저 쓰는 이유가 **학습 속도**다. SVM은 `O(n²)~O(n³)`.
- [[2026-08-19-ai-data-kmeans-vs-knn]] — SVM도 거리 기반이라 **특징 스케일링이 필수**라는 점이 KNN과 같다.
- [[2026-08-13-ai-data-decision-tree]] — 결정 트리는 특징 중요도를 볼 수 있지만 커널 SVM은 볼 수 없다. **해석 가능성**이 갈리는 지점이다.
