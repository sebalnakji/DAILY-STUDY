## 핵심 개념

질문에 답하기 위해 필요한 핵심 개념을 정리한다.

### 문제 설정 — 신경망은 외우기 너무 쉽다

[[2026-09-11-ai-data-cnn]]에서 본 대로, 완전연결층 하나에도 파라미터가 **1억 개**를 넘길 수 있다. 훈련 데이터가 수만 장이면 **데이터보다 파라미터가 훨씬 많다.**

```text
파라미터 > 데이터  →  모델이 데이터를 "이해"하지 않고 "외울" 수 있다
                   →  훈련 손실은 0에 가까운데 새 데이터에서는 엉망
```

[[2026-08-09-ai-data-regularization]]에서 배운 **L1·L2는 가중치의 크기에 벌점**을 준다. 그런데 신경망에는 그것만으로 부족하고, **신경망의 구조를 이용한 기법**이 따로 있다.

### 드롭아웃 — 학습 때마다 뉴런을 무작위로 끈다

**정의**: 학습 스텝마다 **각 뉴런을 확률 `p`로 꺼 버린다.** 꺼진 뉴런은 그 스텝의 순전파·역전파에 참여하지 않는다.

```text
스텝 1                    스텝 2                    스텝 3
○─●─○─●                  ●─●─○─○                  ○─●─●─●
│ │ │ │                  │ │ │ │                  │ │ │ │
●─○─●─○                  ○─●─●─○                  ●─○─○─●
                                                   
● = 살아 있는 뉴런,  ○ = 이번 스텝에 꺼진 뉴런
매 스텝 다른 조합이 살아남는다
```

기준 레포의 표현대로, 매 스텝 **`1−p` 비율의 뉴런만** 학습에 참여한다.

### 왜 이게 효과가 있나 — 세 가지 관점

같은 현상을 보는 세 가지 방식이 있고, 셋 다 맞다.

#### ① 공적응(Co-adaptation) 방지 — 가장 직관적인 설명

뉴런들이 **서로에게 의존하는 관계**를 만들어 버리는 게 문제다.

```text
드롭아웃 없이 학습하면

  뉴런A: "나는 대충 할게, 뉴런B가 보정해 줄 거야"
  뉴런B: "A가 이렇게 나올 테니 나는 이렇게 맞출게"
  → 둘이 짝을 이뤄야만 제대로 동작하는 취약한 조합
```

**드롭아웃은 이 짝을 끊는다.** B가 언제 꺼질지 모르니 A는 **혼자서도 쓸모 있는 특징**을 배워야 한다. 기준 레포의 표현으로는 **"특정 뉴런 부분집합에만 의존하지 못하게 강제한다."**

> 🏫 **비유**: 조별 과제에서 매번 무작위로 몇 명이 빠진다면, **모두가 전 범위를 알아야** 한다. 특정인에게 한 파트를 몰아주는 분업이 불가능해진다.

#### ② 앙상블 근사 — 가장 강력한 설명

매 스텝 **다른 뉴런 조합**이 살아남는다는 건, 매번 **다른 신경망을 학습시키는 것**과 같다.

```text
뉴런이 n개면 살아남는 조합은 2ⁿ 가지
→ 뉴런 100개짜리 층 하나만 해도 2¹⁰⁰ 개의 서브네트워크

학습 : 매 스텝 그중 하나를 뽑아 조금씩 학습
추론 : 그 모든 서브네트워크의 "평균"처럼 동작
```

**앙상블(ensemble)이 과적합을 줄인다**는 건 [[2026-08-18-ai-data-random-forest]]에서 이미 본 원리다. 랜덤 포레스트가 **여러 트리를 따로 학습해 평균**을 냈다면, 드롭아웃은 **하나의 망 안에서 그 효과를 흉내 낸다.**

| | 랜덤 포레스트 | 드롭아웃 |
|---|---|---|
| 모델 수 | 수백 개 (실제로 만든다) | **2ⁿ 개** (가중치를 공유하는 가상의 모델) |
| 비용 | 모델 수만큼 | **거의 공짜** |
| 다양성 확보 | 데이터·특징 샘플링 | **뉴런 샘플링** |

#### ③ 노이즈 주입 = 정규화

무작위로 뉴런을 끄는 것은 **학습 과정에 잡음을 넣는 일**이다. 잡음이 있으면 모델은 **잡음에 흔들리지 않는 견고한 패턴**만 붙잡게 된다. 데이터를 정확히 외우는 해(解)는 잡음 아래에서 유지되지 않는다.

### 학습과 추론이 다르다 — 스케일 문제

**드롭아웃은 학습할 때만 적용한다.** 추론(예측) 때는 **모든 뉴런을 켠다.**

> ⚠️ 여기서 문제가 생긴다. 학습 때는 뉴런의 `1−p`만 켜져 있었는데 추론 때 전부 켜면 **다음 층으로 들어가는 신호의 크기가 갑자기 커진다.**

```text
p = 0.5 인 경우

학습 시 : 평균적으로 절반만 켜짐  →  다음 층 입력 합 ≈ S
추론 시 : 전부 켜짐              →  다음 층 입력 합 ≈ 2S   ← 2배로 튄다
```

학습 때 보던 것과 다른 분포가 들어오니 성능이 무너진다. **보정이 필요하다.**

| 방식 | 언제 보정하나 |
|---|---|
| 원래 드롭아웃 | **추론 시** 출력에 `(1−p)`를 곱한다 |
| **역 드롭아웃(Inverted Dropout)** | **학습 시** 살아남은 값을 `1/(1−p)`로 나눠 미리 키운다 |

**오늘날 프레임워크는 전부 역 드롭아웃을 쓴다.** 학습 때 미리 보정해 두면 **추론 코드는 아무것도 안 해도 되기** 때문이다. 배포되는 쪽을 단순하게 만드는 선택이다.

## 기준 답변

### 신경망 정규화 기법 정리

기준 레포는 네 가지를 든다. 여기에 실무에서 함께 쓰이는 것들을 더해 **어디에 작용하는가**로 묶으면 이렇다.

| 작용 지점 | 기법 | 내용 |
|---|---|---|
| **가중치** | **L1** | 가중치 절댓값 합에 벌점. 일부를 **정확히 0**으로 → 특징 선택 효과 |
| **가중치** | **L2** | 가중치 제곱 합에 벌점. **가중치 감쇠(weight decay)** |
| **뉴런** | **드롭아웃** | 학습 중 뉴런을 확률 `p`로 끈다 |
| **데이터** | **데이터 증강(Data Augmentation)** | 회전·반전·크롭·색 변화 등으로 **훈련 데이터를 인위적으로 늘린다** |
| **학습 과정** | **조기 종료(Early Stopping)** | 검증 손실이 나빠지기 시작하면 학습을 멈춘다 |
| **활성값 분포** | **배치 정규화(Batch Normalization)** | 주 목적은 학습 안정화지만 **정규화 효과도 부수적으로** 있다 |

> 💡 **네 가지가 서로 다른 층위를 건드린다**는 점이 중요하다. 그래서 **함께 쓸 수 있다** — L2와 드롭아웃과 데이터 증강을 동시에 적용하는 것이 표준이다.

### 데이터 증강 — 가장 직접적인 해법

과적합의 근본 원인이 **"데이터에 비해 파라미터가 많다"** 라면, 해법은 둘뿐이다.

```text
① 파라미터를 줄인다     → L1·L2, 드롭아웃, CNN의 가중치 공유
② 데이터를 늘린다        → 데이터 증강
```

**데이터 증강은 두 번째 길이다.** 이미지를 좌우 반전해도 고양이는 고양이이므로, **라벨을 유지하면서 입력만 바꾼** 새 훈련 예시를 공짜로 만든다.

> ⚠️ **어떤 변환을 쓸지는 도메인이 정한다.** 좌우 반전은 고양이 사진에는 안전하지만 **숫자 인식에는 위험하다** — 2를 뒤집으면 2가 아니다. "라벨이 보존되는 변환인가"가 판단 기준이다.

### 드롭아웃 확률 `p` 선택

| 위치 | 관례적인 `p` |
|---|---:|
| 은닉층 | **0.5** |
| 입력층 | 0.1 ~ 0.2 |
| 현대 트랜스포머 | **0.1** 내외 |

- `p`가 크면 정규화가 강해지지만 **학습이 느려지고 과소적합** 위험
- `p`가 작으면 효과가 미미
- 전형적인 튜닝 대상이다 → [[2026-08-31-ai-data-hyperparameter-tuning]]

**입력층에 `p`를 작게 쓰는 이유**: 입력은 원본 정보라 **끄면 정보가 그냥 사라진다.** 은닉층의 특징은 중복성이 있어 몇 개 꺼도 복원되지만, 입력 픽셀은 그렇지 않다.

### 오늘날의 위치

드롭아웃은 2014년 이후 표준이었지만 지금은 **쓰임이 줄었다.**

| 이유 | 설명 |
|---|---|
| **배치 정규화와 충돌** | 배치 정규화가 통계를 쓰는데 드롭아웃이 그 통계를 흔든다. 함께 쓰면 오히려 나빠지는 경우가 있다 |
| **데이터가 많아졌다** | 과적합 압력 자체가 줄었다 |
| **다른 정규화가 강해졌다** | 데이터 증강, 잔차 연결, 가중치 감쇠 |

그럼에도 **트랜스포머에는 여전히 낮은 비율(0.1)로 들어간다.** 완전히 사라진 게 아니라 **강도가 낮아진 것**이다.

## 내가 정리한 내용

### 1. 드롭아웃이 무엇이고 왜 효과가 있나

**드롭아웃은 학습 스텝마다 각 뉴런을 `p` 확률로 꺼 버리는 것.** 꺼진 뉴런은 그 스텝의 순전파·역전파에 관여하지 않는다.

이 방법은 **공적응 방지, 앙상블 근사, 노이즈 주입** 세 가지 효과가 있다.

| 관점 | 내용 |
|---|---|
| **공적응 방지** | 뉴런들이 **짝을 이뤄야만 동작하는 취약한 조합**을 만드는데, 그 짝은 **훈련 데이터에서만 성립하는 우연한 협업**일 수 있다. 언제 꺼질지 모르니 각 뉴런이 **혼자서도 쓸모 있는 특징**을 배우게 된다 → **중복성(redundancy) 확보** |
| **앙상블 근사** | 뉴런이 `n`개면 살아남는 조합이 `2ⁿ` 가지. 매 스텝 **다른 서브네트워크**를 학습하고 추론 때는 그 평균처럼 동작한다. **가중치를 공유해 거의 공짜로** 앙상블 효과를 얻는다 |
| **노이즈 주입** | 학습에 잡음이 있으면 **잡음에 흔들리지 않는 견고한 패턴**만 살아남는다. 데이터를 정확히 외우는 해는 잡음 아래에서 유지되지 않는다 |

### 2. 학습과 추론의 비대칭

- 드롭아웃은 **학습에만 사용하고 추론에서는 사용하지 않는다.**
- 이러면 **학습 때 보던 입력 범위와 추론 때가 달라 학습한 가중치가 그 범위에 맞지 않는다.**
- 이를 해결하기 위해 **역 드롭아웃(Inverted Dropout)** 으로 **학습 때 미리 보정**해, 추론 때는 아무것도 안 해도 되게 만든다.

**`1/(1−p)`가 그 값인 이유**: **평균 스케일을 원래대로 되돌리는 값**이다. `p=0.5`면 절반만 살아남으니 살아남은 값을 2배로 키워야 합이 맞는다.

**왜 학습 쪽에서 보정하나**

```text
학습 : 한 번 한다
추론 : 배포 후 수십억 번 일어난다

→ 비용은 한 번 치르는 쪽에 몰고, 반복되는 쪽은 가볍게
```

덧붙여 **추론 코드에 드롭아웃 분기가 아예 없으면** 모델 변환·배포(ONNX 등)가 단순해지고 **"추론 때 드롭아웃 끄는 걸 깜빡하는" 버그**가 원천 차단된다.

### 3. 정규화 기법의 작용 지점

**각 기법의 작용 지점이 겹치지 않기 때문에 함께 쓸 수 있고**, 배치 정규화와 드롭아웃처럼 **활성값이라는 같은 지점에 작용하는 경우 오히려 성능이 나빠질 수 있다.**

```text
L2         → 가중치 값에 손댄다
드롭아웃    → 뉴런의 on/off에 손댄다
데이터 증강 → 입력 데이터에 손댄다
조기 종료   → 학습을 언제 멈출지에 손댄다

넷이 각자 다른 곳을 건드리니 동시에 적용해도 충돌하지 않는다
```

## 검토 결과

### 확인된 부분

- **"학습 때 보던 입력 범위와 추론 때가 달라 학습한 가중치가 그 범위에 맞지 않는다"** — 결과가 아니라 **원인**으로 설명했다. "성능이 나빠진다"에서 멈추지 않았다.
- **규칙과 예외를 함께** 정리했다 — 겹치지 않으면 함께 쓸 수 있고, 활성값에서 겹치면 충돌한다. 분류표를 단순 암기가 아니라 **판단 도구**로 썼다. 오늘 답변 중 가장 좋다.
- **드롭아웃의 정의**에서 "꺼진 뉴런은 그 스텝의 순전파·역전파에 관여하지 않는다"까지 짚었다.

### 심화: 공적응이 왜 "취약"한가

```text
훈련 중   : A가 항상 +3쯤 과하게 내보내고, B가 −3으로 보정 → 합이 맞다
새 데이터 : A의 출력이 +1로 달라짐
           → B는 여전히 −3으로 보정 → 합이 어긋난다 → 무너진다
```

**공적응은 과적합의 한 형태다.** 훈련 세트에서만 통하는 관계를 학습한 것이기 때문이다.

드롭아웃이 강제하는 것을 한 단어로 하면 **중복성(redundancy)** 이다. 각 뉴런이 혼자서도 쓸모 있어야 하니, 여러 뉴런이 비슷하게 유용한 특징을 나눠 갖게 된다.

> 💡 이것이 **"입력층에는 `p`를 작게 쓴다"** 와 이어진다. 은닉층의 특징은 중복성이 있어 몇 개 꺼도 나머지가 메워 주지만, **입력 픽셀은 중복성이 없어 끄면 정보가 그냥 사라진다.** 드롭아웃이 기댈 중복성이 없는 자리다.

| 위치 | 관례적인 `p` |
|---|---:|
| 은닉층 | **0.5** |
| 입력층 | 0.1 ~ 0.2 |
| 현대 트랜스포머 | **0.1** 내외 |

### 심화: 드롭아웃과 랜덤 포레스트 — 같은 원리, 다른 구현

| | 랜덤 포레스트 | 드롭아웃 |
|---|---|---|
| 모델 수 | 수백 개 (**실제로 만든다**) | **2ⁿ 개** (가중치를 공유하는 가상의 모델) |
| 비용 | 모델 수만큼 | **거의 공짜** |
| 다양성 확보 | 데이터·특징 샘플링 | **뉴런 샘플링** |

[[2026-08-18-ai-data-random-forest]]의 앙상블 원리를 **하나의 망 안에서 흉내 내는** 것이다. 여러 모델을 실제로 만들지 않고도 같은 효과를 얻는다는 점이 드롭아웃의 영리한 부분이다.

### 심화: 왜 배치 정규화와 충돌하는가

```text
배치 정규화 : 활성값의 평균·분산을 계산해 정규화한다
드롭아웃    : 활성값을 무작위로 0으로 만든다
                ↑
      드롭아웃이 배치 정규화가 재는 통계를 흔든다
      게다가 학습 때와 추론 때 그 통계가 달라진다
```

**"층위가 다르면 함께 쓸 수 있고, 겹치면 충돌할 수 있다"** — 이 틀은 조합 가능성뿐 아니라 **불가능성까지** 설명한다. 그래서 단순한 분류표가 아니라 **판단 도구**다.

### 심화: 드롭아웃의 오늘날 위치

2014년 이후 표준이었지만 지금은 쓰임이 줄었다.

| 이유 | 설명 |
|---|---|
| **배치 정규화와 충돌** | 위에서 본 이유 |
| **데이터가 많아졌다** | 과적합 압력 자체가 줄었다 |
| **다른 정규화가 강해졌다** | 데이터 증강, 잔차 연결, 가중치 감쇠 |

그럼에도 **트랜스포머에는 여전히 낮은 비율(0.1)로 들어간다.** 완전히 사라진 게 아니라 **강도가 낮아진 것**이다.

### 심화: 데이터 증강 — 반대편 해법

과적합의 근본 원인이 **"데이터에 비해 파라미터가 많다"** 라면 해법은 둘뿐이다.

```text
① 파라미터를 줄인다  → L1·L2, 드롭아웃, CNN의 가중치 공유
② 데이터를 늘린다     → 데이터 증강
```

**데이터 증강은 두 번째 길이다.** 이미지를 좌우 반전해도 고양이는 고양이이므로, **라벨을 유지하면서 입력만 바꾼** 새 훈련 예시를 공짜로 만든다.

> ⚠️ **어떤 변환을 쓸지는 도메인이 정한다.** 좌우 반전은 고양이 사진에는 안전하지만 **숫자 인식에는 위험하다** — 2를 뒤집으면 2가 아니다. **"라벨이 보존되는 변환인가"** 가 판단 기준이다.

### 이전 학습과의 연결

- [[2026-08-09-ai-data-regularization]] — **L1·L2는 가중치에** 작용하고 **드롭아웃은 뉴런에** 작용한다. 작용 지점이 다르므로 함께 쓸 수 있다. 그 노트에서 드롭아웃은 다루지 않았다.
- [[2026-08-18-ai-data-random-forest]] — **앙상블이 과적합을 줄인다**는 원리가 같다. 랜덤 포레스트는 모델을 실제로 여럿 만들고, 드롭아웃은 가중치를 공유해 흉내 낸다.
- [[2026-08-05-ai-data-bias-variance]] — 모든 정규화 기법이 **분산을 줄이고 편향을 약간 올리는** 거래다.
- [[2026-09-11-ai-data-cnn]] — **가중치 공유가 구조적 정규화**다. 또 이번 정리에서 **"항목을 이름만 나열하는" 패턴이 반복**된 지점이기도 하다.
- [[2026-09-10-ai-data-weight-initialization]] — 배치 정규화가 초기화 민감도를 낮추면서 **드롭아웃과는 충돌**한다. 같은 활성값 층위를 건드리기 때문이다.
- [[2026-08-31-backend-design-mint]] — **"자주 일어나는 쪽을 싸게 만든다"** 는 사고가 역 드롭아웃과 집계 테이블에 똑같이 적용된다.
- [[2026-08-31-ai-data-hyperparameter-tuning]] — `p`가 전형적인 튜닝 대상이다.
