## 핵심 개념

질문에 답하기 위해 필요한 핵심 개념을 정리한다.

### 1. 왜 필요한가 — 선형을 아무리 쌓아도 선형이다

신경망을 쓰는 이유는 **복잡한 비선형 함수를 학습**하기 위해서다. 그런데 활성화 함수가 없으면 그게 불가능하다.

```text
활성화 함수 없이 2층을 쌓으면

  1층:  h  = W₁x + b₁
  2층:  y  = W₂h + b₂
             = W₂(W₁x + b₁) + b₂
             = (W₂W₁)x + (W₂b₁ + b₂)
             =    W'x    +     b'        ← 그냥 1층짜리 선형 변환
```

**행렬 곱을 아무리 많이 이어 붙여도 결국 행렬 하나로 접힌다.** 100층을 쌓아도 표현력은 **1층 선형 회귀와 똑같다.** 층을 쌓느라 파라미터만 늘고 얻는 게 없다.

**비선형 활성화 함수를 층 사이에 끼워 넣어야 이 접힘이 깨진다.**

```text
  1층:  h = σ(W₁x + b₁)     ← σ가 비선형이라 밖으로 못 빠져나옴
  2층:  y = W₂h + b₂         → 더 이상 하나의 행렬로 접히지 않는다
```

> 🏫 **비유**: 자를 여러 개 이어 붙여 봐야 결국 **더 긴 직선 자**일 뿐이다. 곡선을 그리려면 자 사이사이에 **꺾쇠**를 넣어야 한다. 활성화 함수가 그 꺾쇠다.

**보편 근사 정리(Universal Approximation Theorem)**: 비선형 활성화 함수를 가진 은닉층 하나면, 충분한 뉴런 수로 **임의의 연속 함수를 원하는 정밀도로 근사**할 수 있다. 이 정리의 전제 조건이 바로 **비선형성**이다.

### 2. 시그모이드의 문제

```text
σ(x) = 1 / (1 + e⁻ˣ)        출력 범위: (0, 1)

  1 ┤        ╭─────────
    │      ╭─╯
0.5 ┤    ╭─╯
    │  ╭─╯
  0 ┤──╯
    └──┬────┬────┬──── x
      -6    0    6
```

#### 문제 ① 기울기 소실(Vanishing Gradient) — 가장 치명적

시그모이드의 도함수는 **최댓값이 0.25**다(`x=0`일 때). 그리고 입력이 크거나 작으면 **거의 0**이 된다 — 이걸 **포화(saturation)** 라고 한다.

```text
σ'(x) = σ(x)(1 − σ(x))

  x = 0   →  σ' = 0.25    ← 최댓값
  x = 4   →  σ' ≈ 0.018
  x = 8   →  σ' ≈ 0.0003
```

[[2026-08-27-ai-data-gradient-descent]]에서 배운 대로, 역전파는 **연쇄 법칙(chain rule)** 으로 층을 거슬러 올라가며 기울기를 **곱해 나간다.** 그런데 곱하는 값이 매번 1보다 작으면?

| 층 수 | 최상의 경우 기울기 배율 | 실제 값 |
|---:|---|---:|
| 1층 | 0.25 | 0.25 |
| 5층 | 0.25⁵ | 약 0.00098 |
| **10층** | **0.25¹⁰** | **약 0.00000095** |

**10층만 쌓아도 기울기가 백만분의 1로 줄어든다.** 앞쪽 층은 사실상 **학습이 멈춘다.** 이것이 딥러닝이 오랫동안 깊어지지 못했던 핵심 원인 중 하나다.

#### 문제 ② 출력이 0 중심(zero-centered)이 아니다

시그모이드 출력은 항상 **양수**(0~1)다. 그러면 다음 층으로 들어가는 입력이 전부 양수가 되고, **그 층 가중치들의 기울기 부호가 전부 같아진다.**

```text
모든 기울기가 같은 부호 → 모든 가중치가 같은 방향으로만 움직임
→ 최적점으로 대각선으로 못 가고 지그재그로 돌아간다 → 수렴이 느려진다
```

#### 문제 ③ 계산이 비싸다

`e⁻ˣ` 지수 연산이 들어간다. 뉴런 수억 개에 매 스텝 계산하면 무시 못 할 비용이다.

#### tanh는 절반의 해결

```text
tanh(x) 출력 범위: (−1, 1)      도함수 최댓값: 1.0
```

- ✅ **0 중심이다** → 문제 ②를 해결
- ✅ 도함수 최댓값이 **1.0**이라 시그모이드보다 낫다
- ❌ 여전히 양 끝에서 **포화**한다 → 문제 ①은 그대로

## 기준 답변

### 3. ReLU — 문제를 정면으로 없앤다

**ReLU(Rectified Linear Unit, 정류 선형 유닛)**

```text
f(x) = max(0, x)

    │      ╱
    │    ╱
    │  ╱
────┼╱────────  x
    │
   음수는 전부 0, 양수는 그대로
```

| 항목 | ReLU가 하는 일 |
|---|---|
| **기울기 소실 해결** | 양수 구간의 도함수가 **정확히 1**이다. 100층을 곱해도 `1¹⁰⁰ = 1` — 기울기가 줄지 않는다 |
| **계산이 싸다** | `max(0, x)` — **비교 하나**면 끝. 지수 연산이 없다 |
| **포화되지 않는다** | 양수 방향으로 **상한이 없다**(potentially infinite activation) |
| **희소 활성화** | 입력의 절반쯤이 0이 되어 **희소한(sparse)** 표현이 만들어진다. 계산이 줄고 정규화 효과도 있다 |

세 활성화 함수 비교:

| | 시그모이드 | tanh | **ReLU** |
|---|---|---|---|
| 출력 범위 | (0, 1) | (−1, 1) | [0, ∞) |
| 도함수 최댓값 | **0.25** | 1.0 | **1** (양수 구간) |
| 포화 | 양쪽 | 양쪽 | **없음**(양수 쪽) |
| 0 중심 | ❌ | ✅ | ❌ |
| 계산 비용 | 비쌈(exp) | 비쌈(exp) | **매우 쌈** |
| 기울기 소실 | **심각** | 있음 | **없음**(양수 쪽) |

### ReLU의 대가 — 죽은 ReLU(Dying ReLU)

ReLU도 공짜는 아니다. **음수 구간의 도함수는 0**이다.

```text
어떤 뉴런의 입력이 계속 음수라면
→ 출력이 항상 0
→ 기울기도 항상 0
→ 가중치가 영원히 갱신되지 않는다
→ 그 뉴런은 죽었다(dead)
```

학습률이 너무 크면 한 번의 큰 갱신으로 뉴런이 음수 영역에 처박혀 **되살아나지 못한다.** 네트워크 뉴런의 상당 비율이 죽으면 표현력이 통째로 줄어든다.

### 변형들 — 죽은 ReLU를 살리려는 시도

| 함수 | 정의 | 노림수 |
|---|---|---|
| **Leaky ReLU** | `max(0.01x, x)` | 음수 구간에 **작은 기울기**를 줘서 되살아날 여지를 남긴다 |
| **PReLU** | `max(ax, x)`, `a`를 **학습** | 기울기를 고정하지 않고 데이터에서 배운다 |
| **ELU** | 음수 구간을 지수 곡선으로 | 0 중심에 가깝고 부드럽다. 계산이 비싸다 |
| **GELU** | `x · Φ(x)` (Φ는 정규분포 누적함수) | 부드러운 ReLU. **BERT·GPT 계열 트랜스포머의 표준** |
| **Swish / SiLU** | `x · σ(x)` | GELU와 유사. 깊은 망에서 경험적으로 우수 |

> 💡 [[2026-08-06-ai-data-self-attention]]에서 다룬 트랜스포머 블록의 피드포워드 층에 쓰이는 것이 바로 **GELU**다. ReLU 계열의 "부드러운" 버전이라고 보면 된다.

### 출력층은 이야기가 다르다

지금까지는 **은닉층**의 활성화 함수 이야기다. **출력층은 과제가 요구하는 형태를 따른다.**

| 과제 | 출력층 활성화 | 이유 |
|---|---|---|
| 이진 분류 | **시그모이드** | 출력을 0~1 확률로 |
| 다중 분류 | **소프트맥스(Softmax)** | 합이 1인 확률 분포로 → [[2026-08-28-ai-data-temperature-sampling]] |
| 회귀 | **없음(선형)** | 값의 범위를 제한하면 안 되므로 |

**시그모이드는 은닉층에서 쫓겨났을 뿐, 출력층에서는 여전히 현역이다.** 출력층은 층이 하나뿐이라 기울기 소실이 누적되지 않기 때문이다.

## 내가 정리한 내용

### 1. 활성화 함수가 필요한 이유

활성화 함수가 없으면 **선형 행렬곱을 아무리 이어 붙여도 결국 선형 행렬 하나로 접혀**, 100층을 쌓아도 **표현력이 1층 선형 회귀와 같아진다.**

파라미터 개수는 100층이 압도적으로 많지만, 그 수백만 개가 결국 하나의 `W'`로 접혀 **도달할 수 있는 함수의 집합(function class)이 1층과 동일**하다. 더 많은 파라미터로 같은 곳에 도달하는 셈이라 순수한 낭비다.

**보편 근사 정리(Universal Approximation Theorem)** 가 "비선형 활성화 함수를 가진"이라는 단서를 다는 이유가 이것이다 — **비선형성이 정리의 전제 조건**이다.

### 2. 시그모이드의 문제 세 가지

**기울기 소실 / 출력이 0 중심이 아님 / 계산이 비쌈.**

**기울기 소실 문제가 제일 심각하다.**

- 나머지 문제는 **시간이 오래 걸릴 뿐 해결은 되지만**, 기울기 소실은 **기다려서는 해결이 안 되는 문제**다.
- 또 **깊이에 따라 지수적으로 나빠져 딥러닝을 깊게 만들 수 없게 만드는 문제**다.

| 문제 | 결과 | 성격 | 깊이와의 관계 |
|---|---|---|---|
| 계산 비쌈 | 학습이 몇 배 느려짐 | **정도**의 문제 | 선형 증가 |
| 0 중심 아님 | 수렴이 지그재그로 느려짐 | **정도**의 문제 | 거의 무관 |
| **기울기 소실** | 앞쪽 층이 **학습을 안 함** | **종류**의 문제 | **지수적 악화** |

시그모이드 도함수의 최댓값이 `0.25`이고, 역전파는 연쇄 법칙으로 층을 거슬러 올라가며 기울기를 **곱해 나간다.** 10층이면 `0.25¹⁰ ≈ 백만분의 1`.

### 3. ReLU가 해결한 것과 남긴 것

**해결**: 계산 비용 + 기울기 소실

| | 근거 |
|---|---|
| 기울기 소실 해결 | **양수 구간 도함수가 정확히 1** → 100층을 곱해도 `1¹⁰⁰ = 1`. 양수 방향으로 **상한이 없어 포화하지 않는다** |
| 계산이 싸다 | `max(0, x)` — **비교 하나**. 지수 연산 없음 |
| (덤) | 입력의 절반쯤이 0이 되어 **희소한(sparse) 표현**이 만들어진다 |

**남김**: 출력이 0 중심이 아닌 문제 + **죽은 ReLU(Dying ReLU)** 문제

**두 문제 모두 감수할 만하다고 판단됐다.**

- **0 중심** — 학습을 **막지 않고 느리게 할 뿐**이다(정도의 문제). 게다가 **배치 정규화(Batch Normalization)** 가 층 사이에서 출력 분포를 평균 0 근처로 되돌려 실무에서 보정한다.
- **죽은 ReLU** — **Leaky ReLU**(`max(0.01x, x)`), **PReLU**(기울기를 학습), **ELU** 같은 변형이 음수 구간에 작은 기울기를 줘서 되살아날 여지를 남긴다.

**막는 문제(기울기 소실)를 없애면서 느려지는 문제를 남긴 것은 명백히 남는 거래다.**

| 남은 문제 | 누가 대신 푸나 |
|---|---|
| 0 중심 아님 | **배치 정규화** (다른 층이 보정) |
| 죽은 ReLU | **Leaky ReLU / PReLU / ELU** (변형이 보완) |

## 검토 결과

### 확인된 부분

- **"표현력이 같아진다"** 를 정확히 짚었다. 파라미터 개수가 아니라 **표현력**이라고 구분한 것이 핵심이다. 100층의 파라미터가 더 많다는 사실에 흔들리지 않았다.
- **"정도의 문제 vs 종류의 문제"** 와 **"깊이에 지수적"** 두 축을 모두 세웠다. 세 문제를 나열만 하지 않고 **왜 이것만 유독 심각한가**에 답했다.
- **죽은 ReLU를 남은 문제로 함께 짚었다.** 설명에서 "대가"로 따로 다룬 내용을 정리에 스스로 포함시켰다.

### 보강 포인트

#### ① 남은 문제를 "왜 감수했는가"가 빠졌다

| | 내용 |
|---|---|
| **전** | 0 중심 문제와 Dying ReLU 문제는 남아 있음 |
| **후** | (동일) + **두 문제 모두 감수할 만하다고 판단됐다** — 0 중심은 배치 정규화가 보정하고, 죽은 ReLU는 변형들이 보완한다. **막는 문제를 없애면서 느려지는 문제를 남긴 것은 명백히 남는 거래다** |

Q2에서 세운 **"정도 vs 종류"** 축을 그대로 적용하면 답이 나온다. 기울기 소실은 **종류**의 문제였고 남긴 둘은 **정도**의 문제다. **더 나쁜 걸 없애고 덜 나쁜 걸 떠안았다.**

#### ② 첫 답변에서 변형의 목적을 혼동했다

| | 내용 |
|---|---|
| **전(첫 답변)** | 0 중심 문제를 남긴 이유는 **ReLU의 변형들로 어느 정도 해소가 가능하기 때문** |
| **후** | Leaky ReLU·PReLU가 노리는 것은 **0 중심이 아니라 죽은 ReLU** 문제다. 0 중심을 보정하는 것은 주로 **배치 정규화**다 |

```text
Leaky ReLU = max(0.01x, x)
노림수: 음수 구간 기울기를 0이 아니게 → 죽은 뉴런이 되살아날 여지
        (0 중심을 맞추려는 게 아님)
```

부수 효과로 출력이 약간 음수까지 내려가긴 하지만 **주목적이 아니다.** ELU 정도가 "0 중심에 가깝게"를 명시적으로 노린다.

### 심화: 세 문제를 두 축으로 가르기

시그모이드의 세 문제를 **"학습을 막는가"** 와 **"깊이에 따라 악화되는가"** 두 축으로 놓으면 왜 기울기 소실만 유독 심각한지가 선명해진다.

```text
계산 비용    : 층이 늘면 선형으로 증가   (10층 → 10배)
0 중심 아님  : 층과 거의 무관
기울기 소실  : 층이 늘면 지수로 악화     (10층 → 0.25¹⁰ = 백만분의 1)
                                          ↑ 이것만 깊이에 지수적
```

**앞의 둘은 "느려진다"이고, 기울기 소실은 "안 된다"다.** 느린 건 기다리면 되지만 안 되는 건 기다려도 안 된다.

그래서 이건 단순히 "느린 문제"가 아니라 **"딥러닝을 깊게 만들 수 없게 하는 문제"** 였다. 나머지 둘은 얕은 망에서도 깊은 망에서도 비슷하게 성가신 정도다.

### 심화: 모든 문제를 한 컴포넌트가 풀 필요는 없다

ReLU는 시그모이드의 문제를 **전부 해결하지 않았다.** 자기가 제일 잘 푸는 문제(기울기 소실)에 집중하고 나머지는 다른 컴포넌트에 넘겼다.

```text
기울기 소실   → ReLU 자신이 해결
0 중심 아님   → 배치 정규화에 넘김
죽은 ReLU     → 변형(Leaky/PReLU/ELU)에 넘김
```

**시스템 설계와 같은 사고다.** [[2026-09-02-backend-social-graph]]에서 위치 기반 샤딩("어디에 둘까")과 배치 조회("어떻게 가져올까")가 역할을 나눠 가졌던 것, [[2026-08-31-backend-design-mint]]에서 예산은 규칙으로 집계는 저장으로 각각 다른 방향의 트레이드오프를 택했던 것과 같은 구조다.

### 심화: 출력층은 다른 규칙을 따른다

지금까지는 **은닉층**의 활성화 함수 이야기다. **출력층은 과제가 요구하는 형태를 따른다.**

| 과제 | 출력층 활성화 | 이유 |
|---|---|---|
| 이진 분류 | **시그모이드** | 출력을 0~1 확률로 |
| 다중 분류 | **소프트맥스(Softmax)** | 합이 1인 확률 분포로 → [[2026-08-28-ai-data-temperature-sampling]] |
| 회귀 | **없음(선형)** | 값의 범위를 제한하면 안 되므로 |

**시그모이드는 은닉층에서 쫓겨났을 뿐 출력층에서는 현역이다.** 출력층은 층이 하나뿐이라 **기울기 소실이 누적되지 않기** 때문이다. "시그모이드는 나쁘다"가 아니라 **"깊이 쌓을 때 나쁘다"** 가 정확한 진술이다.

### 이전 학습과의 연결

- [[2026-08-27-ai-data-gradient-descent]] — 역전파가 **연쇄 법칙으로 기울기를 곱해 나간다**는 사실이 기울기 소실의 메커니즘 전부다. 그때 배운 학습률 문제도 **죽은 ReLU**의 원인으로 다시 등장한다(학습률이 크면 뉴런이 음수 영역에 처박힌다).
- [[2026-08-06-ai-data-self-attention]] — 트랜스포머 블록의 피드포워드 층에 쓰이는 **GELU**가 ReLU 계열의 부드러운 변형이다.
- [[2026-08-28-ai-data-temperature-sampling]] — 출력층의 **소프트맥스**가 확률 분포를 만드는 자리다. 온도 조절이 그 소프트맥스에 개입한다.
- [[2026-08-09-ai-data-regularization]] — **배치 정규화**는 정규화 계열 기법이면서 0 중심 문제를 보정하는 역할까지 겸한다.
- [[2026-09-01-ai-data-svm]] — SVM의 커널이 "저차원에서 선형 분리가 안 되는 문제"를 고차원 매핑으로 풀었다면, 신경망은 **비선형 활성화 함수를 층마다 끼워** 같은 문제를 푼다. **비선형성을 얻는 두 가지 다른 전략**이다.
- [[2026-08-05-ai-data-bias-variance]] — 활성화 함수가 없으면 표현력이 선형에 갇혀 **편향이 크게** 남는다.

### 오늘 나온 축약어

| 축약어 | 풀네임 | 설명 |
|---|---|---|
| ReLU | Rectified Linear Unit | 정류 선형 유닛 — `max(0, x)` |
| PReLU | Parametric ReLU | 음수 구간 기울기를 학습하는 ReLU |
| ELU | Exponential Linear Unit | 음수 구간이 지수 곡선인 활성화 함수 |
| GELU | Gaussian Error Linear Unit | 부드러운 ReLU — BERT·GPT 계열 표준 |
| SiLU | Sigmoid Linear Unit | Swish와 같은 함수 — `x · σ(x)` |
| tanh | Hyperbolic Tangent | 쌍곡탄젠트 — 0 중심 활성화 함수 |
| BN | Batch Normalization | 배치 정규화 |
