## 핵심 개념

질문에 답하기 위해 필요한 핵심 개념을 정리한다.

### 이름이 닮아 헷갈리지만, 근본이 다르다

**둘 다 이름에 `K`가 있고 거리를 쓰지만, 학습 유형 자체가 다르다.** → [[2026-07-28-ai-data-types-of-ml]]

| | **K-means** | **KNN (K-Nearest Neighbors)** |
|---|---|---|
| **학습 유형** | **비지도 학습** | **지도 학습** |
| **정답 레이블** | **없음** | **있음** |
| **목적** | **군집화(clustering)** — 데이터를 K개 그룹으로 묶음 | **분류·회귀** — 새 데이터의 값을 예측 |
| **K의 의미** | **군집의 개수** | **참조할 이웃의 개수** |
| **학습 단계** | 있음 (중심점을 반복 갱신) | **없음** (게으른 학습) |
| **출력** | 각 데이터가 속한 **군집 번호** | 새 데이터의 **예측 레이블/값** |

### K-means — 비지도 군집화

**데이터를 K개의 군집으로 나눈다.** 각 군집은 **중심점(centroid)** 으로 대표된다.

**동작**

```text
① K개의 중심점을 무작위로 초기화
② 각 데이터를 가장 가까운 중심점의 군집에 할당
③ 각 군집의 평균으로 중심점을 갱신
④ 중심점이 더 이상 변하지 않을 때까지 ②~③ 반복
```

- **"means"** 는 군집의 **평균**으로 중심점을 갱신하기 때문에 붙은 이름이다.
- **학습이 존재한다.** 중심점을 찾는 과정이 곧 학습이며, 학습이 끝나면 **중심점 K개만 남는다.**
- 새 데이터가 오면 **가장 가까운 중심점의 군집**으로 배정한다.

**특징과 한계**
- 초기 중심점에 따라 결과가 달라진다 → **K-means++** 같은 초기화 기법 사용
- **K를 사람이 정해야 한다** → 엘보우 방법, 실루엣 계수로 탐색
- 군집이 **구형(spherical)** 이고 크기가 비슷하다고 가정
- **이상치에 민감**하다(평균을 쓰므로)
- 스케일에 민감 → **특징 정규화 필요**

### KNN — 지도 학습, 게으른 학습

**새 데이터가 오면 가장 가까운 K개의 이웃을 보고 다수결(분류) 또는 평균(회귀)으로 예측한다.**

**동작**

```text
① 새 데이터와 모든 학습 데이터의 거리를 계산
② 가장 가까운 K개를 고른다
③ 분류: 다수결 / 회귀: 평균
```

- **게으른 학습(lazy learning)**: 학습 단계에서 하는 일이 **데이터를 저장하는 것뿐**이다. 실제 계산은 **예측 시점**에 일어난다.
- 그래서 **학습은 빠르고 예측이 느리다.** 일반적인 모델과 반대다.

**특징과 한계**
- **K를 사람이 정해야 한다.** 작으면 노이즈에 민감(과적합), 크면 경계가 뭉개짐(과소적합)
- 예측할 때마다 **전체 데이터와 거리 계산** → 데이터가 크면 매우 느림
- **차원의 저주**에 취약 — 차원이 높으면 거리 개념이 무의미해진다
- 스케일에 민감 → **특징 정규화 필요**
- **모델 파라미터가 없다**(비모수적, non-parametric)

### 공통점

- 둘 다 **거리 기반**이다(보통 유클리드 거리).
- 둘 다 **`K`를 사람이 정해야 한다**(하이퍼파라미터).
- 둘 다 **특징 정규화가 필수**다. 스케일이 다르면 거리 계산이 왜곡된다. → [[2026-08-09-ai-data-regularization]]
- 둘 다 **차원의 저주**에 취약하다.

### 핵심 한 줄

> **K-means의 K는 "몇 개로 나눌까", KNN의 K는 "몇 명에게 물어볼까".**
> **K-means는 그룹을 만들고, KNN은 답을 맞힌다.**

## 기준 답변

> ⚠️ 이 기준 레포는 질문 목록만 제공하고 답변은 싣지 않는다. 아래는 표준적인 ML 교재 기준으로 재구성한 답변이다.

**K-means와 KNN은 이름이 비슷하고 둘 다 거리를 사용하지만 근본적으로 다른 알고리즘**이다.

**K-means는 비지도 학습의 군집화 알고리즘**이다. 정답 레이블이 없는 데이터를 **K개의 군집으로 묶는 것**이 목적이며, 여기서 `K`는 **군집의 개수**다. K개의 중심점을 무작위로 초기화한 뒤, 각 데이터를 가장 가까운 중심점에 할당하고 군집의 평균으로 중심점을 갱신하는 과정을 수렴할 때까지 반복한다. 학습이 끝나면 **중심점 K개**가 모델로 남는다.

**KNN은 지도 학습의 분류·회귀 알고리즘**이다. 정답 레이블이 있는 데이터를 사용하며, 새 데이터가 오면 **가장 가까운 K개의 이웃**을 찾아 분류는 다수결, 회귀는 평균으로 예측한다. 여기서 `K`는 **참조할 이웃의 개수**다.

**KNN은 게으른 학습(lazy learning)** 이라는 점이 특징이다. 학습 단계에서 데이터를 저장하기만 하고 실제 계산은 예측 시점에 하므로, **학습은 빠르지만 예측이 느리다.** 반면 K-means는 학습 단계에서 중심점을 찾는 실제 계산을 수행한다.

**공통점**은 둘 다 거리 기반이라 **특징 정규화가 필수**이고, `K`를 사람이 정해야 하는 하이퍼파라미터이며, **차원의 저주**에 취약하다는 점이다.

정리하면 **K-means의 K는 "몇 개로 나눌까", KNN의 K는 "몇 명에게 물어볼까"** 이며, **K-means는 그룹을 만들고 KNN은 답을 맞힌다.**

## 내가 정리한 내용

**1. K-means와 KNN의 근본적 차이**

**K-means는 비지도 학습**(정답이 없는 학습 방법)이고, **KNN은 지도 학습**(정답이 있는 학습 방법)이다.

그래서 **목적이 다르다.** K-means는 데이터를 K개 그룹으로 묶는 **군집화**이고, KNN은 새 데이터의 값을 예측하는 **분류·회귀**다.

**학습 단계도 다르다.** K-means는 중심점을 반복 갱신하는 **학습이 존재**하며 끝나면 중심점 K개가 모델로 남는다. 반면 KNN은 데이터를 저장만 하는 **게으른 학습(lazy learning)** 이라 실제 계산이 예측 시점에 일어난다. 따라서 **학습은 빠르지만 예측이 느리다.**

**2. 각각의 K가 의미하는 것**

- **K-means의 K** = **군집의 개수.** 즉 "몇 개로 나눌지"
- **KNN의 K** = **참조할 이웃의 개수.** 즉 "비슷한 데이터 몇 개를 찾을지"

**3. 공통점**

- **거리 기반**의 방법 (보통 유클리드 거리)
- **K를 사람이 정한다** (하이퍼파라미터)
- **특징 정규화가 필수** — 스케일이 다르면 큰 특징이 거리를 독점한다
- **차원의 저주에 취약**하다

## 검토 결과

### 확인된 부분

- **지도/비지도라는 근본 축을 먼저 세움.** 두 알고리즘을 가르는 가장 중요한 기준을 정확히 짚었다.
- **공통점 네 가지를 빠짐없이** 정리. 특히 "특징 정규화 필수"와 "차원의 저주"까지 포함했다.
- 실습 Q1·Q2 모두 정확. 특히 Q2에서 "스케일이 큰 특징이 작은 특징을 지배한다"를 정확히 표현.

### 보강 포인트

- **Q1에 "목적"과 "학습 단계"를 더할 것.** 지도/비지도만으로는 "그래서 실제로 뭐가 다른가"에 답이 부족하다.
  - **목적**: K-means는 **그룹을 만들고**, KNN은 **답을 맞힌다.**
  - **학습 단계**: K-means는 학습이 있고, KNN은 **게으른 학습**이라 계산이 예측 시점에 일어난다.

### 심화: KNN의 속도 문제 — 이미 배운 해법 (Q1)

**모델 = 학습 데이터 전체**다. KNN은 데이터를 통째로 들고 있어야 하므로 **데이터가 늘면 모델도 그만큼 커진다.** 일반 모델은 데이터가 100배 늘어도 파라미터 수는 그대로다.

**대규모에서의 해법**

```text
전수 비교(brute force): O(N)  → 100만 개면 100만 번 거리 계산
근사 최근접 이웃(ANN):  훨씬 빠름 → HNSW 등
```

**ANN(Approximate Nearest Neighbor)** — 임베딩 학습 때 나온 그것. *"정확한 1등을 포기하고 아주 빠르게 거의 1등을 찾는다"*.

> ### **벡터 검색이 곧 대규모 KNN이다.**

**벡터 데이터베이스**(Pinecone, FAISS)가 하는 일이 정확히 **KNN의 속도 문제를 푸는 것**이다. 임베딩을 저장하고 "가장 가까운 K개"를 찾는 것이니까. **같은 알고리즘인데 이름이 달라 보였을 뿐이다.** → [[2026-08-03-ai-data-embeddings]]

KD-tree, Ball-tree도 같은 계열의 해법이다.

### 심화: 정규화 없이 KNN을 돌리면 (Q2)

```text
고객 A: 연봉 5,000만원, 나이 30세
고객 B: 연봉 6,000만원, 나이 40세

거리 = √( (10,000,000)² + (10)² )
     = √( 100,000,000,000,000 + 100 )
     ≈ 10,000,000
```

**나이 차이 10살이 기여한 것은 `100`이고 전체는 `100조`다.**

> **나이는 사실상 존재하지 않는 것과 같다.** KNN이 "연봉만 보는 모델"이 되며, 나이 컬럼을 지운 것과 결과가 거의 같다.

**정규화의 필요성은 같지만 방향이 다르다.**

| | 정규화 안 하면 |
|---|---|
| **L1/L2 정규화** | 스케일 작은 특징이 **부당하게 큰 벌점**을 받음 |
| **KNN·K-means** | 스케일 큰 특징이 **거리를 독점**함 |

**둘 다 "특징들을 같은 출발선에 세워야 한다"** 는 같은 요구다. → [[2026-08-09-ai-data-regularization]]

⚠️ **트리 계열과는 정반대**다. 트리는 분기가 한 특징 내부의 크기 비교라 스케일링이 불필요했다. → [[2026-08-13-ai-data-decision-tree]]

### K-means 상세

```text
① K개의 중심점을 무작위로 초기화
② 각 데이터를 가장 가까운 중심점의 군집에 할당
③ 각 군집의 평균으로 중심점을 갱신   ← "means"의 유래
④ 중심점이 더 이상 변하지 않을 때까지 ②~③ 반복
```

**한계**
- **초기 중심점에 따라 결과가 달라진다** → **K-means++** 같은 초기화 기법
- **K를 사람이 정해야 한다** → 엘보우 방법, 실루엣 계수로 탐색
- 군집이 **구형(spherical)** 이고 크기가 비슷하다고 가정
- **평균을 쓰므로 이상치에 민감**

### KNN 상세

```text
① 새 데이터와 모든 학습 데이터의 거리를 계산
② 가장 가까운 K개를 고른다
③ 분류: 다수결 / 회귀: 평균
```

**일반 모델과 반대의 성능 특성**

```text
일반 모델:  학습 느림 → 예측 빠름
KNN:       학습 빠름 → 예측 느림   ← 매번 전체 데이터와 거리 계산
```

**K 선택의 트레이드오프**: 작으면 노이즈에 민감(과적합), 크면 경계가 뭉개짐(과소적합). → [[2026-08-05-ai-data-bias-variance]]

**비모수적(non-parametric)** — 학습되는 모델 파라미터가 없다.

### 핵심 한 줄

> **K-means의 K는 "몇 개로 나눌까", KNN의 K는 "몇 명에게 물어볼까".**
> **K-means는 그룹을 만들고, KNN은 답을 맞힌다.**
