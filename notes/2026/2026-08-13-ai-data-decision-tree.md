## 질문

> **결정 트리란 무엇이며 어떻게 동작하는가?**
>
> 원문: *What is a decision tree and how does it work?*

## 핵심 개념

질문에 답하기 위해 필요한 핵심 개념을 정리한다.

### 정의

**데이터를 특징 기준으로 반복해서 나누며, 스무고개처럼 질문을 이어가 예측하는 모델.**

```text
              [나이 < 30?]
             예 ↙      ↘ 아니오
      [소득 < 3천?]      [구매이력 있음?]
      ↙       ↘          ↙        ↘
   이탈    유지        유지      이탈
```

- **내부 노드** = 특징에 대한 질문(분기 조건)
- **가지(branch)** = 질문의 답
- **리프(leaf)** = 최종 예측값

### 어떻게 학습하나 — 탐욕적 분할

```text
① 현재 노드의 데이터를 가장 잘 나누는 (특징, 기준값) 쌍을 찾는다
② 그 기준으로 데이터를 둘로 나눈다
③ 각 자식 노드에 대해 ①~②를 재귀적으로 반복
④ 정지 조건에 도달하면 리프로 만들고 예측값을 정한다
```

- **탐욕적(greedy)**: 매 단계에서 **당장 가장 좋은 분할**을 고른다. 전체 최적을 보장하지는 않는다.

### "가장 잘 나눈다"의 기준 — 불순도(impurity)

분할 후 각 노드가 **한 클래스로 순수해질수록** 좋은 분할이다.

| 기준 | 용도 | 설명 |
|---|---|---|
| **지니 불순도(Gini impurity)** | 분류 | 무작위로 뽑은 두 샘플의 클래스가 다를 확률. CART 기본값 |
| **엔트로피 / 정보 이득** | 분류 | 불확실성의 감소량이 큰 분할을 선택 |
| **분산 감소 / MSE** | 회귀 | 분할 후 각 노드의 분산이 작아지도록 |

**정보 이득(Information Gain)** = 부모의 불순도 − 자식들의 가중 평균 불순도. **이 값이 가장 큰 분할**을 고른다.

### 정지 조건과 가지치기(Pruning)

트리를 끝까지 키우면 **리프마다 샘플이 하나씩** 남아 학습 데이터를 완벽히 외운다 → **과적합** → [[2026-08-05-ai-data-bias-variance]]

**사전 가지치기(pre-pruning)** — 자라는 것을 미리 막는다
- `max_depth`(최대 깊이), `min_samples_split`(분할 최소 샘플 수), `min_samples_leaf`(리프 최소 샘플 수), `max_leaf_nodes`

**사후 가지치기(post-pruning)** — 다 키운 뒤 가지를 쳐낸다
- 검증 성능이 개선되지 않는 가지를 제거(cost-complexity pruning 등)

> **가지치기는 결정 트리의 정규화다.** 복잡도를 억제해 분산을 줄인다. → [[2026-08-09-ai-data-regularization]]

### 장점

- **해석이 매우 쉽다.** 규칙을 그대로 사람 언어로 읽을 수 있다(화이트박스).
- **특징 스케일링이 불필요**하다. 분기 기준이 "값의 크기 비교"라 단위와 무관.
- **수치형·범주형을 모두** 다룬다.
- **비선형 관계와 특징 간 상호작용**을 자연스럽게 포착한다.
- **특징 선택이 암묵적으로** 일어난다. 유용한 특징만 분기에 쓰인다. → [[2026-08-12-ai-data-feature-selection]]
- **결측치 처리**가 상대적으로 수월하다(구현에 따라 네이티브 지원). → [[2026-08-10-ai-data-missing-data]]

### 단점

- **과적합되기 쉽다.** 제약 없이 키우면 학습 데이터를 그대로 외운다.
- **불안정하다(high variance).** 데이터가 조금만 바뀌어도 트리 구조가 크게 달라진다.
- **축에 수직인 경계만** 만든다. 대각선 형태의 결정 경계를 계단으로 근사해야 한다.
- **탐욕적 분할**이라 전역 최적 트리를 보장하지 않는다.
- **불균형 데이터에 편향**될 수 있다.

### 그래서 앙상블로 간다

단일 트리는 **분산이 크다**는 결정적 약점이 있다. 이를 해결하는 것이 앙상블이다.

- **배깅 / 랜덤 포레스트**: 여러 트리를 독립적으로 학습해 **평균** → **분산 감소**
- **부스팅 / GBDT**: 트리를 순차적으로 학습해 **이전 트리의 오차를 보정** → **편향 감소**

> **결정 트리 자체보다, 결정 트리를 재료로 쓰는 앙상블이 실무의 주력이다.** XGBoost·LightGBM·CatBoost가 모두 여기에 속한다.

## 기준 답변

> ⚠️ 이 기준 레포는 질문 목록만 제공하고 답변은 싣지 않는다. 아래는 표준적인 ML 교재 기준으로 재구성한 답변이다.

**결정 트리는 데이터를 특징 기준으로 반복해서 분할하며 예측하는 모델**이다. 내부 노드는 특징에 대한 질문이고, 가지는 그 답이며, 리프는 최종 예측값이다. 스무고개처럼 질문을 이어가 답에 도달한다.

**학습은 탐욕적 분할로 이루어진다.** 현재 노드의 데이터를 가장 잘 나누는 (특징, 기준값) 쌍을 찾아 둘로 나누고, 각 자식에 대해 재귀적으로 반복한다. "가장 잘 나눈다"의 기준은 **불순도**로, 분류에서는 **지니 불순도**나 **엔트로피(정보 이득)**, 회귀에서는 **분산 감소**를 사용한다. 부모의 불순도에서 자식들의 가중 평균 불순도를 뺀 **정보 이득이 가장 큰 분할**을 고른다.

트리를 제약 없이 키우면 리프마다 샘플이 하나씩 남아 **과적합**되므로, `max_depth`나 `min_samples_leaf` 같은 **사전 가지치기**나, 다 키운 뒤 가지를 쳐내는 **사후 가지치기**로 복잡도를 억제한다.

**장점**은 해석이 매우 쉽고(화이트박스), 특징 스케일링이 불필요하며, 수치형·범주형을 모두 다루고, 비선형 관계와 상호작용을 자연스럽게 포착한다는 점이다.

**단점**은 과적합되기 쉽고 **분산이 크다**는 것이다. 데이터가 조금만 바뀌어도 트리 구조가 크게 달라진다. 또한 축에 수직인 경계만 만들 수 있고, 탐욕적 분할이라 전역 최적을 보장하지 않는다.

이 약점 때문에 실무에서는 단일 트리보다 **앙상블**을 쓴다. **랜덤 포레스트**는 여러 트리를 평균 내 분산을 줄이고, **GBDT** 계열은 트리를 순차적으로 학습해 편향을 줄인다.

## 내가 정리한 내용

**1. 결정 트리란? 어떻게 학습하는가**

스무고개 같은 구조로 **조건을 통해 데이터를 트리 형태로 분할**하는 모델이다. 내부 노드는 특징에 대한 질문, 가지는 그 답, 리프는 최종 예측값이다.

학습은 **데이터를 가장 잘 나누는 (특징, 기준값)을 찾는 작업을 정지 조건에 도달할 때까지 재귀적으로 반복**한다. 이때 "가장 잘 나눈다"는 분할 후 각 노드가 **순수해지는 것**을 뜻하며, **불순도**로 측정한다. 분류에서는 **지니 불순도**나 **엔트로피(정보 이득)**, 회귀에서는 **분산 감소**를 쓴다. 매 단계 당장 가장 좋은 분할을 고르는 **탐욕적(greedy)** 방식이다.

**2. 장점**

- 모델 결과에 대한 **해석이 비교적 쉬움**(화이트박스)
- 분기가 **크기 비교**라 **스케일링이 불필요**함
- **수치형·범주형 모두** 학습 가능
- 선형 모델이 하지 못하는 **비선형 관계와 상호작용** 포착 가능
- **암묵적 특징 선택** 가능

**3. 단점과 해결책**

- **과적합되기 쉽다.** 제약 없이 키우면 리프마다 샘플이 하나씩 남아 학습 데이터를 외운다.
- **분산이 커** 데이터가 조금만 바뀌어도 트리 구조가 확 달라진다.
- **탐욕적 구조**라 전역 최적을 보장하지 못한다.
- 축에 수직인 경계만 만들 수 있다.

**해결책**

- **가지치기(pruning)** — `max_depth`, `min_samples_leaf` 같은 **사전 가지치기**와, 다 키운 뒤 쳐내는 **사후 가지치기**로 복잡도를 억제한다. 결정 트리의 정규화에 해당한다.
- **앙상블** — **배깅(랜덤 포레스트)은 여러 트리를 평균 내 분산을 줄이고**, **부스팅(GBDT)은 트리를 순차 학습해 이전 오차를 보정하며 편향을 줄인다.** XGBoost·LightGBM·CatBoost가 후자에 속한다.

## 검토 결과

### 확인된 부분

- **장점 5가지를 빠짐없이 정리함.** 특히 "분기가 크기 비교라 스케일링 불필요"를 정확히 짚었다.
- 단점을 과적합·분산·탐욕적 구조로 정확히 구분.
- 실습 Q2에서 **분산 감소 = 앙상블 평균**을 정확히 연결. → [[2026-08-05-ai-data-bias-variance]]

### 보강 포인트

- **"가장 잘 나눈다"의 정의(불순도)가 초기 답변에서 누락 → 추가.** 면접관이 반드시 되묻는 지점이다.
- **해결책이 앙상블로 바로 건너뛰었다 → 가지치기를 먼저.** 단일 트리 차원의 처방이 앙상블보다 앞선다.
- **앙상블은 하나가 둘 다 하는 게 아니다.** **배깅 → 분산 감소 / 부스팅 → 편향 감소**로 방식이 다르다.

### 심화: 왜 트리는 스케일링이 필요 없나 (Q1)

| | 선형 모델 | 결정 트리 |
|---|---|---|
| 특징을 다루는 방식 | **여러 특징을 합산·비교** (`w₁x₁ + w₂x₂ ...`) | **한 번에 하나씩** 독립적으로 |
| 스케일이 왜 문제 | 계수와 벌점이 **특징 간 비교**를 전제 | **비교 자체가 없음** |

> **트리의 분기는 "이 특징이 3천보다 큰가?"다. 다른 특징이 뭔지, 단위가 뭔지는 아예 보지 않는다.**

`소득 > 3000만`과 `나이 > 30`은 **서로 무관하게** 판단된다. 8/9에 배운 *"스케일이 작은 특징이 부당하게 큰 벌점을 받는다"* 는 문제가 **애초에 발생할 구조가 아니다.** → [[2026-08-09-ai-data-regularization]]

**같은 이유로 단조 변환에도 불변이다.** 소득에 `log`를 씌워도 대소 관계가 그대로라 **트리 구조가 바뀌지 않는다.** 선형 모델이라면 완전히 다른 결과가 나온다.

### 심화: 왜 평균이 분산을 줄이나 — 그리고 랜덤 포레스트의 발명 (Q2)

> **독립적인 `n`개의 추정치를 평균 내면 분산이 `1/n`로 줄어든다.**

트리 100개를 평균 내면 이론상 분산이 1/100이 된다. **그런데 함정이 있다.**

⚠️ **같은 데이터로 같은 알고리즘을 돌리면 100번 돌려도 똑같은 트리가 나온다.** 평균을 내봐야 그대로다.

> **"독립적인"이 조건이다. 트리들이 서로 달라야 평균의 효과가 난다.**

**그래서 랜덤 포레스트는 일부러 트리를 다르게 만든다.**

| 기법 | 방법 |
|---|---|
| **부트스트랩 샘플링(배깅)** | 각 트리를 **데이터의 다른 부분집합**으로 학습 |
| **특징 무작위 선택** | 분기할 때마다 **특징 일부만** 후보로 |

**두 번째가 랜덤 포레스트의 진짜 발명이다.** 배깅만 하면 강한 특징 하나가 모든 트리의 최상단을 차지해 **트리들이 여전히 닮게 된다.** 특징을 무작위로 제한하면 **강제로 다양해진다.**

> **"평균을 내려면 먼저 달라야 한다"** — 랜덤 포레스트의 설계 철학.

### 불순도 기준

| 기준 | 용도 | 설명 |
|---|---|---|
| **지니 불순도** | 분류 | 무작위로 뽑은 두 샘플의 클래스가 다를 확률. CART 기본값 |
| **엔트로피 / 정보 이득** | 분류 | 불확실성의 감소량이 큰 분할을 선택 |
| **분산 감소 / MSE** | 회귀 | 분할 후 각 노드의 분산이 작아지도록 |

**정보 이득** = 부모의 불순도 − 자식들의 가중 평균 불순도. **이 값이 최대인 분할**을 고른다.

```text
나쁜 분할: [이탈5, 유지5] → [이탈3,유지2] + [이탈2,유지3]   여전히 섞임
좋은 분할: [이탈5, 유지5] → [이탈5,유지0] + [이탈0,유지5]   완벽히 분리 ✅
```

### 이전 학습과의 연결

- **가지치기 = 트리의 정규화.** L1/L2와 목적이 같다 — 복잡도를 억제해 분산을 줄인다. → [[2026-08-09-ai-data-regularization]]
- **단일 트리의 높은 분산**이 편향-분산 트레이드오프의 교과서적 사례. → [[2026-08-05-ai-data-bias-variance]]
- **암묵적 특징 선택** — 트리는 유용한 특징만 분기에 쓰므로, L1처럼 명시적 선택을 하지 않아도 된다. → [[2026-08-12-ai-data-feature-selection]]
- **결측치 네이티브 처리** — XGBoost 계열이 분기 방향을 학습으로 결정하는 것이 여기서 출발한다. → [[2026-08-10-ai-data-missing-data]]
- **XGBoost의 `reg_lambda`·`max_depth`가 곧 정규화**라는 8/5의 논의가 트리 구조를 알고 나면 더 명확해진다.

### 오늘 나온 축약어

| 축약어 | 풀네임 |
|---|---|
| CART | Classification And Regression Tree |
| MSE | Mean Squared Error |
| GBDT | Gradient Boosted Decision Trees |
