## 핵심 개념

질문에 답하기 위해 필요한 핵심 개념을 정리한다.

### 문제 설정 — 밑바닥부터 배우기엔 너무 비싸다

```text
ImageNet으로 CNN을 처음부터 학습하려면
  데이터 : 약 1,400만 장 (1,000 클래스)
  연산   : GPU 여러 대로 수일
```

그런데 **실무 문제는 대개 데이터가 수백~수천 장**이다. 흉부 X선 판독기를 만드는데 이미지가 800장뿐인 식이다.

[[2026-09-16-ai-data-dropout]]에서 본 대로 **데이터보다 파라미터가 많으면 모델은 외운다.** 800장으로 2,500만 파라미터짜리 ResNet을 처음부터 학습하면 확실히 과적합한다.

**전이학습은 "이미 배운 것을 가져다 쓰자"는 해법이다.**

### 형식적 정의

기준 레포(`alexeygrigorev`)의 정의를 그대로 옮기면:

> 소스 도메인 `D_S`와 학습 과제 `T_S`, 타깃 도메인 `D_T`와 학습 과제 `T_T`가 주어졌을 때, 전이학습은 **`D_S`와 `T_S`의 지식을 이용해 `D_T`에서 타깃 예측 함수 `f_T`의 학습을 개선하는 것**을 목표로 한다. 단 `D_S ≠ D_T` 이거나 `T_S ≠ T_T` 이다.

**마지막 조건이 핵심이다.** 도메인이 다르거나 **과제가 다르거나**, 둘 중 하나는 달라야 전이학습이다. 완전히 같으면 그냥 이어서 학습하는 것일 뿐이다.

| 경우 | 예시 |
|---|---|
| **도메인이 다르다** (`D_S ≠ D_T`) | 일반 사진 → 흉부 X선 사진 |
| **과제가 다르다** (`T_S ≠ T_T`) | 1,000종 분류 → 종양 유무 판정 |

### 왜 되는가 — CNN의 계층적 특징이 근거다

[[2026-09-11-ai-data-cnn]]에서 본 계층 구조가 그대로 답이 된다.

| 층 깊이 | 학습되는 특징 | 다른 과제에도 쓸모 있나 |
|---|---|---|
| **얕은 층** | 엣지, 색 변화, 밝기 대비 | **매우 그렇다** — 어떤 이미지에나 엣지는 있다 |
| **중간 층** | 모서리, 질감, 단순한 도형 | **대체로 그렇다** |
| **깊은 층** | 눈, 귀, 바퀴 같은 물체의 부분 | 과제에 따라 다르다 |
| **마지막 층** | "이건 골든리트리버다" | **거의 아니다** — 소스 과제 전용 |

```text
앞쪽 = 범용(general)  ←─────────────────→  뒤쪽 = 특화(specific)
```

**엣지 검출기는 고양이 사진에서 배우든 X선에서 배우든 똑같다.** 그래서 앞쪽 층은 그대로 가져다 쓰고, **뒤쪽만 새 과제에 맞춰 바꾸면** 된다.

> 💡 이것이 전이학습이 **CNN에서 특히 잘 통하는 이유**다. 계층적 특징이라는 구조 자체가 "재사용 가능한 부분"과 "과제 전용 부분"을 자연스럽게 분리해 준다.

### 두 가지 방법

#### ① 특징 추출(Feature Extraction) — 얼리고 머리만 갈아 끼운다

```text
사전학습 모델
┌──────────────────────────┬────────┐
│   합성곱 층들 (동결)       │ 분류기  │  ← 이 부분만 떼어내고
└──────────────────────────┴────────┘
┌──────────────────────────┬────────┐
│   합성곱 층들 (동결)       │ 새 분류기│ ← 새로 붙여 이것만 학습
└──────────────────────────┴────────┘
        가중치 고정              학습
```

- 사전학습 가중치를 **동결(freeze)** 하고 **마지막 분류층만 새로 만들어 학습**한다
- 사실상 **사전학습 모델을 "특징 추출기"로 쓰는 것**이다
- **학습할 파라미터가 아주 적어** 데이터가 적어도 과적합하지 않는다
- 빠르다 — 역전파가 마지막 층까지만 흐른다 → [[2026-09-04-ai-data-backpropagation]]

#### ② 파인튜닝(Fine-tuning) — 가져온 것도 조금씩 고친다

- 사전학습 가중치를 **초기값으로 삼고**, 일부 또는 전체 층을 **다시 학습**한다
- **반드시 낮은 학습률**을 쓴다(보통 처음부터 학습할 때의 `1/10` ~ `1/100`)
- 보통 **뒤쪽 층부터 풀어 준다**(앞쪽은 범용이라 건드릴 이유가 적다)

> ⚠️ **왜 학습률을 낮추는가?** 사전학습 가중치는 **이미 좋은 지점**에 있다. 큰 보폭으로 움직이면 애써 배운 것을 **뭉개 버린다** — 이를 **파괴적 망각(catastrophic forgetting)** 이라고 한다. [[2026-08-27-ai-data-gradient-descent]]에서 배운 학습률 문제가 여기서 다른 얼굴로 나타난다.

## 기준 답변

### 어느 쪽을 언제 쓰나 — 두 축으로 판단한다

**데이터 양**과 **도메인 유사도** 두 축으로 갈린다.

| | **소스와 비슷한 도메인** | **소스와 다른 도메인** |
|---|---|---|
| **데이터가 적다** | **특징 추출**<br>(마지막 층만 학습) | **가장 어려운 경우**<br>중간 층까지만 쓰고 그 위를 학습 |
| **데이터가 많다** | **파인튜닝**<br>(뒤쪽 여러 층을 낮은 LR로) | **전체 파인튜닝** 또는<br>처음부터 학습도 고려 |

**판단의 두 원칙**

```text
데이터가 적을수록  →  학습할 파라미터를 적게  (과적합 방지)
도메인이 다를수록  →  가져다 쓸 층을 앞쪽으로 (뒤쪽은 소스 전용이라 쓸모없음)
```

> 💡 **"데이터가 적고 도메인도 다른" 경우가 왜 제일 어려운가?** 두 원칙이 **서로 반대 방향을 가리키기** 때문이다. 도메인이 다르니 뒤쪽 층을 새로 학습해야 하는데, 데이터가 적어 많이 학습시킬 수 없다. 이때는 **데이터 증강**이나 **더 비슷한 소스 모델 찾기**로 우회한다.

### 전이학습의 실무적 가치

| 항목 | 처음부터 학습 | 전이학습 |
|---|---|---|
| 필요 데이터 | 수십만~수백만 | **수백~수천** |
| 학습 시간 | 수일 | **수분~수시간** |
| 필요 장비 | GPU 클러스터 | **GPU 1대, 때로는 CPU** |
| 도달 성능 | 데이터가 충분하면 최고 | **적은 데이터에서는 압도적 우위** |

**오늘날 컴퓨터 비전에서 처음부터 학습하는 경우는 드물다.** ImageNet 사전학습 모델에서 시작하는 것이 기본값이다.

### LLM에서의 전이학습 — 사실 이게 표준 패러다임이다

**대규모 언어 모델 전체가 전이학습 구조 위에 서 있다.**

```text
사전학습(Pre-training)      : 인터넷 규모 텍스트로 "언어 일반"을 배운다   ← 소스 과제
     ↓
파인튜닝(Fine-tuning)       : 특정 과제·도메인에 맞춘다                  ← 타깃 과제
     ↓
지시 튜닝 / 정렬(SFT, RLHF)  : 지시를 따르도록 만든다
```

| 기법 | 내용 |
|---|---|
| **전체 파인튜닝** | 모든 파라미터를 갱신. 비싸고 메모리를 많이 쓴다 |
| **PEFT / LoRA** | **일부 작은 행렬만** 학습하고 원래 가중치는 동결 → 특징 추출의 LLM 버전 |
| **프롬프트 엔지니어링** | 가중치를 아예 안 바꾸고 입력만 조정 → 가장 가벼운 형태 |

> 💡 **[[2026-09-08-ai-data-model-distillation]]과의 차이**를 구분해 두면 좋다.
>
> | | 전이학습 | 증류 |
> |---|---|---|
> | 무엇을 물려받나 | **가중치** | **출력 분포(행동)** |
> | 학생 모델 크기 | 보통 교사와 같다 | **더 작다** |
> | 목적 | **새 과제 적응** | **압축** |

### 왜 이게 "데이터를 대신하는 지식"인가

[[2026-09-11-ai-data-cnn]]에서 **귀납적 편향은 데이터를 대신하는 지식**이라고 정리했다. 전이학습도 같은 구조다.

```text
CNN의 귀납적 편향 : 사람이 "지역성·평행이동 등변성"을 구조에 넣어 줌
전이학습          : 다른 데이터에서 배운 가중치를 초기값으로 넣어 줌
                     ↑
        둘 다 "타깃 데이터가 부족한 자리를 외부 지식으로 메우는" 일
```

[[2026-09-10-ai-data-weight-initialization]]의 관점에서 보면 더 선명하다. **전이학습은 결국 초기화 전략이다.** 무작위 초기값(He·Xavier) 대신 **이미 유용한 특징을 담고 있는 값**에서 출발하는 것이다.

## 내가 정리한 내용

### 1. 전이학습이 무엇이고 왜 필요한가

- **처음부터 학습은 너무 비싸고**, 실무에서 보유한 데이터 수는 보통 적다. 이때 전이학습을 사용한다.
- 전이학습은 **사전학습된 모델을 기반으로 일부 또는 전체를 추가 학습하는 것**이다.
- **도메인이 다르거나 과제가 달라야 한다** (`D_S ≠ D_T` 또는 `T_S ≠ T_T`). 둘 다 같으면 그냥 이어서 학습하는 것일 뿐이다.

### 2. 왜 되는가 — 어느 층을 가져다 쓰나

- **범용적인 것들을 담당하는 앞쪽 층은 그대로 두고, 특화된 것들을 담당하는 뒤쪽만 갈아끼운다.**
- 기준은 **"얼마나 과제 독립적인가"** 다. 앞쪽이 범용인 이유는 **어떤 이미지에나 엣지와 색 변화가 존재하기 때문**이고, "골든리트리버의 귀 모양"은 개 사진에만 있다.
- 범용↔특화는 **스위치가 아니라 기울기**다.

```text
앞쪽 ──────────────────────────────────▶ 뒤쪽
범용                                    특화
100% 재사용                             0% 재사용
       ↑ 여기서 자를지는 정해져 있지 않다
```

**"어디서 자를 것인가"가 결정 사항**이고, 그 지점을 정하는 것이 아래 3번의 판단 표다.

### 3. 두 가지 방법과 언제 쓰나

- **특징 추출(Feature Extraction)** — 사전학습 가중치를 **동결(freeze)** 하고 **마지막 분류층만 새로 만들어 학습**한다. 학습할 파라미터가 적어 **데이터가 적어도 과적합하지 않는다.** 사실상 사전학습 모델을 "특징 추출기"로 쓰는 것이다.
- **파인튜닝(Fine-tuning)** — 사전학습 가중치를 **초기값으로 삼고** 일부 또는 전체 층을 **다시 학습**한다. 보통 뒤쪽 층부터 풀어 주며 **낮은 학습률**을 쓴다.

**두 축을 곱해서 판단한다.**

| | **비슷한 도메인** | **다른 도메인** |
|---|---|---|
| **데이터 적음** | 특징 추출 | **가장 어려운 경우** |
| **데이터 많음** | 파인튜닝 | 전체 파인튜닝 또는 처음부터 |

```text
데이터 양     →  학습할 파라미터를 얼마나 둘 수 있나
도메인 유사도 →  어느 층까지 가져다 쓸 수 있나

곱해야 답이 나온다. 더하면 안 된다.
```

**두 축을 OR로 묶으면 안 된다.** "도메인이 다르면 파인튜닝"이라고 하면, 데이터가 적으면서 도메인이 다른 칸 — **어느 쪽도 잘 안 되는 칸** — 이 사라져 버린다.

### 4. 낮은 학습률을 쓰는 이유

- 이미 사전학습된 모델의 가중치는 **좋은 지점**에 있어, 높은 학습률을 쓰면 **애써 배운 것을 뭉개 버린다.** 이를 **파괴적 망각(catastrophic forgetting)** 이라고 한다.
- **가장 위험한 순간은 첫 몇 스텝**이다. 새로 붙인 분류층은 무작위 초기화라 손실이 크고, **그 큰 기울기가 역전파로 사전학습 층까지 흘러가** 첫 스텝에 특징을 뭉갠다.

| 실무 장치 | 내용 |
|---|---|
| **2단계 학습** | 사전학습 층을 **동결한 채 새 분류층만 먼저** 학습 → 안정된 뒤 풀어서 함께 파인튜닝 |
| **점진적 해동(Gradual Unfreezing)** | 뒤쪽 층부터 **한 층씩 차례로** 풀어 준다 |
| **층별 학습률 차등(Discriminative LR)** | **앞쪽 층일수록 더 낮은 학습률** |

**특징 추출과 파인튜닝은 "둘 중 하나 고르기"가 아니라 순서대로 하는 것**이기도 하다.

## 검토 결과

### 확인된 부분

- **정의의 조건을 빼먹지 않았다** — `D_S ≠ D_T` 또는 `T_S ≠ T_T`. 이 조건이 "그냥 이어서 학습하는 것"과 전이학습을 가르는 경계다.
- **필요성 → 정의 → 조건** 순으로 세 층을 다 담았다.
- **파괴적 망각**을 정확히 짚었다.

### 보강 포인트

#### ① 각 방법이 "무엇인지"가 없었다 — **세 번째 반복**

| | 내용 |
|---|---|
| **전** | 데이터가 적을 때 **특징 추출**, 많거나 도메인이 다르면 **파인튜닝** |
| **후** | 각 방법이 **무엇을 하는지** 한 줄씩 (위 `내가 정리한 내용` 3번) |

"언제 쓰나"만 있고 **"무엇인가"가 없었다.**

> ⚠️ **같은 패턴이 세 번 반복됐다.**
>
> | 날짜 | 어디서 |
> |---|---|
> | [[2026-09-11-ai-data-cnn]] | CNN의 두 핵심 아이디어 |
> | [[2026-09-16-ai-data-dropout]] | 드롭아웃의 세 관점 |
> | 2026-09-17 (오늘) | 특징 추출 / 파인튜닝 |
>
> 오늘은 **질문에 "각각 한 줄씩 붙여 주세요"라고 미리 적었는데도** 같은 형태가 나왔다. 습관이 굳어 있다는 뜻이다.
>
> **규칙으로 삼을 것: "항목을 적으면 바로 뒤에 그게 무엇인지 한 줄."**
> 면접에서 "특징 추출과 파인튜닝이 있습니다"까지만 말하고 멈추면 **설명을 못 하는 것으로 들린다.**

#### ② 2×2 표가 OR로 납작해졌다

| | 내용 |
|---|---|
| **전** | 데이터가 많**거나** 도메인이 다른 경우 파인튜닝 |
| **후** | **두 축을 곱해서** 판단한다 |

**두 축은 각각 다른 것을 말한다.** 데이터 양은 "학습할 파라미터를 얼마나 둘 수 있나", 도메인 유사도는 "어느 층까지 가져다 쓸 수 있나"를 정한다. OR로 묶으면 **가장 어려운 칸이 사라진다.**

#### ③ 재사용 기준이 명시되지 않았다

"범용/특화"는 **결과**고, **"얼마나 과제 독립적인가"** 가 기준이다. 교정 후 내용은 위 `내가 정리한 내용` 2번에 반영.

#### ④ 파괴적 망각이 "언제" 가장 위험한지가 빠졌다

**첫 몇 스텝**이라는 답과 그에 따른 세 가지 실무 장치. 교정 후 내용은 위 `내가 정리한 내용` 4번에 반영.

### 심화: 왜 첫 몇 스텝이 가장 위험한가

```text
새로 붙인 분류층 : 무작위 초기화 → 처음엔 엉터리 예측 → 손실이 크다
                                              ↓
                                      기울기가 크다
                                              ↓
                          그 큰 기울기가 역전파로 사전학습 층까지 흘러간다
                                              ↓
                              애써 배운 특징이 첫 스텝에 뭉개진다
```

[[2026-09-04-ai-data-backpropagation]]에서 본 대로 **기울기는 뒤에서 앞으로 흐른다.** 뒤에 붙인 엉터리 층이 만든 큰 기울기가 앞쪽까지 전달되는 것이다.

**2단계 학습(특징 추출 먼저 → 그다음 파인튜닝)이 이 문제의 직접적 해법**이다. 새 분류층이 안정될 때까지 사전학습 층을 동결해 두면, 큰 기울기가 앞쪽으로 흘러갈 통로 자체가 막힌다.

### 심화: "가장 어려운 칸"에서 제약을 옮기는 법

```text
도메인이 다르다  →  뒤쪽 층이 쓸모없다  →  새로 학습할 층이 많아진다
                                          →  학습할 파라미터가 많이 필요
데이터가 적다    →  학습할 파라미터를 줄여야 한다  (과적합 방지)

                        ↑ 정확히 반대 방향
```

**한쪽은 "많이 학습해야 한다"고 하고 다른 쪽은 "적게 학습해야 한다"고 한다.** 어느 쪽으로 가도 손해다 — 많이 학습하면 과적합하고, 적게 학습하면 타깃 도메인에 적응을 못 한다.

| 우회 방법 | 어느 제약을 푸는가 |
|---|---|
| **데이터 증강** | **데이터가 적다**는 쪽 → [[2026-09-16-ai-data-dropout]] |
| **더 비슷한 소스 찾기** | **도메인이 다르다**는 쪽. X선이면 ImageNet 대신 **의료 영상 사전학습 모델** |
| **자기지도 사전학습** | 라벨 없는 타깃 도메인 데이터로 먼저 적응시킨 뒤 파인튜닝 |

**제약이 둘이면 해법도 둘 중 하나를 푸는 방향이다.** 문제를 그대로 두고 방법만 바꾸는 게 아니라 **제약 자체를 옮긴다.**

### 심화: 전이학습은 결국 초기화 전략이다

[[2026-09-10-ai-data-weight-initialization]]의 관점에서 보면 선명하다.

| | 초기값 |
|---|---|
| **He / Xavier 초기화** | 분산만 맞춘 **무작위 값** |
| **전이학습** | **이미 유용한 특징을 담고 있는 값** |

둘 다 "학습을 어디서 출발시킬 것인가"에 답한다. 전이학습은 **훨씬 좋은 출발점**을 주는 것이다.

그리고 [[2026-09-11-ai-data-cnn]]의 **귀납적 편향** 논의와도 같은 구조다.

```text
CNN의 귀납적 편향 : 사람이 "지역성·평행이동 등변성"을 구조에 넣어 줌
전이학습          : 다른 데이터에서 배운 가중치를 초기값으로 넣어 줌
                     ↑
        둘 다 "타깃 데이터가 부족한 자리를 외부 지식으로 메우는" 일
```

### 심화: LLM에서의 전이학습과 증류의 차이

```text
사전학습(Pre-training)     : 인터넷 규모 텍스트로 "언어 일반"을 배운다   ← 소스 과제
     ↓
파인튜닝(Fine-tuning)      : 특정 과제·도메인에 맞춘다                  ← 타깃 과제
     ↓
지시 튜닝 / 정렬(SFT, RLHF)
```

| 기법 | 내용 |
|---|---|
| **전체 파인튜닝** | 모든 파라미터를 갱신. 비싸고 메모리를 많이 쓴다 |
| **PEFT / LoRA** | **일부 작은 행렬만** 학습하고 원래 가중치는 동결 → **특징 추출의 LLM 버전** |
| **프롬프트 엔지니어링** | 가중치를 아예 안 바꾸고 입력만 조정 → 가장 가벼운 형태 |

**증류와 구분해 둘 것**

| | 전이학습 | 증류 |
|---|---|---|
| 무엇을 물려받나 | **가중치** | **출력 분포(행동)** |
| 학생 모델 크기 | 보통 교사와 같다 | **더 작다** |
| 목적 | **새 과제 적응** | **압축** |

### 이전 학습과의 연결

- [[2026-09-11-ai-data-cnn]] — **계층적 특징이 전이학습의 근거 전부**다. 앞쪽이 범용이고 뒤쪽이 특화라는 구조가 "어디를 가져다 쓸까"에 바로 답한다. **귀납적 편향 = 데이터를 대신하는 지식**이라는 틀도 그대로 적용된다.
- [[2026-09-10-ai-data-weight-initialization]] — **전이학습은 초기화 전략이다.** He·Xavier가 분산만 맞춘 무작위 값이라면, 전이학습은 이미 유용한 특징을 담은 값에서 출발한다.
- [[2026-09-04-ai-data-backpropagation]] — 기울기가 **뒤에서 앞으로 흐르기** 때문에 새 분류층의 큰 기울기가 사전학습 층을 망친다. 2단계 학습이 그 통로를 막는다.
- [[2026-08-27-ai-data-gradient-descent]] — **학습률 문제가 다른 얼굴로** 나타난다. 여기서는 "너무 크면 수렴을 못 한다"가 아니라 "너무 크면 이미 가진 좋은 해를 잃는다"다.
- [[2026-09-16-ai-data-dropout]] — **데이터 증강**이 "데이터가 적다"는 제약을 푸는 공통 도구다.
- [[2026-09-08-ai-data-model-distillation]] — 둘 다 **"이미 학습된 모델을 활용"** 하지만, 전이학습은 **가중치**를, 증류는 **출력 분포**를 물려받는다.
- [[2026-08-05-ai-data-bias-variance]] — 데이터가 적을 때 과적합(분산)이 주된 문제이고, 전이학습은 학습할 파라미터를 줄여 이를 억제한다.
