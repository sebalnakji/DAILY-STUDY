## 핵심 개념

질문에 답하기 위해 필요한 핵심 개념을 정리한다.

- **정의**: 입력 변수 `X`와 출력 변수 `y` 사이에 **선형 관계**가 있다고 가정하는 모델.
  ```
  y = B0 + B1*x1 + ... + Bn*xN
  ```
  - `B0`: 절편(intercept), `B1...Bn`: 회귀 계수(기울기), `x`: 독립변수, `y`: 종속변수
- **단순 vs 다중**: 설명변수가 1개면 단순(simple) 선형 회귀, 2개 이상이면 다중(multiple) 선형 회귀.
- **위치**: 지도 학습 중 **회귀(연속값 예측)** 에 속한다. → [[2026-07-20-ai-data-supervised-learning]]
- **학습 = 계수 찾기**: "데이터를 가장 잘 설명하는 직선"의 계수 `B`를 찾는 것. 기준은 **잔차 제곱합(SSE) 최소화** = 최소제곱법(least squares).
- **푸는 방법 두 갈래**
  - **정규방정식(normal equation)**: `β = (XᵀX)⁻¹Xᵀy`. 한 번에 닫힌 해. 단, 역행렬 계산이 비싸 대규모엔 부담. (sklearn은 SVD 사용)
  - **경사하강법(gradient descent)**: 오차를 조금씩 줄이며 반복적으로 계수 갱신. 데이터가 클 때 유리.
- **주요 가정 (어기면 결과가 왜곡됨)**
  1. 특징과 타깃 사이 **선형 관계**
  2. **가법성(additivity)**: 한 특징의 효과가 다른 특징 값에 의존하지 않음
  3. 특징 간 **다중공선성 없음**(상관 높으면 개별 효과 분리 어려움)
  4. 오차의 **독립성 / 등분산성(homoscedasticity) / 정규성**
- **평가지표**: MSE, RMSE, MAE, R²(결정계수), Adjusted R².
- **언제 쓰나**: 출력이 연속값이고, 입력과 출력이 대체로 선형이며, **해석 가능성**(어떤 변수가 얼마나 영향을 주는지)이 중요할 때. 계수가 그대로 "영향력"으로 읽혀 설명이 쉽다.

## 기준 답변

기준 레포의 답변을 바탕으로 핵심만 재구성한다.

**선형 회귀는 입력 변수(X)와 하나의 출력 변수(y) 사이에 선형 관계가 있다고 가정하는 모델**이다.

간단한 식으로 표현하면 다음과 같다.

```
y = B0 + B1*x1 + ... + Bn*xN
```

여기서 `B`는 회귀 계수, `x`는 독립(설명) 변수, `y`는 종속 변수다. 설명 변수가 하나면 **단순 선형 회귀**, 둘 이상이면 **다중 선형 회귀**라고 한다.

선형 회귀는 지도 학습의 회귀 문제에 해당하며, **연속적인 수치값을 예측**할 때 사용한다. 계수를 구하는 것은 곧 **잔차 제곱합을 최소화**하는 직선을 찾는 문제이고, 정규방정식이나 경사하강법으로 풀 수 있다.

## 내가 정리한 내용

**1. 선형 회귀란?**

입력과 출력 사이에 선형 관계가 있다고 가정하고, 그 **직선을 데이터에 맞추는** 모델. 학습은 **데이터와 직선 사이 거리 차의 제곱이 최소가 되는 직선**을 찾는 것(최소제곱법).

**2. 관계가 곡선이면?**

**다항 회귀(Polynomial Regression)** 를 사용한다. 변수의 차수를 올려(예: `면적²`) 곡선 관계를 잡는다.

**3. 로지스틱 회귀와의 관계**

로지스틱 회귀는 선형 회귀를 **내부 재료로 사용**한다. 선형 회귀식으로 값을 계산한 뒤, 그 결과를 **시그모이드 함수**에 통과시켜 0~1 확률로 바꾸고, 임계값(0.5)으로 잘라 분류한다. 그래서 선형 회귀는 **회귀**, 로지스틱 회귀는 그 위에 시그모이드를 얹은 **분류** 모델이다.

## 검토 결과

### 확인된 부분

- **최소제곱법을 자기 언어로 정확히 서술**함("거리 차의 제곱이 최소가 되는 직선"). 정의 + 학습의 의미를 모두 담음.
- 곡선 문제에 다항 회귀를 정확히 지목(초기 "다중 회귀" → 즉시 교정).
- 로지스틱 회귀 = 분류, 시그모이드 활용까지 정확히 짚음.
- 첫날 배운 **"확률을 임계값으로 잘라 0/1을 만들면 분류"** 원리를 로지스틱 회귀에 그대로 연결함. → [[2026-07-20-ai-data-supervised-learning]]

### 보강 포인트

- **다중 회귀(Multiple) vs 다항 회귀(Polynomial) 구분** (초기 혼동 → 교정)

  | | 다중 회귀 | 다항 회귀 |
  |---|---|---|
  | 늘리는 것 | 변수의 **개수** | 변수의 **차수** |
  | 식 | `y = B0 + B1·면적 + B2·층수` | `y = B0 + B1·면적 + B2·면적²` |
  | 모양 | 직선(평면) | **곡선** |
  | 해결 | 여러 요인 반영 | **휘어지는 관계** 반영 |

- **다항 회귀도 "선형 회귀"다.** "선형"은 입력 `x`가 아니라 **계수 `B`** 에 대한 것. `x²`를 새 변수 `z`로 치환하면 `y = B0 + B1x + B2z`로 다시 선형 식이 된다. 계수들이 덧셈으로만 엮이면 곡선을 그려도 선형 회귀.
- **로지스틱 회귀는 선형 회귀와 남남이 아니다.** 관계는 "선형 회귀 위에 시그모이드를 얹은 것":
  ```
  ① 선형 회귀식 계산 (B0 + B1x + ...)  ← 선형 회귀를 그대로 사용
  ② 시그모이드 통과 → 0~1 확률
  ③ 임계값 0.5로 잘라 분류
  ```
  이름에 'regression'이 남은 이유가 ①이다.
