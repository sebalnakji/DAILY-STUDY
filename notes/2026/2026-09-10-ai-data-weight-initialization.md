## 핵심 개념

질문에 답하기 위해 필요한 핵심 개념을 정리한다.

### 문제 설정 — 시작점이 왜 중요한가

[[2026-08-27-ai-data-gradient-descent]]에서 배운 대로, 학습은 **어떤 지점에서 출발해 기울기를 따라 내려가는 과정**이다. 그렇다면 **출발점을 어디로 잡을 것인가**가 남는다.

사소해 보이지만 그렇지 않다. **초기화를 잘못하면 학습이 아예 시작되지 않거나, 시작해도 앞으로 나아가지 못한다.**

### 1. 전부 0으로 두면 — 대칭성 문제(Symmetry Problem)

**결론부터**: 신경망이 **선형 모델보다 나을 게 없어진다.**

왜 그런지 한 층을 들여다보자. 같은 층에 뉴런 세 개가 있고 가중치가 전부 0이라면:

```text
입력 x ──┬──[w=0]──▶ 뉴런1  출력 0
         ├──[w=0]──▶ 뉴런2  출력 0
         └──[w=0]──▶ 뉴런3  출력 0
```

**세 뉴런이 완전히 똑같다.** 같은 입력을 받고, 같은 가중치를 갖고, 같은 출력을 낸다.

이제 [[2026-09-04-ai-data-backpropagation]]의 역전파를 태워 보자.

```text
역전파는 각 가중치의 기울기 ∂L/∂w 를 구한다
  → 세 뉴런이 완전히 동일하므로
  → 세 뉴런에 돌아오는 기울기도 완전히 동일하다
  → 세 뉴런이 똑같은 양만큼 똑같은 방향으로 갱신된다
  → 갱신 후에도 여전히 셋이 똑같다
  → 영원히 똑같다
```

**한 번도 갈라지지 않는다.** 뉴런을 100개 두든 10,000개 두든, 실질적으로는 **뉴런 하나짜리 층**이다. 층을 아무리 넓게·깊게 만들어도 표현력이 늘지 않는다.

> 💡 [[2026-09-03-ai-data-activation-functions]]에서 "활성화 함수가 없으면 100층이 1층과 같아진다"고 했다. **0 초기화는 그것의 가로 방향 버전**이다 — 뉴런 100개가 1개와 같아진다. 하나는 **깊이**가 무너지고, 하나는 **너비**가 무너진다.

이 현상을 **대칭성을 깨지 못한다(fail to break symmetry)** 고 표현한다. 학습이 하는 일 중 하나가 **뉴런마다 서로 다른 특징을 담당하게 분화시키는 것**인데, 출발점이 같으면 분화가 일어나지 않는다.

#### 0만의 문제가 아니다

**모든 가중치를 같은 상수로 채우면 값이 무엇이든 같은 문제가 생긴다.** `0.5`로 채워도, `-3`으로 채워도 뉴런들이 동일하므로 기울기도 동일하다.

**핵심은 "0"이 아니라 "전부 같다"는 것이다.**

#### 편향(bias)은 0이어도 괜찮다

기준 레포가 정확히 짚는 부분이다.

> 편향을 0으로 두는 것은 문제를 일으키지 않는다. **0이 아닌 가중치가 대칭을 깨 주기 때문에**, 편향이 0이어도 각 뉴런의 값은 여전히 서로 다르다.

**대칭을 깨는 역할은 가중치가 맡는다.** 가중치가 무작위면 뉴런마다 다른 출력이 나오므로, 편향이 전부 0이어도 분화가 일어난다. 그래서 실무에서 **편향은 보통 0으로 초기화**한다.

### 2. 무작위 초기화 — 그럼 아무 무작위나 되나?

아니다. **크기(스케일)가 결정적이다.** 기준 레포가 두 실패 사례를 든다.

| 초기값이 | 무슨 일이 벌어지나 |
|---|---|
| **너무 크면** | `Wx + b`가 커져서, 시그모이드 같은 활성화 함수가 값을 **1 근처로 밀어 넣는다.** 그 구간은 기울기가 완만해 **학습이 매우 느려진다** |
| **너무 작으면** | 값이 **0 근처로 몰린다.** 결과는 같다 — **기울기 소실(vanishing gradient)** |

**양쪽 끝 모두 포화(saturation)로 이어진다** — [[2026-09-03-ai-data-activation-functions]]에서 다룬 시그모이드의 그 문제다.

#### 왜 층이 깊을수록 심각한가

한 층을 지날 때 활성값의 분산이 `k`배가 된다면, `L`개 층을 지나면 **`k^L`배**가 된다.

| 층당 분산 배율 | 10층 후 | 20층 후 |
|---|---:|---:|
| 0.5배 (너무 작은 초기값) | **1/1,024** | **약 100만분의 1** |
| 2배 (너무 큰 초기값) | **1,024배** | **약 100만 배** |

**지수적으로 증폭되거나 소멸한다.** 어제 다룬 역전파의 곱셈 누적과 정확히 같은 구조다 — 이번엔 순전파 쪽에서 벌어진다.

## 기준 답변

### 3. 해법 — 분산을 층마다 일정하게 유지한다

목표가 분명해진다: **신호가 층을 지나도 분산이 유지되게 하라.**

이를 위해 **입력 뉴런 수(`fan_in`)에 따라 초기값의 크기를 조절**한다. 입력이 많을수록 합해지는 항이 많아지므로, 각 항을 그만큼 작게 만들어야 한다.

| 방법 | 분산 | 함께 쓰는 활성화 함수 |
|---|---|---|
| **Xavier / Glorot 초기화** | `Var(W) = 1 / n_in`<br>(또는 `2 / (n_in + n_out)`) | **시그모이드, tanh** |
| **He 초기화** | `Var(W) = 2 / n_in` | **ReLU 계열** |

#### 왜 활성화 함수에 따라 갈리는가

**ReLU가 입력의 절반을 0으로 만들기 때문이다.**

```text
ReLU = max(0, x)
→ 입력이 0을 중심으로 분포하면 약 절반이 음수 → 전부 0이 됨
→ 통과한 신호의 분산이 대략 절반으로 줄어든다
→ 그래서 미리 2배로 키워 둔다  →  Var(W) = 2 / n_in
```

**He 초기화의 `2`는 ReLU가 버리는 절반을 보상하는 숫자다.** 마법의 상수가 아니라 활성화 함수의 성질에서 유도된 값이다.

**구체적인 감각** — 입력 뉴런이 256개인 층이라면:

| 방법 | 표준편차 |
|---|---:|
| Xavier | `√(1/256)` = **약 0.063** |
| He | `√(2/256)` = **약 0.088** |

### 초기화 방법 정리

| 방법 | 내용 | 평가 |
|---|---|---|
| **전부 0 / 같은 상수** | 모든 가중치를 같은 값으로 | ❌ **대칭성을 못 깬다** |
| **작은 무작위** | 예: `N(0, 0.01)` | △ 얕은 망에서는 되지만 깊어지면 신호가 소멸 |
| **Xavier / Glorot** | `fan_in`(과 `fan_out`)으로 분산 조절 | ✅ 시그모이드·tanh |
| **He** | `2 / fan_in` | ✅ **ReLU 계열 표준** |
| **편향** | 보통 **0** | ✅ 가중치가 대칭을 깨 주므로 문제없다 |

### 오늘날의 맥락

**배치 정규화(Batch Normalization)** 가 층마다 활성값 분포를 다시 맞춰 주기 때문에, 초기화에 대한 민감도는 예전보다 줄었다. 잔차 연결(residual connection)도 신호가 곧바로 흐를 경로를 만들어 같은 방향으로 돕는다.

그럼에도 **초기화는 여전히 기본기다.**

- 배치 정규화가 없는 구조도 많다
- 학습 **초기 몇 스텝**의 안정성은 초기화가 좌우한다
- **대칭성 문제는 어떤 정규화로도 해결되지 않는다** — 출발점이 같으면 배치 정규화를 해도 뉴런은 여전히 동일하다

## 내가 정리한 내용

### 1. 전부 0으로 두면 생기는 일

- 가중치를 전부 0으로 두면 **뉴런에 연결된 가중치의 기울기도 항상 동일한 값**을 가진다.
- 기울기가 항상 동일하면 **대칭성을 깨지 못한다.**
- **왜 "영원히"인가**: 경사하강법은 **결정적(deterministic)** 이라 대칭을 보존한다. 초기 상태가 대칭이면 갱신 규칙도 대칭적이라 갱신 후에도 대칭이다. **대칭을 깨려면 외부에서 비대칭을 주입해야 하는데, 학습 과정에는 그런 통로가 없다 — 유일한 주입 통로가 초기화다.**

```text
초기 상태가 대칭 → 갱신 규칙이 대칭적 → 갱신 후에도 대칭 → (반복)
                        ↑
        손실 함수도, 역전파도, 옵티마이저도 전부 결정적
```

그래서 초기화는 "그냥 시작값 정하기"가 아니라 **학습이 가능해지기 위한 필요조건**이다.

### 2. 가중치와 편향의 차이

- **가중치는 입력의 어느 방향에 반응할지 정하고, 편향은 반응의 기준선을 옮긴다.**
- 실질적으로 **분화를 일으키는 건 가중치**이므로 가중치는 값이 달라야 하지만 편향은 0이어도 된다.
- **반대 경우를 보면 더 명확하다** — 편향만 무작위로 하고 가중치를 0으로 두면 `Wx + b = b`가 되어 **출력이 입력과 무관해진다.** 뉴런들이 달라지긴 하지만 **입력을 아예 보지 않는 상수 출력기**가 된다.

| | 가중치 `W` | 편향 `b` |
|---|---|---|
| 하는 일 | **입력의 어느 방향에 반응할지** | 반응의 **기준선(임계값)** |
| 다르면 | 뉴런마다 **다른 특징을 담당** | 같은 특징을 **다른 문턱**에서 감지 |
| 0이면 | **입력과의 연결이 끊긴다** | 문턱이 0일 뿐, 연결은 살아 있다 |

### 3. 무작위면 되는가 — 크기가 문제다

- **초기값이 너무 크면** 활성값이 포화 구간으로 밀려 **기울기가 완만해지고 학습이 매우 느려진다.**
- **초기값이 너무 작으면** 값이 0 근처로 몰려 **기울기 소실** 문제가 발생한다.
- **양쪽 끝 모두 포화(saturation)로 수렴한다.**
- **깊이에 따라 지수적으로 악화된다** — 층당 분산이 `k`배면 `L`층 후에는 **`k^L`배**가 된다.

| 층당 분산 배율 | 10층 후 | 20층 후 |
|---|---:|---:|
| 0.5배 | **1/1,024** | 약 **100만분의 1** |
| 2배 | **1,024배** | 약 **100만 배** |

얕은 망에서는 티가 안 나도 깊어지면 지수적으로 증폭·소멸한다. **역전파의 곱셈 누적과 같은 구조가 순전파 쪽에서 반복되는 것**이다.

### 4. Xavier와 He의 차이

- **Xavier / Glorot**은 시그모이드·tanh와 함께 쓰며, **이들은 입력을 전부 사용한다**(신호 통과율 ≈ 1). → `Var(W) = 1 / n_in`
- **He**는 ReLU와 함께 쓰며, **ReLU는 음수 입력을 0으로 만들어 분산을 대략 절반 버리기 때문에 분산을 미리 2배로 늘려 놓는다.** → `Var(W) = 2 / n_in`

**두 초기화는 별개의 발명이 아니라 같은 공식의 양 끝이다.**

```text
Var(W) = 2 / ((1 + a²) · n_in)      (a = 음수 구간 기울기)

a = 0    (순수 ReLU)   → 2 / n_in    ← He
a = 1    (항등함수)     → 1 / n_in    ← Xavier
```

## 검토 결과

### 확인된 부분

- **가중치와 편향의 역할 구분**을 정확히 옮기고 — "입력의 어느 방향에 반응할지"(가중치) vs "반응의 기준선"(편향) — 거기서 **"분화를 일으키는 건 가중치"** 라는 결론까지 끌어냈다.
- **두 실패 모드**(너무 큼 / 너무 작음)를 양쪽 다 짚고, **둘 다 결국 기울기 소실로 수렴한다**는 점을 잡았다.
- **"입력을 전부 사용함" vs "절반을 버림"** — **통과율**로 두 초기화를 갈랐다. `2`라는 숫자를 외운 게 아니라 **유도했다는 신호**다. 오늘 답변 중 가장 좋다.

### 보강 포인트

#### ① "영원히"의 근거가 한 단계 빠졌다

| | 내용 |
|---|---|
| **전** | 기울기가 항상 동일한 값을 가지면 대칭성을 깨지 못함 |
| **후** | (동일) + **경사하강법은 결정적이라 대칭을 보존한다.** 대칭을 깨려면 외부에서 비대칭을 주입해야 하는데, **유일한 주입 통로가 초기화다** |

"기울기가 같아서 안 깨진다"는 **현상**이고, **왜 학습이 스스로 못 깨는가**가 한 겹 아래다. 이걸 말할 수 있으면 **초기화가 학습의 필요조건**이라는 결론까지 자연스럽게 닿는다.

#### ② 반대 경우(편향만 무작위)를 짚으면 완성된다

`W = 0`의 진짜 문제가 **대칭성만이 아니라 "입력과의 연결이 끊긴다"** 는 것도 함께 보인다. 교정 후 내용은 위 `내가 정리한 내용` 2번에 반영.

#### ③ 깊이에 따른 지수적 악화가 빠졌다

층당 분산 배율이 `k^L`로 누적된다는 점이 **초기화가 "깊은 망에서만 문제가 되는" 이유**다. 교정 후 내용은 위 `내가 정리한 내용` 3번에 반영.

### 심화: 경사하강법은 대칭을 보존한다

> **대칭을 깨려면 외부에서 비대칭을 주입해야 한다.**

학습 과정 어디에도 그런 통로가 없다 — 손실 함수도, 역전파도, 옵티마이저도 전부 결정적이다. **유일한 주입 통로가 초기화다.**

> 💡 엄밀히는 통로가 하나 더 있다 — **드롭아웃**처럼 확률적 요소가 끼면 뉴런마다 다른 마스크가 걸려 대칭이 깨질 수 있다. 하지만 그건 우연에 기대는 것이고, 표준적으로는 **초기화가 그 일을 맡는다.**

**대칭성 문제는 어떤 정규화로도 해결되지 않는다.** 출발점이 같으면 배치 정규화를 해도 뉴런은 여전히 동일하다. 이것이 배치 정규화가 있어도 초기화가 여전히 기본기인 이유 중 하나다.

### 심화: 깊이와 너비, 두 방향의 붕괴

| | 무너지는 것 | 결과 |
|---|---|---|
| **활성화 함수 없음** | **깊이** | 100층이 1층과 같아진다 → [[2026-09-03-ai-data-activation-functions]] |
| **가중치 전부 0** | **너비** | 뉴런 100개가 1개와 같아진다 |

**둘 다 "표현력이 늘지 않는다"는 같은 결론에 도달한다.** 하나는 세로로, 하나는 가로로 접히는 것이다. 신경망이 힘을 내려면 **깊이와 너비가 모두 실질적으로 살아 있어야** 한다.

### 심화: 왜 `fan_in`으로 나누는가

목표는 **신호가 층을 지나도 분산이 유지되게 하는 것**이다.

입력 뉴런이 `n_in`개면 `n_in`개 항이 합해진다. 독립인 항들을 더하면 **분산도 더해지므로**, 합의 분산은 대략 `n_in × Var(W) × Var(x)`가 된다. 이것을 `Var(x)`와 같게 만들려면:

```text
n_in × Var(W) = 1   →   Var(W) = 1 / n_in      ← Xavier
```

**입력이 많을수록 각 항을 작게** 만들어야 합이 폭주하지 않는다는 뜻이다.

입력 뉴런이 256개인 층이라면:

| 방법 | 표준편차 |
|---|---:|
| Xavier | `√(1/256)` = 약 **0.063** |
| He | `√(2/256)` = 약 **0.088** |

### 심화: 초기화 방법 정리

| 방법 | 내용 | 평가 |
|---|---|---|
| **전부 0 / 같은 상수** | 모든 가중치를 같은 값으로 | ❌ **대칭성을 못 깬다.** 핵심은 "0"이 아니라 **"전부 같다"** 는 것 — `0.5`나 `-3`으로 채워도 같은 문제 |
| **작은 무작위** | 예: `N(0, 0.01)` | △ 얕은 망에서는 되지만 깊어지면 신호가 소멸 |
| **Xavier / Glorot** | `1 / n_in` | ✅ 시그모이드·tanh |
| **He** | `2 / n_in` | ✅ **ReLU 계열 표준** |
| **편향** | 보통 **0** | ✅ 가중치가 대칭을 깨 주므로 문제없다 |

### 이전 학습과의 연결

- [[2026-09-04-ai-data-backpropagation]] — **"모든 뉴런이 같은 기울기를 받는다"** 가 0 초기화 문제의 전부다. 또 **분산이 층마다 곱해져 지수적으로 누적**되는 구조가 역전파의 곱셈 누적과 같다 — 그쪽은 역방향, 이쪽은 순방향.
- [[2026-09-03-ai-data-activation-functions]] — **He의 `2`가 ReLU의 성질에서 나온다.** 또 초기값이 크거나 작을 때 생기는 **포화**가 시그모이드 문제 그 자체다. 그리고 **깊이(활성화 함수) vs 너비(초기화)** 의 붕괴가 짝을 이룬다.
- [[2026-08-27-ai-data-gradient-descent]] — 학습이 **"어디서 출발해 기울기를 따라 내려가는가"** 라면, 초기화는 그 **출발점을 정하는 일**이다.
- [[2026-09-01-ai-data-svm]] — SVM은 목적 함수가 **볼록(convex)** 이라 어디서 출발해도 같은 답에 도달했다. 신경망은 그렇지 않아 **출발점이 결과를 바꾼다.** 초기화가 중요한 근본 이유다.
- [[2026-08-09-ai-data-regularization]] — **배치 정규화**가 초기화 민감도를 낮춰 주지만, **대칭성 문제만은 해결하지 못한다.**
