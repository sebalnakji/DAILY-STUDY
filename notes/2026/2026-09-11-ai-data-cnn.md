## 핵심 개념

질문에 답하기 위해 필요한 핵심 개념을 정리한다.

### 문제 설정 — 완전연결층으로 이미지를 다루면 왜 안 되나

**① 파라미터가 폭발한다.**

`224 × 224` 컬러 이미지 한 장을 완전연결층에 넣으려면 먼저 **일렬로 펴야** 한다.

```text
224 × 224 × 3 = 150,528 개의 입력
은닉 뉴런 1,000개와 완전연결하면
→ 150,528 × 1,000 ≈ 1억 5천만 개의 가중치     ← 층 하나에서
```

층 하나에 1.5억 개다. 학습이 불가능하고, [[2026-08-05-ai-data-bias-variance]]에서 다룬 **과적합**이 확실하다.

**② 공간 구조가 파괴된다.**

이미지를 일렬로 펴는 순간, **바로 옆 픽셀과 한참 떨어진 픽셀이 동등해진다.** 인접 관계라는 핵심 정보가 사라진다.

```text
원래 이미지            일렬로 편 후
┌───┬───┬───┐
│ a │ b │ c │        a b c d e f g h i
├───┼───┼───┤          ↑       ↑
│ d │ e │ f │          a와 d는 실제로 위아래로 붙어 있는데
├───┼───┼───┤          펴고 나면 멀어 보인다
│ g │ h │ i │
└───┴───┴───┘
```

**③ 위치가 바뀌면 다시 배워야 한다.**

왼쪽 위에 있는 고양이를 인식하도록 학습한 가중치는, **오른쪽 아래에 있는 고양이에는 아무 소용이 없다.** 완전연결층에서는 위치마다 별개의 가중치가 붙기 때문이다.

### CNN의 두 가지 핵심 아이디어

이 세 문제를 **두 가지 발상**으로 한꺼번에 해결한다.

#### ① 지역 수용 영역(Local Receptive Field) — 작은 창으로만 본다

각 뉴런이 **이전 층 전체가 아니라 작은 영역(예: 3×3)만** 본다.

```text
완전연결                        합성곱
모든 입력 ──▶ 뉴런             ┌───┐
(150,528개)                    │3×3│──▶ 뉴런
                               └───┘
                               9개(×채널)만 본다
```

**근거는 이미지의 지역성(locality)** 이다 — 엣지, 모서리, 질감 같은 저수준 특징은 **좁은 영역 안에서** 결정된다. 고양이 귀를 알아보는 데 이미지 반대편 픽셀은 필요 없다.

#### ② 가중치 공유(Parameter Sharing) — 같은 필터를 전체에 굴린다

**같은 3×3 필터(커널)를 이미지 전체에 슬라이딩**시키며 적용한다.

```text
필터를 왼쪽 위부터 오른쪽 아래까지 한 칸씩 옮기며 내적을 계산
→ 결과가 특징 맵(feature map)

┌─┬─┬─┬─┐        ┌─┬─┬─┬─┐        ┌─┬─┬─┬─┐
│▓│▓│ │ │        │ │▓│▓│ │        │ │ │▓│▓│
│▓│▓│ │ │  ──▶   │ │▓│▓│ │  ──▶   │ │ │▓│▓│  ──▶ ...
│ │ │ │ │        │ │ │ │ │        │ │ │ │ │
└─┴─┴─┴─┘        └─┴─┴─┴─┘        └─┴─┴─┴─┘
  같은 필터가 모든 위치를 훑는다
```

**근거는 평행이동 등변성(translation equivariance)** 이다 — **세로 엣지를 찾는 필터는 이미지 어디에서든 세로 엣지를 찾는다.** 위치마다 따로 배울 이유가 없다.

#### 파라미터 수 비교

```text
완전연결 (224×224×3 → 1,000)
  150,528 × 1,000 = 150,528,000 개

합성곱 (3×3 필터, 입력 3채널, 필터 64개)
  3 × 3 × 3 × 64 = 1,728 개 (+ 편향 64) = 1,792 개
```

| | 파라미터 수 | 비율 |
|---|---:|---:|
| 완전연결 | **1억 5천만** | 1× |
| 합성곱 | **1,792** | **약 1/84,000** |

**8만 배 차이다.** 그런데 성능은 오히려 더 좋다. 파라미터가 적으면서 성능이 좋은 이유는 **CNN이 이미지에 대한 올바른 가정(귀납적 편향)을 구조에 내장**했기 때문이다.

### 합성곱 연산의 구성 요소

| 용어 | 뜻 |
|---|---|
| **필터 / 커널(Filter, Kernel)** | 슬라이딩하는 작은 가중치 행렬 (예: 3×3) |
| **스트라이드(Stride)** | 필터를 몇 칸씩 옮길지. 크면 출력이 작아진다 |
| **패딩(Padding)** | 가장자리에 0을 덧대기. 출력 크기 유지, 가장자리 정보 보존 |
| **채널(Channel)** | 입력의 깊이(RGB면 3). 필터도 같은 깊이를 갖는다 |
| **특징 맵(Feature Map)** | 필터 하나가 만들어 내는 출력. 필터 `k`개면 특징 맵 `k`개 |

**출력 크기**: `(입력 − 커널 + 2×패딩) / 스트라이드 + 1`

> 💡 **필터 하나 = 특징 하나.** 어떤 필터는 세로 엣지에, 다른 필터는 가로 엣지에, 또 다른 필터는 특정 색 변화에 반응한다. **필터를 여러 개 두는 것이 여러 특징을 동시에 찾는 방법**이다.

## 기준 답변

### 풀링(Pooling) — 요약하고 줄인다

합성곱 층 사이에 **풀링 층**을 끼워 특징 맵을 축소한다.

```text
맥스 풀링 2×2, 스트라이드 2

┌───┬───┬───┬───┐
│ 1 │ 3 │ 2 │ 4 │        ┌───┬───┐
├───┼───┼───┼───┤        │ 5 │ 8 │   각 2×2 영역에서
│ 5 │ 2 │ 8 │ 1 │   ──▶  ├───┼───┤   최댓값만 남긴다
├───┼───┼───┼───┤        │ 9 │ 7 │
│ 9 │ 4 │ 3 │ 7 │        └───┴───┘
├───┼───┼───┼───┤
│ 2 │ 6 │ 1 │ 5 │
└───┴───┴───┴───┘
```

| 풀링의 효과 | 설명 |
|---|---|
| **계산량·메모리 감소** | 특징 맵 크기가 줄어든다 |
| **평행이동 불변성(invariance)** | 특징이 **조금 움직여도 같은 출력**이 나온다 |
| **수용 영역 확대** | 같은 3×3 필터가 원본 이미지의 더 넓은 영역을 보게 된다 |

> ⚠️ **등변성(equivariance)과 불변성(invariance)은 다르다.**
>
> | | 뜻 | 담당 |
> |---|---|---|
> | **등변성** | 입력이 움직이면 **출력도 같이 움직인다** | 합성곱 |
> | **불변성** | 입력이 움직여도 **출력이 그대로다** | 풀링 |
>
> 합성곱은 "귀가 오른쪽으로 갔다"를 그대로 반영하고, 풀링은 "조금 움직인 건 신경 안 쓴다"로 뭉갠다. **둘이 합쳐져 "어디 있든 고양이는 고양이"가 된다.**

### 계층적 특징 학습 — CNN의 진짜 힘

층을 쌓으면 **특징이 점점 추상화된다.**

| 층 깊이 | 학습되는 특징 |
|---|---|
| **얕은 층** | 엣지, 색 변화, 밝기 대비 |
| **중간 층** | 모서리, 질감, 단순한 도형 |
| **깊은 층** | 눈, 귀, 바퀴 같은 **물체의 부분** |
| **가장 깊은 층** | 얼굴, 자동차 같은 **물체 전체** |

**사람이 "엣지를 먼저 찾아라"라고 지시한 적이 없다.** 손실을 줄이도록 역전파가 가중치를 조정하다 보니 **저절로 그런 계층이 생겨난다** — [[2026-09-04-ai-data-backpropagation]]

이것이 **특징 공학(feature engineering)의 자동화**다. 전통적 컴퓨터 비전에서는 SIFT·HOG 같은 특징 추출기를 **사람이 설계**했는데, CNN은 그것을 **데이터에서 학습**한다.

### 전형적인 구조

```text
입력 이미지
  ↓
[합성곱 → 활성화(ReLU) → 풀링]  ×  N번 반복
  ↓
평탄화(Flatten)
  ↓
완전연결층 1~2개
  ↓
소프트맥스 → 클래스 확률
```

- **활성화 함수는 ReLU**가 표준 → [[2026-09-03-ai-data-activation-functions]]
- **초기화는 He**를 쓴다 (ReLU를 쓰므로) → [[2026-09-10-ai-data-weight-initialization]]
- 깊어지면 **잔차 연결**로 기울기 소실을 막는다 (ResNet)

### CNN vs 완전연결 신경망

| 항목 | 완전연결(FC) | **CNN** |
|---|---|---|
| 연결 범위 | 이전 층 **전체** | **지역(작은 창)** |
| 가중치 | 위치마다 **따로** | **전체에서 공유** |
| 파라미터 수 | 폭발적 | **적다** |
| 공간 구조 | **파괴됨** | **보존됨** |
| 위치 변화 | 다시 배워야 함 | **그대로 통함** |
| 적합한 데이터 | 표 형태 | **이미지·오디오·시계열** |

### 왜 이게 "좋은 편향"인가

CNN은 이미지에 대해 **두 가지 가정을 구조에 못 박았다** — 지역성과 평행이동 등변성. 이런 내장된 가정을 **귀납적 편향(inductive bias)** 이라고 한다.

[[2026-08-05-ai-data-bias-variance]]의 관점에서 보면:

```text
편향을 일부러 넣었다  →  모델이 탐색할 가설 공간이 줄어든다
                      →  분산이 줄고 과적합이 억제된다
                      →  적은 데이터로도 잘 학습된다
```

**가정이 데이터의 실제 성질과 맞으면, 편향은 손해가 아니라 이득이다.** 이미지는 실제로 지역적이고 평행이동에 강하므로 CNN의 가정이 옳다.

> 💡 **비전 트랜스포머(ViT)** 와의 대비가 이 점을 잘 보여준다. ViT는 이런 가정을 **내장하지 않고 데이터에서 배운다.** 그래서 **데이터가 아주 많을 때는 CNN을 능가하지만, 데이터가 적으면 CNN이 더 낫다.** 편향을 넣을지 말지가 **데이터 양과의 거래**인 셈이다.

## 내가 정리한 내용

### 1. 완전연결층으로 이미지를 다룰 때의 문제 세 가지

- **과도한 파라미터 문제**: 완전연결층에 넣으려면 먼저 일렬로 펴야 하는데, 이러면 **층 하나에 파라미터가 과도하게 많아져** 학습이 불가능하고 과적합이 된다.
- **공간 구조 파괴 문제**: 이미지를 펴는 순간 **바로 옆 픽셀과 한참 떨어진 픽셀이 동등해진다.**
- **위치가 바뀌면 다시 배워야 하는 문제**: **위치마다 별개의 가중치가 붙으므로** 위치가 바뀌면 인식하지 못해 추가 학습이 필요하다.

### 2. CNN의 두 핵심 아이디어와 근거

- **지역 수용 영역(Local Receptive Field)**: 각 뉴런이 이전 층 전체가 아니라 **작은 영역(예: 3×3)만** 본다.
  - 근거는 **이미지의 지역성(locality)** — 엣지·질감 같은 저수준 특징은 **좁은 영역 안에서 결정된다.**
- **가중치 공유(Parameter Sharing)**: **같은 필터를 이미지 전체에 슬라이딩**시킨다.
  - 근거는 **평행이동 등변성(translation equivariance)** — 세로 엣지를 찾는 필터는 **어디에서든 세로 엣지를 찾으므로** 위치마다 따로 배울 이유가 없다.

### 3. 합성곱과 풀링의 역할 분담

- **합성곱**은 **무엇이 어디에 있는지를 찾고**, 등변성을 이용해 **위치를 보존**한다.
- **풀링**은 **"어디에"를 조금씩 흐리게 만들어**, 층을 거칠수록 **"어디"가 점점 지워지고 "무엇"만 남는다.**
- **순서가 중요하다** — **찾지도 않은 걸 뭉갤 수는 없다.** 등변성이 먼저 있어야 불변성이 의미를 갖는다. 그래서 `합성곱 → 풀링`을 **번갈아 반복**한다.

| 없으면 | 결과 |
|---|---|
| **풀링이 없으면** | 위치 정보가 끝까지 따라다닌다. 최종 답은 위치와 무관한 "고양이다"여야 하는데 **"어디"를 버리는 단계가 없다** |
| **합성곱이 없으면** | **뭉갤 대상이 없다.** 풀링은 찾는 연산이 아니라 요약하는 연산이라, 원본 픽셀을 풀링하면 그냥 저해상도 이미지가 된다 |

### 4. 귀납적 편향 — 언제 이득이고 언제 손해인가

- **데이터가 아주 많을 때**는 내장된 가정 대신 **데이터로 배우는 ViT가 유리**하지만, **데이터가 적으면** 일부러 귀납적 편향을 넣어 **분산을 줄인 CNN이 유리**하다.
- **데이터가 적으면 분산이 주된 문제**라 편향을 넣어 분산을 억제하는 게 이득이다. **데이터가 많아지면 분산이 자연히 작아지므로 남는 건 편향뿐**이고, 이때 CNN의 가정이 **오히려 족쇄**가 된다.

> **귀납적 편향은 데이터를 대신하는 지식이다.** 데이터가 부족하면 사람이 넣어 준 지식이 이득이고, 데이터가 넘치면 그 지식이 제약이 된다.

CNN의 가정은 **대체로 맞지만 완벽하진 않다** — 이미지에는 전역적 관계도 있는데(사진 양 끝의 하늘이 이어진다든가), CNN은 작은 창만 보므로 깊은 층에 가서야 겨우 본다. ViT는 처음부터 모든 패치가 서로를 본다.

### 확인된 부분

- **완전연결층의 세 문제를 원인과 함께** 정리했다. 특히 **"위치마다 별개의 가중치가 붙으므로"** 라고 메커니즘까지 짚었다 — 현상만 외운 게 아니다.
- **"어디가 점점 지워지고 무엇만 남는다"** — 층을 거치며 정보가 걸러지는 과정을 한 문장으로 압축했다.
- **데이터 양에 따라 유불리가 뒤집힌다**는 교차 구조를 정확히 잡았다. 편향-분산을 **모델 선택 수준**에서 적용한 것이다.

### 보강 포인트

#### ① 매핑만 있고 내용이 없었다

| | 내용 |
|---|---|
| **전** | 지역 수용 영역 → 이미지의 지역성 / 가중치 공유 → 평행이동 등변성 |
| **후** | 각 아이디어가 **구체적으로 무엇을 하는지**까지 (위 `내가 정리한 내용` 2번에 반영) |

직전 대화에서는 두 아이디어를 충분히 설명했는데 **정리에서 한 줄 매핑으로 줄었다.** 노트는 **나중에 혼자 읽을 문서**라 이 상태로는 "지역 수용 영역이 뭐였지"가 복원되지 않는다.

> 💡 면접에서도 같다. "지역 수용 영역과 지역성"만 말하면 **용어를 아는 것**이고, "각 뉴런이 3×3만 보는데 엣지는 좁은 영역에서 결정되니까"까지 말해야 **이해한 것**으로 들린다.

#### ② 합성곱과 풀링의 순서가 왜 중요한지가 빠졌다

**찾지도 않은 걸 뭉갤 수는 없다** — 등변성이 먼저 있어야 불변성이 의미를 갖는다. 교정 후 내용은 위 `내가 정리한 내용` 3번에 반영.

#### ③ "데이터가 적으면 분산이 주된 문제"라는 연결 고리가 빠졌다

결론(교차)은 맞았지만 **왜 그렇게 되는지**의 중간 단계가 없었다. 교정 후 내용은 위 `내가 정리한 내용` 4번에 반영.

### 심화: 적은 파라미터로 더 잘하는 역설

**CNN은 완전연결층보다 표현력이 실제로 작다.**

```text
합성곱 = 완전연결에 두 가지 제약을 건 것
  ① 멀리 있는 연결의 가중치를 0으로 고정  (지역성)
  ② 여러 위치의 가중치를 같은 값으로 묶음  (가중치 공유)

→ CNN이 표현할 수 있는 함수는 FC가 표현할 수 있는 함수의 부분집합이다
```

FC가 CNN을 흉내 낼 수는 있지만 반대는 안 된다. **표현력만 보면 FC의 완승이다.**

**그런데도 CNN이 이긴다. 문제가 "표현력 부족"이 아니었기 때문이다.**

FC의 1.5억 개 파라미터 중 상당수는 **"왼쪽 위의 고양이"와 "오른쪽 아래의 고양이"를 따로 배우는 데** 쓰인다. 같은 걸 위치마다 중복해서 배우는 것이다.

```text
FC의 여분 표현력 = "위치마다 다른 규칙을 쓸 자유"
                    ↑
        이미지 문제에서는 쓸모없는 자유다
        그런데 그 자유가 있으면 모델은 그걸 써서 훈련 데이터를 외운다
```

**CNN은 표현력을 깎은 게 아니라 애초에 필요 없던 자유도를 제거한 것**이고, 그 자유도가 바로 과적합의 원료였다.

> 🏫 **비유**: 답안지에 아무 말이나 쓸 수 있는 자유가 있다고 시험을 더 잘 보는 게 아니다. **"수식으로만 답하시오"라는 제약이 오히려 정답에 가깝게 만들 수 있다** — 제약이 정답의 방향과 일치할 때.

**핵심은 표현력의 크기가 아니라 방향이다.**

### 심화: 등변성과 불변성 — 정확한 구분

| | 뜻 | 담당 |
|---|---|---|
| **등변성(equivariance)** | 입력이 움직이면 **출력도 같이 움직인다** | 합성곱 |
| **불변성(invariance)** | 입력이 움직여도 **출력이 그대로다** | 풀링 |

합성곱은 "귀가 오른쪽으로 갔다"를 그대로 반영하고, 풀링은 "조금 움직인 건 신경 안 쓴다"로 뭉갠다.

```text
합성곱  : "무엇이" "어디에" 있는지 찾는다      (등변성 — 위치를 보존)
풀링    : "어디에"를 조금씩 흐린다             (불변성 — 위치를 버림)

층을 거칠수록 → "어디"가 점점 지워지고 "무엇"만 남는다
                마지막 완전연결층 + 소프트맥스에서 위치 무관한 클래스 확률
```

### 심화: 데이터 양에 따른 CNN과 ViT의 교차

```text
성능
 ▲                                    ╱ ViT
 │                              ╱────
 │                        ╱────
 │        ╱──────────────────────  CNN
 │    ╱
 │ ╱
 └──────────────┬──────────────────▶ 데이터 양
              교차점
```

| | 데이터가 적을 때 | 데이터가 아주 많을 때 |
|---|---|---|
| 주된 문제 | **분산** | **편향** |
| 유리한 쪽 | **CNN** (편향을 넣어 분산 억제) | **ViT** (가정 없이 데이터에서 학습) |

이것은 [[2026-08-05-ai-data-bias-variance]] 트레이드오프의 **모델 선택 버전**이다. 보통은 같은 모델 안에서 복잡도를 조절하는 이야기인데, 여기서는 **아키텍처 자체가 편향의 양을 정한다.**

### 심화: 계층적 특징 학습

| 층 깊이 | 학습되는 특징 |
|---|---|
| **얕은 층** | 엣지, 색 변화, 밝기 대비 |
| **중간 층** | 모서리, 질감, 단순한 도형 |
| **깊은 층** | 눈, 귀, 바퀴 같은 **물체의 부분** |
| **가장 깊은 층** | 얼굴, 자동차 같은 **물체 전체** |

**사람이 "엣지를 먼저 찾아라"라고 지시한 적이 없다.** 손실을 줄이도록 역전파가 가중치를 조정하다 보니 저절로 그런 계층이 생긴다.

이것이 **특징 공학(feature engineering)의 자동화**다. 전통적 컴퓨터 비전에서는 SIFT·HOG 같은 특징 추출기를 **사람이 설계**했는데, CNN은 그것을 **데이터에서 학습**한다.

### 이전 학습과의 연결

- [[2026-08-05-ai-data-bias-variance]] — **귀납적 편향**이 편향-분산 트레이드오프의 아키텍처 수준 적용이다. "편향을 일부러 넣어 분산을 줄인다"가 CNN 설계의 핵심.
- [[2026-09-10-ai-data-weight-initialization]] — CNN은 ReLU를 쓰므로 **He 초기화**가 표준이다. 또 가중치 공유는 **"파라미터를 줄이는" 또 다른 방식**이다.
- [[2026-09-03-ai-data-activation-functions]] — `합성곱 → ReLU → 풀링`이 기본 블록이다.
- [[2026-09-04-ai-data-backpropagation]] — 계층적 특징이 **사람의 지시 없이** 생기는 것은 역전파가 손실을 줄이는 방향으로 가중치를 조정한 결과다. 또 깊은 CNN에서 **잔차 연결**이 필요한 이유도 여기서 나온다.
- [[2026-08-06-ai-data-self-attention]] — **ViT**가 CNN의 대안이 되는 근거가 어텐션이다. 모든 패치가 처음부터 서로를 보므로 **전역 관계**를 바로 다룬다.
- [[2026-08-12-ai-data-feature-selection]] — 사람이 특징을 고르던 일을 CNN이 **자동화**한다. 특징 공학의 자동화라는 같은 축.
- [[2026-08-09-ai-data-regularization]] — 가중치 공유는 **구조적 정규화**로 볼 수 있다. 파라미터에 제약을 걸어 과적합을 막는다는 점에서 L1·L2와 목적이 같다.
