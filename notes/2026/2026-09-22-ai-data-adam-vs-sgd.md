## 핵심 개념

질문에 답하기 위해 필요한 핵심 개념을 정리한다.

### 출발점 — SGD의 두 가지 불편

[[2026-08-27-ai-data-gradient-descent]]의 갱신식은 이렇다.

```text
w ← w − η · g          (g = 기울기, η = 학습률)
```

여기엔 두 가지 불편이 있다.

#### ① 모든 파라미터가 같은 보폭을 쓴다

```text
파라미터 A : 기울기가 매 스텝 크게 변동 → 작은 보폭이 필요
파라미터 B : 기울기가 아주 작고 일정   → 큰 보폭이 필요

그런데 η는 하나뿐이다
```

특히 **희소한 특징**(자주 안 나오는 단어의 임베딩 등)은 기울기가 가끔만 들어오므로, 같은 학습률을 쓰면 **거의 학습되지 않는다.**

#### ② 매 스텝의 기울기를 그대로 믿는다

미니배치마다 기울기가 흔들린다. 좁고 긴 골짜기에서는 **좌우로 튕기며 느리게** 내려간다.

```text
       ╲    ╱
        ╲  ╱      기울기를 그대로 따르면
    →→→→ ⤵⤴ ←←←  벽을 오가며 지그재그
       ╲  ╱
        ╲╱
```

### 두 가지 처방 — 1차 모멘트와 2차 모멘트

| 처방 | 무엇을 기억하나 | 무엇을 고치나 |
|---|---|---|
| **Momentum** | 기울기의 **이동평균** (1차 모멘트) | **방향** — 관성을 줘서 진동을 상쇄 |
| **RMSprop** | 기울기 **제곱의 이동평균** (2차 모멘트) | **보폭** — 파라미터마다 다르게 |

**Momentum의 직관**: 공이 굴러 내려가듯 **가던 방향으로 계속 가려는 힘**. 좌우 진동은 서로 상쇄되고 아래 방향만 누적된다.

**RMSprop의 직관**: 기울기가 **크게 요동친 파라미터는 보폭을 줄이고**, 조용했던 파라미터는 보폭을 키운다.

```text
보폭 ∝ 1 / √(기울기 제곱의 평균)

기울기가 컸던 파라미터 → 분모가 큼 → 보폭 작게
기울기가 작았던 파라미터 → 분모가 작음 → 보폭 크게
```

### Adam = Momentum + RMSprop

**Adam(Adaptive Moment Estimation, 적응적 모멘트 추정)** 은 둘을 합친 것이다.

```text
m ← β₁·m + (1−β₁)·g        1차 모멘트 (방향)
v ← β₂·v + (1−β₂)·g²       2차 모멘트 (보폭)

w ← w − η · m̂ / (√v̂ + ε)
                └───┘
        방향은 m이, 보폭은 v가 정한다
```

표준 기본값: `β₁ = 0.9`, `β₂ = 0.999`, `ε = 1e-8`

#### 편향 보정(Bias Correction) — 초반의 함정

`m`과 `v`는 **0에서 출발한다.** 그래서 학습 초반에는 실제보다 **작게 추정**된다.

```text
1스텝째: m = 0.9×0 + 0.1×g = 0.1g
         → 실제 기울기의 10%밖에 안 된다
```

그대로 두면 초반 갱신이 지나치게 작아진다. 그래서 **`(1−β^t)`로 나눠 부풀린다.**

```text
m̂ = m / (1 − β₁ᵗ)      t가 커질수록 분모가 1에 가까워져 보정이 사라진다
```

**초반에만 강하게 작동하고 자연히 꺼지는 보정**이다.

## 기준 답변

### Adam과 SGD의 핵심 차이

| 항목 | **SGD (+Momentum)** | **Adam** |
|---|---|---|
| 학습률 | **모든 파라미터에 동일** | **파라미터마다 적응적** |
| 기억하는 것 | (Momentum이면) 1차 모멘트 | **1차 + 2차 모멘트** |
| 추가 메모리 | 파라미터당 1배 | **파라미터당 2배** |
| 초기 수렴 속도 | 느리다 | **빠르다** |
| 하이퍼파라미터 민감도 | **높다** (학습률을 잘 맞춰야) | 낮다 (기본값이 대체로 통함) |
| 최종 일반화 성능 | **더 좋은 경우가 많다** | 약간 떨어지는 경향 |

**한 줄로 하면**: **SGD는 하나의 보폭으로 모두를 움직이고, Adam은 파라미터마다 자기 보폭을 갖는다.**

### 언제 무엇을 쓰나

| 상황 | 선택 | 이유 |
|---|---|---|
| **일단 돌려 보고 싶다** | **Adam** | 기본값으로도 대체로 수렴한다. 튜닝 부담이 적다 |
| **희소한 기울기** (NLP, 임베딩, 추천) | **Adam** | 가끔만 기울기가 오는 파라미터도 제대로 학습된다 |
| **트랜스포머 / LLM** | **AdamW** | 사실상 표준 |
| **이미지 분류에서 최고 성능** | **SGD + Momentum** | 경험적으로 **최종 일반화가 더 좋다**. 대신 학습률 스케줄을 잘 짜야 한다 |
| **메모리가 빠듯하다** | **SGD** | Adam은 파라미터당 상태를 2개 더 들고 있다 |

> ⚠️ **AdamW를 따로 알아 두면 좋다.** 원래 Adam에서 **가중치 감쇠(weight decay)** 를 그냥 손실에 더하면, 적응적 보폭 때문에 **파라미터마다 정규화 강도가 달라지는 왜곡**이 생긴다. AdamW는 감쇠를 **갱신식에서 분리**해 이 문제를 고쳤다. 오늘날 트랜스포머 학습의 기본값이다 → [[2026-08-09-ai-data-regularization]]

**Adam의 일반화가 약간 떨어지는 이유**에 대해서는 정설이 없지만, 적응적 보폭이 **더 뾰족한(sharp) 최소점**에 안착하는 경향이 있고, 뾰족한 최소점이 평평한 최소점보다 일반화가 나쁘다는 설명이 자주 인용된다.

### 학습률은 고정해야 하는가 — 아니다

**바꿔야 한다.** 이유는 학습 단계마다 필요한 보폭이 다르기 때문이다.

```text
초반 : 최적점에서 멀다  → 큰 보폭으로 빠르게 접근
후반 : 최적점 근처다    → 작은 보폭으로 정밀하게 안착
```

**고정 학습률의 딜레마**

| 고정값이 | 결과 |
|---|---|
| **크면** | 초반은 빠르지만 후반에 **최적점 주변을 계속 맴돈다**(수렴 못 함) |
| **작으면** | 후반은 정밀하지만 **초반이 하염없이 느리다** |

**어느 하나로는 양쪽을 다 만족시킬 수 없다.** 그래서 스케줄을 쓴다.

#### 주요 스케줄

| 방식 | 내용 |
|---|---|
| **Step Decay** | 정해진 에폭마다 학습률을 `1/10` 등으로 뚝 떨어뜨린다 |
| **Cosine Annealing** | 코사인 곡선을 따라 부드럽게 감소. **현재 가장 널리 쓰임** |
| **Linear Decay** | 선형으로 감소. LLM 학습에서 흔함 |
| **Warmup** | **처음엔 아주 작게 시작해 서서히 올린다** — 아래 참고 |

#### 왜 Warmup이 필요한가

**Adam의 편향 보정만으로는 부족한 초반 불안정이 있다.**

```text
학습 초기 : 2차 모멘트 v의 추정이 아직 부정확하다 (표본이 몇 개 없다)
           → 보폭 계산이 신뢰할 수 없다
           → 큰 학습률을 쓰면 엉뚱한 방향으로 크게 튄다
           → 잘못된 지점에 갇힌다
```

그래서 **처음 수백~수천 스텝 동안 학습률을 0에서 서서히 올린다.** 그동안 모멘트 추정이 안정되고, 그 뒤에 본격적인 스케줄(보통 코사인 감소)로 넘어간다.

**Warmup + Cosine Decay**가 오늘날 트랜스포머 학습의 표준 조합이다.

```text
학습률
  ▲
  │      ╱‾‾‾╲___
  │     ╱        ‾‾‾╲___
  │    ╱                 ‾‾╲__
  │   ╱                        ‾‾╲_
  └──┴────────────────────────────── 스텝
   warmup        cosine decay
```

> 💡 [[2026-09-17-ai-data-transfer-learning]]에서 본 **2단계 학습**과 발상이 같다. 불안정한 초반을 **보호 구간**으로 감싸 준 뒤 본 학습에 들어간다.

## 내가 정리한 내용

### 1. SGD의 두 가지 불편과 처방

- **모든 파라미터가 같은 보폭을 쓴다** → **RMSprop**: 기울기 **제곱의 이동평균**으로 **파라미터마다 보폭을 다르게** 준다. 희소한 특징(자주 안 나오는 단어의 임베딩 등)도 제대로 학습된다.
- **매 스텝의 기울기를 그대로 믿는다** → **Momentum**: **이동평균**으로 **관성**을 줘서 좁은 골짜기의 지그재그를 줄인다.

### 2. Adam이 무엇인가

**Adam = Momentum + RMSprop.** 1차 모멘트가 **방향**을, 2차 모멘트가 **보폭**을 수정한다.

**어떻게 고치는가**

- **1차 모멘트** — 기울기의 **이동평균**을 내면 **좌우 진동은 부호가 번갈아 상쇄되고 일관된 방향만 누적**되어 관성이 생긴다.

```text
스텝1: 좌로 +5,  아래로 −1
스텝2: 우로 −5,  아래로 −1
스텝3: 좌로 +4,  아래로 −1

좌우 성분 : +5, −5, +4 … → 상쇄되어 0에 가까워진다
아래 성분 : −1, −1, −1 … → 일관되므로 그대로 누적된다
```

- **2차 모멘트** — 기울기 **제곱**의 이동평균을 내면 **부호가 지워져 "얼마나 흔들렸나"만** 남고, 그 값으로 보폭을 나눠 요동친 파라미터의 보폭을 줄인다.

**왜 하필 제곱인가**

```text
기울기가 +5, −5, +4, −4 로 요동치는 파라미터

그냥 평균    : (+5 −5 +4 −4)/4 = 0      → "변동이 없다"고 잘못 읽는다
제곱의 평균  : (25+25+16+16)/4 = 20.5   → "크게 요동친다"를 제대로 잡는다
```

**1차는 부호를 살려 방향을, 2차는 부호를 지워 크기를 잰다.**

### 3. Adam vs SGD — 내주는 것과 얻는 것

- **Adam**이 내주는 건 **최종 일반화 성능 약간**과 **메모리 2배**이고, 얻는 것은 **빠른 수렴**과 **튜닝 부담 감소**다.
- **SGD**가 내주는 건 **튜닝 비용**과 **느린 초기 수렴**이고, 얻는 것은 **최종 일반화 성능**이다.

### 4. 학습률 스케줄

- **고정값이 크면** 초반엔 빠르지만 **후반에 수렴을 못 하고**, **작으면** 후반은 정밀하지만 **초반이 느리다.** 학습률을 고정하면 **양쪽을 만족시킬 수 없다.**
- **Warmup** — 초반에 **신뢰할 정보가 부족**해, 천천히 보폭을 움직이면서 방향을 찾는 것이다. Warmup을 하지 않으면 **이상한 방향으로 크게 튈 수 있다.**

## 검토 결과

### 확인된 부분

- **Adam vs SGD의 양쪽 거래를 모두** 담았고 **메모리 2배**까지 넣었다. 직전 대화에서 지적된 누락 항목을 바로 반영한 것이다.
- **고정 학습률의 딜레마를 양쪽 다** 구체적으로 썼다. "문제가 생긴다"가 아니라 "크면 수렴을 못 하고, 작으면 초반이 느리다"로 갈라 썼다.
- **Warmup의 이유를 "초반에 신뢰할 정보가 부족하다"** 는 일반 원리로 잡았다. Adam 전용 설명에 갇히지 않았다 — 실제로 큰 배치나 깊은 모델에서도 같은 이유로 warmup을 쓴다.
- **두 불편과 두 처방의 대응**이 정확하다. 헷갈리기 쉬운 짝인데 바르게 이었다.

### 보강 포인트

#### ① "어떻게"가 빠졌다

질문이 **"두 모멘트가 각각 무엇을 어떻게 고치나"** 였는데 **"무엇을"** 만 답했다. 교정 후 내용은 위 `내가 정리한 내용` 2번에 반영.

> 💡 **질문 문장에 있는 단어를 정리에서 되짚는 습관**을 들이면 이런 누락이 줄어든다 — **"어떻게"가 있으면 메커니즘을, "왜"가 있으면 근거를** 반드시 한 줄 넣는 식으로.

#### ② 처방에 한 줄씩

대응 자체는 맞았으나 각 처방이 **뭘 하는지**가 없었다. 교정 후 내용은 위 `내가 정리한 내용` 1번에 반영.

#### ③ 첫 답변의 "과적합"은 정확한 표현이 아니었다

| | 내용 |
|---|---|
| **전(첫 답변)** | Adam은 **과적합 될 위험**이 있음 |
| **후** | Adam은 **같은 훈련 손실에 도달해도 일반화가 약간 떨어지는 최소점**에 안착하는 경향이 있다 |

```text
과적합       : 훈련 손실은 계속 내려가는데 검증 손실이 올라간다 → 데이터를 외우는 것
Adam의 격차  : 훈련 손실은 SGD와 비슷하게 도달하는데 검증 성능만 조금 낮다
             → 외우는 게 아니라 "다른 종류의 해"에 도달한 것
```

정리에서는 **"일반화 성능"** 으로 바르게 고쳐 썼다.

### 심화: 뾰족한 최소점 vs 평평한 최소점

Adam의 일반화 격차에 자주 인용되는 설명이다.

```text
손실
 │  ╲    ╱           ╲___________╱
 │   ╲  ╱
 │    ╲╱              평평한 최소점 (flat)
 │  뾰족한 최소점       → 파라미터가 조금 어긋나도 손실이 별로 안 오른다
 │  (sharp)           → 새 데이터에 강하다
 │  → 조금만 어긋나도 손실이 급등
```

적응적 보폭이 뾰족한 쪽으로 이끄는 경향이 있다는 것이다.

> ⚠️ **다만 정설은 없다.** 활발히 논쟁 중인 주제라, 면접에서는 **"경험적으로 관찰되는 격차이고 원인은 확립되지 않았다"** 고 말하는 것이 정확하다.
>
> 그리고 **요즘은 격차가 많이 줄었다.** AdamW + 잘 설계된 스케줄이면 SGD와 거의 비슷하게 나온다. "SGD가 더 좋다"는 경험칙은 주로 **컴퓨터 비전의 특정 설정**에서 나온 것이고, 트랜스포머에서는 **AdamW가 압도적 표준**이다.

### 심화: 편향 보정(Bias Correction)

`m`과 `v`는 **0에서 출발한다.** 그래서 학습 초반에는 실제보다 **작게 추정**된다.

```text
1스텝째: m = 0.9×0 + 0.1×g = 0.1g
         → 실제 기울기의 10%밖에 안 된다
```

그대로 두면 초반 갱신이 지나치게 작아지므로 **`(1−β^t)`로 나눠 부풀린다.**

```text
m̂ = m / (1 − β₁ᵗ)      t가 커질수록 분모가 1에 가까워져 보정이 자연히 사라진다
```

**초반에만 강하게 작동하고 스스로 꺼지는 보정**이다.

표준 기본값: `β₁ = 0.9`, `β₂ = 0.999`, `ε = 1e-8`

### 심화: AdamW — 가중치 감쇠를 분리한 이유

원래 Adam에서 **가중치 감쇠(weight decay)** 를 그냥 손실에 더하면, **적응적 보폭 때문에 파라미터마다 정규화 강도가 달라지는 왜곡**이 생긴다.

```text
L2 벌점을 손실에 더한다
  → 그 벌점의 기울기도 2차 모멘트 v에 섞여 들어간다
  → 보폭이 큰 파라미터는 정규화도 약하게, 작은 파라미터는 강하게 받는다
  → 의도하지 않은 불균등
```

**AdamW는 감쇠를 갱신식에서 분리**해 이 문제를 고쳤다. 오늘날 트랜스포머 학습의 기본값이다 → [[2026-08-09-ai-data-regularization]]

### 심화: 학습률 스케줄의 종류

| 방식 | 내용 |
|---|---|
| **Step Decay** | 정해진 에폭마다 학습률을 `1/10` 등으로 뚝 떨어뜨린다 |
| **Cosine Annealing** | 코사인 곡선을 따라 부드럽게 감소. **현재 가장 널리 쓰임** |
| **Linear Decay** | 선형으로 감소. LLM 학습에서 흔함 |
| **Warmup** | 처음엔 아주 작게 시작해 서서히 올린다 |

```text
학습률
  ▲
  │      ╱‾‾‾╲___
  │     ╱        ‾‾‾╲___
  │    ╱                 ‾‾╲__
  │   ╱                        ‾‾╲_
  └──┴────────────────────────────── 스텝
   warmup        cosine decay
```

**Warmup + Cosine Decay**가 오늘날 트랜스포머 학습의 표준 조합이다.

> 💡 [[2026-09-17-ai-data-transfer-learning]]의 **2단계 학습**과 발상이 같다. 불안정한 초반을 **보호 구간**으로 감싸 준 뒤 본 학습에 들어간다. 파인튜닝에서는 새 분류층이 안정될 때까지 동결하고, 여기서는 모멘트 추정이 안정될 때까지 보폭을 줄인다.

### 이전 학습과의 연결

- [[2026-08-27-ai-data-gradient-descent]] — `w ← w − η·g`가 출발점이다. 그 노트에서 옵티마이저를 **한 줄 표로만** 지나갔던 것을 오늘 정면으로 팠다. **특징 스케일에 민감하다**는 SGD의 한계가 곧 RMSprop이 푸는 문제다.
- [[2026-09-04-ai-data-backpropagation]] — **"역전파는 기울기를 구하고 옵티마이저는 그걸 쓴다"** 는 분리가 오늘 구체화됐다. `loss.backward()`를 안 바꾸고 `optimizer`만 SGD→Adam으로 교체할 수 있는 이유다.
- [[2026-08-09-ai-data-regularization]] — **AdamW**가 가중치 감쇠(L2)를 왜 분리했는지가 여기서 이어진다.
- [[2026-09-17-ai-data-transfer-learning]] — **초반을 보호 구간으로 감싼다**는 발상이 warmup과 2단계 학습에 공통이다. 파인튜닝의 낮은 학습률도 같은 계열의 처방이다.
- [[2026-09-10-ai-data-weight-initialization]] — 초기화가 **출발점**을 정한다면 옵티마이저·스케줄은 **거기서 어떻게 움직일지**를 정한다.
- [[2026-08-31-ai-data-hyperparameter-tuning]] — 학습률은 **로그 스케일로 탐색**해야 하는 대표적 하이퍼파라미터다. Adam이 "튜닝 부담이 적다"는 것은 이 탐색 비용이 준다는 뜻이다.
- [[2026-09-15-ai-data-mixture-of-experts]] — Adam의 **옵티마이저 상태가 모델 크기의 2배**라는 점이 LLM 학습 메모리 계산에서 실제로 큰 항목이다.
