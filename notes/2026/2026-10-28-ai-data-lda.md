## 핵심 개념

질문에 답하기 위해 필요한 핵심 개념을 정리한다.

LDA는 **두 얼굴**이 있다. 같은 수학이 **분류기**로도, **차원 축소**로도 쓰인다. 하나씩 본다.

### 얼굴 ① 분류기로서의 LDA

#### 1. 무엇을 원하는 상황인가

키(`x`)를 보고 **어른(A)인지 아이(B)인지** 분류하고 싶다.

#### 2. 로지스틱 회귀는 어떻게 했나

[[2026-10-08-ai-data-logistic-cross-entropy]]에서 로지스틱 회귀는 **경계를 직접** 찾았다. "키가 몇 이상이면 어른"이라는 선을 교차 엔트로피로 학습했다. 이런 방식을 **판별 모델(discriminative model)** 이라 한다 — `P(클래스 | x)`를 바로 배운다.

#### 3. LDA는 반대 방향으로 간다 — 먼저 "각 클래스가 어떻게 생겼나"를 배운다

**LDA는 경계를 직접 찾지 않는다.** 대신 **각 클래스의 데이터가 어떤 분포를 이루는지**를 먼저 모델링하고, 그걸로 경계를 **계산해 낸다.** 이런 방식을 **생성 모델(generative model)** 이라 한다 — `P(x | 클래스)`를 배운 뒤 베이즈 정리로 `P(클래스 | x)`를 얻는다.

**LDA의 두 가지 가정**

| 가정 | 뜻 |
|---|---|
| ① 각 클래스는 **정규분포**를 따른다 | 어른 키는 평균 170 근처에 종 모양, 아이 키는 평균 130 근처에 종 모양 |
| ② **모든 클래스의 분산(공분산)이 같다** | 두 종 모양의 **폭이 같다** |

**작은 숫자로** — 어른 키 평균 `μ_A = 170`, 아이 키 평균 `μ_B = 130`, 둘 다 표준편차 `σ = 10`, 어른·아이 비율 반반.

```text
키 150은 어느 쪽인가?
  어른 평균에서 (150 − 170) = −20,  2σ 떨어짐
  아이 평균에서 (150 − 130) = +20,  2σ 떨어짐
  → 정확히 같은 거리 → 경계

키 160은?
  어른에서 −10 (1σ),  아이에서 +30 (3σ)  → 어른 쪽이 훨씬 그럴듯 → 어른
```

**경계는 두 평균의 정확히 가운데(150)** 다. 분산이 같고 비율이 같으면 항상 그렇다.

#### 4. 왜 경계가 "선형"이 되나 — 가정 ②가 핵심

두 클래스 중 어느 쪽 확률이 큰지 보려면 **두 정규분포의 로그 확률 차이**를 본다. 1차원에서 한 줄씩 전개하면:

```text
log P(x|A) − log P(x|B)

  = [ −(x − μ_A)² + (x − μ_B)² ] / (2σ²)            ← 정규분포의 지수 부분만 남음

  = [ −(x² − 2μ_A·x + μ_A²) + (x² − 2μ_B·x + μ_B²) ] / (2σ²)     ← 제곱을 풀었다

  = [ −x² + x² + 2(μ_A − μ_B)·x + (μ_B² − μ_A²) ] / (2σ²)

  = [ 2(μ_A − μ_B)·x + (μ_B² − μ_A²) ] / (2σ²)      ← x²이 사라졌다!
       └──────────┬──────────┘
            x에 대한 1차식 = 직선
```

**`x²` 항이 정확히 상쇄되는 이유는 두 클래스의 `σ`가 같기 때문이다.** 분모 `2σ²`가 같아야 `−x²`와 `+x²`가 같은 크기로 만나 사라진다. 그래서 경계가 **직선(고차원에서는 초평면)** 이 된다 — 이게 이름의 "선형(Linear)"이다.

**분산이 다르면?** `x²`이 남아 경계가 **곡선**이 된다. 이게 **QDA**(Quadratic Discriminant Analysis, 이차 판별 분석)다.

| | 가정 | 경계 |
|---|---|---|
| **LDA** | 모든 클래스의 공분산이 **같다** | **직선** |
| **QDA** | 클래스마다 공분산이 **다르다** | **곡선**(이차) |

### 얼굴 ② 차원 축소로서의 LDA (Fisher의 판별)

#### 1. 무엇을 원하는 상황인가

2차원 데이터를 **1차원 직선 하나에 투영**해서, **투영한 뒤에도 두 클래스가 잘 갈리게** 하고 싶다. 어느 방향으로 투영할까?

#### 2. 기준 — 두 가지를 동시에

```text
좋은 방향의 조건
  ① 두 클래스의 평균이 투영 후 멀리 떨어져야 한다        (분자 ↑)
  ② 각 클래스 안의 점들이 투영 후 뭉쳐 있어야 한다         (분모 ↓)

J = (투영된 두 평균의 차)² / (투영된 클래스 안 분산의 합)
→ J를 가장 크게 만드는 방향을 고른다
```

**①만 보면 안 된다.** 평균은 멀어도 클래스 안이 넓게 퍼져 있으면 겹친다. **둘의 비율**을 봐야 한다.

#### 3. 작은 숫자로 — PCA와 비교하면 차이가 선명하다

두 클래스, 점 3개씩:

```text
클래스 A : (0, 2), (2, 4), (4, 6)        ← 대각선 위쪽
클래스 B : (2, 0), (4, 2), (6, 4)        ← 대각선 아래쪽

  y
  6 │         A
  4 │     A       B
  2 │ A       B
  0 │     B
    └──────────────── x
      0   2   4   6
```

세 방향으로 투영해 보자. (대각 방향은 `√2`로 나눠 길이를 1로 맞춘 값)

| 투영 방향 | A의 투영값 | B의 투영값 | 결과 |
|---|---|---|---|
| **x축** | 0, 2, 4 | 2, 4, 6 | **겹침** — 2와 4가 양쪽에 다 있다 |
| **(1, 1) 대각** | 1.41, 4.24, 7.07 | 1.41, 4.24, 7.07 | **완전히 겹침** — 두 클래스가 똑같은 값 |
| **(1, −1) 대각** | −1.41, −1.41, −1.41 | +1.41, +1.41, +1.41 | **완벽 분리** — 클래스 안 흩어짐 0 |

**PCA는 (1, 1) 방향을 고른다.** PCA는 **라벨을 보지 않고 데이터 전체가 가장 넓게 퍼진 방향**을 찾는데, 6개 점이 가장 길게 늘어선 방향이 (1, 1)이다. 그런데 **그 방향에서는 두 클래스가 완전히 겹친다.**

**LDA는 (1, −1) 방향을 고른다.** **라벨을 보고**, 평균은 멀고 클래스 안은 뭉치는 방향을 찾기 때문이다.

> 🏫 **비유**: 사진을 찍어 두 무리를 구분해야 한다. **PCA**는 "무리 전체가 가장 넓게 보이는 각도"에서 찍는다. 그 각도에서는 두 무리가 앞뒤로 겹쳐 하나로 보일 수 있다. **LDA**는 "두 무리 사이 틈이 가장 잘 보이는 각도"에서 찍는다.

## 기준 답변

### LDA vs PCA

| | **PCA** | **LDA** |
|---|---|---|
| 라벨 | **안 쓴다** (비지도) | **쓴다** (지도) |
| 찾는 방향 | 데이터 전체의 **분산이 최대**인 방향 | 클래스 **분리가 최대**인 방향 |
| 축소할 수 있는 최대 차원 | 원래 차원 수까지 | **클래스 수 − 1** (2클래스면 1차원) |
| 쓰임 | 압축·시각화·잡음 제거 | **분류를 위한** 특징 추출 |

**"클래스 수 − 1"인 이유**: 클래스 평균 `C`개는 최대 `C − 1`차원 공간에 놓인다(점 2개는 직선 1개, 점 3개는 평면 1개). 평균들 사이의 차이가 담긴 방향이 그만큼뿐이다.

### LDA vs 로지스틱 회귀

둘 다 **경계가 직선인 선형 분류기**다. 차이는 **경계를 어떻게 얻느냐**다.

| | **로지스틱 회귀** | **LDA** |
|---|---|---|
| 방식 | **판별 모델** — 경계를 직접 학습 | **생성 모델** — 클래스 분포를 모델링해 경계를 계산 |
| 배우는 것 | `P(클래스 \| x)` | `P(x \| 클래스)` → 베이즈로 뒤집음 |
| 가정 | 적다 | **정규분포 + 같은 공분산** |
| 가정이 맞을 때 | 좋다 | **더 좋다** — 적은 데이터로도 안정적 |
| 가정이 틀릴 때 | **덜 흔들린다** | 나빠진다 (특히 **이상치**에 약함) |

**편향-분산으로 보면** — [[2026-08-05-ai-data-bias-variance]]

```text
LDA       : 가정이 강하다 → 분산↓ 편향↑  → 데이터가 적을 때 유리 (가정이 맞다면)
로지스틱   : 가정이 약하다 → 분산↑ 편향↓  → 데이터가 많거나 분포가 정규가 아닐 때 유리
```

[[2026-09-28-ai-data-parametric-vs-nonparametric]]에서 본 **"가정은 데이터를 대신하는 지식"** 이 여기서도 그대로다.

**이상치에 약한 이유**: LDA는 **평균과 분산**을 추정하는데, 둘 다 극단값 하나에 크게 끌려간다. 로지스틱 회귀는 이미 경계에서 멀리 떨어진 점의 손실이 0에 가까워져 영향이 작다.

### 실무에서

- **소량 데이터의 다중 분류 기준선**으로 쓸 만하다. 학습이 빠르고(평균·공분산 계산이면 끝), 해석이 쉽다.
- **분류 전 차원 축소**로 쓴다. 예: 얼굴 인식의 고전 기법 **Fisherfaces**.
- 데이터가 충분하고 분포가 정규와 거리가 멀면 **로지스틱 회귀나 부스팅**이 보통 낫다.

### 실무 관점 — 지금도 쓰이는 자리

**표 형태 데이터에서 최종 분류기로 LDA를 고르는 일은 드물다.** 데이터가 어느 정도 있으면 대부분 XGBoost·CatBoost가 이긴다. 하지만 "이제 안 쓴다"는 아니다.

**부스팅이 이기는 경우 — 대부분의 표 데이터**

| 조건 | 이유 |
|---|---|
| 데이터가 수백~수천 개 이상 | 가정 없이도 패턴을 배울 만큼 데이터가 있다 |
| 비선형 관계·**특징 간 상호작용** | LDA 경계는 직선이라 표현할 수 없다 |
| 범주형·연속형 혼합 | LDA는 정규분포를 가정해 범주형과 맞지 않는다 |
| 치우친 분포·이상치 | 평균·분산이 끌려가 흔들린다 |

**LDA가 지금도 쓰이는 자리**

| 자리 | 이유 |
|---|---|
| **특징이 샘플보다 많을 때** (뇌파 BCI, 유전자 발현) | 부스팅은 나눌 근거가 부족해 과적합한다. 가정이 강한 모델이 오히려 안정적이다. BCI에서는 **수축(shrinkage) LDA**가 오랫동안 표준 분류기였다 |
| **라벨을 쓰는 차원 축소·시각화** | 클래스를 잘 가르는 방향으로 투영. KNN 등 쓰기 전 전처리 |
| **빠르고 해석 가능한 기준선** | 평균·공분산 계산이면 학습 끝, 튜닝 거의 없음, 예측은 곱셈 한 번 |

**면접에서 묻는 것은 모델보다 개념이다** — 생성 vs 판별, PCA vs LDA, "분산이 같으면 `x²`이 상쇄돼 직선", "가정이 강하면 소량 데이터에 유리". [[2026-09-28-ai-data-parametric-vs-nonparametric]]의 결론(실무 기본값은 부스팅, 이론은 그 기본값이 틀리는 경우를 알려 준다)과 같다.

### 한 문장 요약

> **LDA는 각 클래스가 정규분포를 따르고 공분산이 같다고 가정한 생성 모델로, 공분산이 같기 때문에 두 분포의 로그 비교에서 `x²` 항이 상쇄되어 경계가 직선이 된다. 차원 축소로 쓰면 라벨을 이용해 "평균은 멀고 클래스 안은 뭉치는" 방향을 찾으므로, 라벨 없이 분산만 보는 PCA와 달리 클래스 분리에 유리하다. 로지스틱 회귀와 같은 선형 분류기지만, 경계를 직접 배우지 않고 분포에서 계산하며, 가정이 맞으면 적은 데이터에 강하고 틀리면(비정규·이상치) 약하다.**

## 내가 정리한 내용

### 1. 분류기로서 LDA의 경계가 직선인 이유

- **분산이 같으므로 선형이 된다.**
- 두 클래스 중 어느 쪽이 그럴듯한지 비교하려고 **두 정규분포의 로그 확률 차이**를 계산하면 각각에서 `−x²`와 `+x²`가 나온다. **분산이 같으면 둘이 같은 크기라 정확히 상쇄**되고, `x`에 대한 **1차식만 남아 경계가 직선**이 된다. 분산이 다르면 `x²`이 남아 곡선(QDA)이 된다.

### 2. PCA와 LDA가 다른 방향을 고르는 이유

- **PCA는 라벨을 보지 않고** 전체가 가장 넓게 퍼진 방향을 찾고, **LDA는 라벨을 보고** 평균은 멀고 클래스 안은 뭉치는 방향을 찾는다.
- 예시에서 (1, 1)은 점 6개가 가장 넓게 퍼진 방향이지만 두 클래스가 완전히 겹치고, (1, −1)은 클래스 안 흩어짐이 0이라 완벽히 갈린다.

### 3. 로지스틱 회귀와의 차이

- 로지스틱 회귀는 경계를 직접 학습하는 **판별 모델**이고, LDA는 클래스 분포를 배워 경계를 계산하는 **생성 모델**이다.
- 판단의 중심축은 **LDA의 가정(정규분포·같은 분산)이 맞는가**다. 가정이 맞고 데이터가 적으면 **LDA**, 가정이 틀리거나(비정규·이상치) 데이터가 충분하면 **로지스틱 회귀**가 유리하다.
- LDA는 가정이 강해 **분산이 낮고(적은 데이터에 유리) 편향이 높다(가정이 틀리면 손해).**

## 검토 결과

### 확인된 부분

- PCA와 LDA의 차이를 **"라벨을 쓰느냐, 무엇을 최대화하느냐"** 로 정확히 대비했다.
- 로지스틱 회귀와 LDA를 **판별 모델 vs 생성 모델**로 정확히 구분했다.
- 대화 중 **"LDA는 옛날 모델 아닌가, 부스팅이 낫지 않나?"** 를 스스로 물었다. 그 답에서 **지금도 LDA가 쓰이는 자리**(특징 > 샘플, 라벨 있는 차원 축소, 기준선)와 **면접에서 실제로 묻는 것은 모델이 아니라 개념**이라는 정리가 나왔다.

### 보강 포인트

#### ① Q1 — 결론만 있고 역할이 빠졌다

| | 내용 |
|---|---|
| **전** | 분산이 같으므로 선형이 됨 |
| **후** | 로그 확률 차이에서 **`−x²`와 `+x²`가 분산이 같아 상쇄** → 1차식만 남아 직선 |

질문은 가정이 **"어떤 역할을 하는지"** 를 물었다. 결론만 말하면 "그게 왜 선형을 만드나요?"라는 꼬리 질문이 바로 온다. **"분산이 같다 → `x²` 상쇄 → 1차식"** 의 연결이 답이다.

#### ② Q3 — 조건을 AND로 묶었다

| | 내용 |
|---|---|
| **전** | 데이터가 적고 이상치가 없으면 LDA, **데이터가 많고 이상치가 있으면** 로지스틱 |
| **후** | **"가정이 맞는가"** 를 중심축으로 — 가정 위반이나 충분한 데이터, **둘 중 하나만** 해당해도 로지스틱 쪽으로 기운다 |

"많고 그리고 이상치가 있으면"은 두 조건이 동시에 필요한 것처럼 읽힌다. 또 **이상치는 가정 위반의 한 종류**일 뿐이다 — 치우친 분포, 클래스마다 다른 분산도 가정 위반이다.

### 심화: 생성 vs 판별을 편향-분산으로

```text
생성 모델(LDA)  : P(x | 클래스)를 모델링 → 분포 가정이 강하다 → 분산↓ 편향↑
판별 모델(로지스틱) : P(클래스 | x)만 모델링 → 가정이 약하다 → 분산↑ 편향↓
```

**가정이 맞으면 생성 모델이 적은 데이터로 더 빨리 좋은 경계에 도달한다.** 가정이 틀리면 데이터가 아무리 많아도 그 틀린 가정에 묶인다. 데이터가 늘수록 판별 모델이 따라잡고 앞서는 경향이 있다 — [[2026-09-11-ai-data-cnn]]의 CNN vs ViT 교차 그래프와 같은 모양이다.

### 심화: 같은 수학의 두 얼굴

| | 분류기 LDA | 차원 축소 LDA (Fisher) |
|---|---|---|
| 목표 | 새 점이 어느 클래스인가 | 클래스를 가장 잘 가르는 방향 |
| 핵심 | 분산이 같아 `x²` 상쇄 → 직선 경계 | 평균 차 ÷ 클래스 안 분산을 최대화 |
| 결과 | 직선 경계 | **클래스 수 − 1** 개의 축 |

같은 가정(같은 공분산) 아래 두 관점은 **같은 방향**을 가리킨다. 경계에 수직인 방향이 곧 최적의 투영 방향이다.
