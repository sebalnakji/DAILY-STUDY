## 질문

> **분류 모델을 어떻게 평가하는가? 정확도(accuracy)는 항상 좋은 지표인가? 정밀도(precision)와 재현율(recall)은 무엇인가?**
>

## 핵심 개념

질문에 답하기 위해 필요한 핵심 개념을 정리한다.

### 혼동 행렬(Confusion Matrix)

거의 모든 분류 지표가 이 표에서 나온다.

| | 실제 Positive (1) | 실제 Negative (0) |
|---|---|---|
| **예측 Positive (1)** | **TP** (True Positive) | **FP** (False Positive) |
| **예측 Negative (0)** | **FN** (False Negative) | **TN** (True Negative) |

- **TP**: 실제 1인데 1로 예측 (맞힘)
- **TN**: 실제 0인데 0으로 예측 (맞힘)
- **FP**: 실제 0인데 1로 예측 — **헛다리** (거짓 경보)
- **FN**: 실제 1인데 0으로 예측 — **놓침**

> 이름 읽는 법: 뒷 글자가 **예측**, 앞 글자가 **맞았는지 여부**. `False Positive` = "Positive로 예측했는데 틀림".

### 주요 지표

| 지표 | 식 | 의미 |
|---|---|---|
| **정확도(Accuracy)** | `(TP+TN) / 전체` | 전체 중 맞힌 비율 |
| **정밀도(Precision)** | `TP / (TP+FP)` | **1이라 예측한 것 중** 진짜 1의 비율 |
| **재현율(Recall)** | `TP / (TP+FN)` | **진짜 1 중에서** 잡아낸 비율 |
| **F1 점수** | `2PR / (P+R)` | 정밀도와 재현율의 **조화평균** |

- 정밀도·재현율 모두 **1이 최고** (FP나 FN이 하나도 없는 상태).
- F1도 최대 1, 최소 0.
- 그 외: 로지스틱 손실(= 교차 엔트로피 손실), 자카드 유사도 계수.

### ⚠️ 정확도의 함정 — 불균형 데이터

**데이터가 불균형하면 정확도는 좋은 지표가 아니다.**

> 이진 분류에서 A 클래스가 95%, B 클래스가 5%라면 → **무조건 A라고만 답해도 정확도 95%.**

아무것도 학습하지 않은 모델이 95점을 받는다. 이런 경우 문제에 맞게 **정밀도, 재현율, F1**을 선택해야 한다.

### 정밀도-재현율 트레이드오프

- 모델을 그대로 두고 **결정 임계값(threshold)을 옮기면** 한쪽이 오르고 다른 쪽이 내려간다.
- 완벽히 분리 가능한 데이터라면 둘 다 1.0이 가능하지만, 현실 데이터에는 노이즈가 있어 경계 근처에 섞인 점들이 존재한다.
- 그래서 **경계를 옮기면 정밀도나 재현율 중 하나만 올릴 수 있다.** → [[2026-07-20-ai-data-supervised-learning]]에서 예고한 그 트레이드오프.

**어느 쪽을 우선할지는 비용이 결정한다.**

| 상황 | 더 무서운 오류 | 우선 지표 |
|---|---|---|
| 암 진단 | **놓침(FN)** — 환자를 놓치면 생명 위험 | **재현율** |
| 스팸 필터 | **헛다리(FP)** — 중요 메일이 스팸함으로 | **정밀도** |

### ROC 곡선과 AUC

- **ROC(Receiver Operating Characteristics)**: 여러 임계값에서의 **참 양성률(TPR) vs 거짓 양성률(FPR)** 을 그린 곡선. 이진 결과의 확률을 예측할 때 사용한다.
- **AUC(Area Under the ROC Curve)**: ROC 곡선 아래 면적. **클래스를 구분해내는 능력(separability)** 의 정도를 나타낸다.
  - 1에 가까울수록 우수, 0.5면 **구분 능력이 전혀 없음**(찍기와 동일), 0에 가까우면 최악.
- **PR 곡선(Precision-Recall Curve)**: 여러 임계값에서 정밀도(y축)와 재현율(x축)을 그린 곡선.
  - **심하게 불균형한 데이터에서는 ROC가 지나치게 낙관적으로 보일 수 있어 PR 곡선을 권장한다.**

### 참고: 로지스틱 회귀

- **이진 분류**에 쓰는 알고리즘. `Y`가 두 값만 가질 때 사용한다(True/False, spam/not spam, churn/not churn).
- **일반화 선형 모델(generalized linear model)** 로 분류된다. 결과가 항상 **입력과 파라미터의 합**에 의존하기 때문. 파라미터의 곱이나 나눗셈에는 의존하지 않는다. → [[2026-07-25-ai-data-linear-regression]]
- **시그모이드(sigmoid)** 는 출력을 0~1로 눌러주는 **압착(squashing) 함수**이자 활성화 함수. 확률 예측에 유용하다.
  ```text
  sigmoid(x) = 1 / (1 + e^(-x))
  ```

## 기준 답변

기준 레포의 답변을 바탕으로 핵심만 재구성한다.

**분류 모델 평가지표**로는 정확도, 정밀도, 재현율, F1 점수, 로지스틱 손실(교차 엔트로피 손실), 자카드 유사도 계수 등이 있다. 문제에 따라 적절한 것을 선택한다.

**정확도**는 맞힌 예측 수를 전체 예측 수로 나눈 값이다. 하지만 **데이터가 불균형할 때는 좋은 지표가 아니다.** 예를 들어 A 클래스 95%, B 클래스 5%인 이진 분류에서 항상 A라고만 예측해도 정확도는 95%가 된다. 이런 경우 문제에 맞게 정밀도, 재현율, F1을 선택해야 한다.

**혼동 행렬**은 모델이 만든 TP, TN, FP, FN의 개수를 보여주며, 분류 지표 대부분이 이 값들에 기반한다.

**정밀도는 `TP/(TP+FP)`, 재현율은 `TP/(TP+FN)`** 이다. 둘 다 1이 최선이며, FP와 FN이 없고 TP만 있는 상태를 뜻한다. **F1은 둘을 조화평균으로 결합한 점수**로 `2PR/(P+R)`이며 최대 1, 최소 0이다.

**정밀도-재현율 트레이드오프**는 모델을 그대로 둔 채 한쪽을 올리면 다른 쪽이 내려가는 현상이다. 완벽히 분리 가능한 데이터에서는 둘 다 1.0이 가능하지만, 현실 데이터는 노이즈가 있어 양성 클래스 점이 음성 클래스 가까이 있는 경우가 생긴다. 이때 **결정 경계를 옮기면 정밀도나 재현율 중 하나만 올릴 수 있다.**

**ROC 곡선**은 참 양성률과 거짓 양성률의 대비를 보여주며, **AUC**는 그 곡선 아래 면적으로 클래스 구분 능력을 나타낸다. 0.5면 구분 능력이 전혀 없다는 뜻이다. **심하게 치우친 데이터에서는 ROC가 과도하게 낙관적일 수 있어 PR 곡선을 권장한다.**

## 내가 정리한 내용

**1. 정확도(Accuracy)는 왜 항상 좋은 지표가 아닌가**

**불균형 데이터에서 편향된 결과**를 보여줄 수 있기 때문이다. 예를 들어 99%가 정상이고 1%가 비정상인 데이터에서 모델이 전부 정상으로 예측해도 정확도는 99%가 된다. 아무것도 학습하지 않은 모델이 높은 점수를 받는 것이다.

**2. 정밀도와 재현율**

- **정밀도(Precision)** = `TP/(TP+FP)` — **우리가 양성이라고 예측한 것 중** 실제로 양성인 비율
- **재현율(Recall)** = `TP/(TP+FN)` — **실제로 양성인 것 중** 모델이 양성으로 맞힌 비율
- 분자는 둘 다 TP로 같고 **분모(무엇 중에서)만 다르다.** 한마디로 **정밀도는 "내 말이 맞았나", 재현율은 "다 찾았나"** 이다.
- **F1 점수**는 둘의 조화평균으로, 한쪽이 0에 가까우면 F1도 0에 가까워진다.

**3. 어느 쪽을 우선할지 판단하는 기준**

**어느 쪽 오류의 비용이 더 큰가**로 판단한다.

- **헛다리(FP)가 더 비싸면 정밀도** 우선 — 스팸 필터에서 중요 메일이 스팸함으로 가면 큰 손해
- **놓침(FN)이 더 비싸면 재현율** 우선 — 암 진단에서 환자를 놓치면 생명과 직결

또한 둘 다 중요하면 **단계를 나눠** 1단계는 재현율 우선으로 넓게 거르고, 2단계에서 정밀하게 확인하는 설계를 쓸 수 있다(자가진단 키트 → PCR 검사).

## 검토 결과

### 확인된 부분

- **정확도의 함정을 구체적 수치 예시와 함께 정확히 설명함.** "아무것도 학습하지 않은 모델이 99%"라는 핵심을 짚음.
- 정밀도 정의를 정확히 서술("우리가 양성이라 예측한 것 중 실제 양성").
- 실습 Q1(사기 탐지)·Q2(코로나 키트) 모두 정확히 판단.

### 보강 포인트

- **재현율 정의가 순환 문장이었다 → 교정.** 초기 답변: *"전체 양성인 데이터 중에서 **실제로 양성인** 데이터의 비율"* → 읽으면 "양성 중 양성"이라 항상 100%가 되는 문장. 분자가 잘못 들어갔다.
  - 올바른 형식: **"실제로 양성인 것 중 → 모델이 양성으로 맞힌 비율"**

  | | 무엇 중에서 (분모) | 무엇의 비율 (분자) |
  |---|---|---|
  | 정밀도 | **내가 양성이라 한 것** | 맞힌 것(TP) |
  | 재현율 | **실제 양성인 것** | 맞힌 것(TP) |

  > **정밀도는 "내 말이 맞았나", 재현율은 "다 찾았나".**

- **판단 기준에 "정확도"라는 단어를 쓰지 말 것.** 초기 답변의 *"정확도가 더 중요하다고 여겨지면"* 은 의미는 통하나, Accuracy는 방금 "믿으면 안 된다"고 배운 **다른 지표의 이름**이라 혼동을 부른다.
  - **"어느 쪽 오류의 비용이 더 큰가"** 로 말하면 판단이 기계적으로 명확해진다.
- **혼동 행렬 이름 읽는 법**: **뒷 글자 = 내가 뭐라고 예측했나 / 앞 글자 = 그게 맞았나.**
  - `False Positive` = "Positive라고 예측했는데 틀림" = **헛다리**
  - `False Negative` = "Negative라고 예측했는데 틀림" = **놓침**
  - 이 규칙 하나면 네 개를 개별로 외울 필요가 없다.
- **F1이 산술평균이 아니라 조화평균인 이유**: 한쪽이 0에 가까우면 F1도 0에 가까워지도록. 정밀도 100% / 재현율 0%는 평균 50점이 아니라 **낙제**여야 한다.

### 심화: 사기 탐지는 양쪽 다 아프다 (Q1)

암 진단은 "놓침이 더 아프다"로 명확하지만, 사기 탐지는 다르다.

| 오류 | 비용 |
|---|---|
| **놓침(FN)** | 사기 거래 통과 → **돈이 나감** |
| **헛다리(FP)** | 정상 거래 차단 → **고객이 화나서 이탈** |

카드가 정상 결제인데 자꾸 막히면 고객은 그 카드를 안 쓴다. 그래서 사기 탐지는 F1이나 **PR 곡선**으로 균형을 본다. → 원문의 *"심하게 불균형한 데이터에는 PR 곡선 권장"* 이 적용되는 사례.

### 심화: 트레이드오프를 감수하지 말고 설계로 풀어라 (Q2)

코로나 검사는 재현율 우선이 맞지만, 정밀도를 완전히 버릴 수도 없다. 위양성이 너무 많으면 불필요한 격리 비용이 들고, 무엇보다 **사람들이 키트를 믿지 않게 된다.**

```text
1단계: 자가진단 키트   싸고 빠름 · 재현율 우선 · 넓게 거른다
          ↓ 양성이면
2단계: PCR 검사        비싸고 정확 · 정밀도 확보 · 확정
```

**어제 배운 검색 구조와 동형이다.**

| | 검색 | 코로나 검사 |
|---|---|---|
| 1단계 | **Bi-encoder** — 빠르게 100개 (재현율) | **자가진단 키트** — 넓게 (재현율) |
| 2단계 | **Cross-encoder** — 정확히 10개 (정밀도) | **PCR** — 확정 (정밀도) |

> **하나의 지표로 다 못 잡으면, 단계를 나눠 각 단계에 다른 지표를 맡긴다.**

→ [[2026-08-03-ai-data-embeddings]]

면접에서는 **"재현율을 우선하되 정밀도는 2단계 확인으로 보완합니다"** 라고 답하면, 트레이드오프를 감수하는 게 아니라 **설계로 푸는** 사람으로 읽힌다.

### ROC / AUC 주의점

- **AUC 0.5는 "반타작"이 아니라 "구분 능력 전혀 없음"**(찍기와 동일). 자주 헷갈리는 지점.
- **ROC/AUC도 불균형 데이터에서 속을 수 있다.** 음성이 압도적으로 많으면 FPR의 분모가 커서 FP가 늘어도 티가 안 난다. → 원문이 심하게 치우친 데이터에 **PR 곡선**을 권장하는 이유.
- 정확도든 AUC든, **불균형 데이터에서는 모든 "전체 평균형 지표"를 의심해야 한다.**

### 이전 학습과의 연결

- **임계값(threshold)이 곧 정밀도-재현율 트레이드오프**라고 첫날 예고했던 그 내용. 모델은 그대로 두고 판정 기준만 옮기는 것. → [[2026-07-20-ai-data-supervised-learning]]
- **로지스틱 회귀**는 시그모이드로 0~1 확률을 만든 뒤 임계값으로 자르는 이진 분류 모델. 일반화 선형 모델로 분류되는 이유는 결과가 **입력과 파라미터의 합**에 의존하기 때문. → [[2026-07-25-ai-data-linear-regression]]
- 평가 자체를 신뢰하려면 **평가에 쓴 데이터가 학습·선택에 쓰이지 않아야** 한다. → [[2026-07-30-ai-data-validation]]

### 오늘 나온 축약어

| 축약어 | 풀네임 |
|---|---|
| TP / TN | True Positive / True Negative |
| FP / FN | False Positive / False Negative |
| ROC | Receiver Operating Characteristics |
| AUC | Area Under the Curve |
| PR 곡선 | Precision-Recall Curve |
| TPR / FPR | True Positive Rate / False Positive Rate |
| PCR | Polymerase Chain Reaction (중합효소 연쇄 반응) |
